# 系统干预、反馈回路与回溯推演

本文用于反复症状、多主体反馈、时间延迟和不确定目标态下的工程干预。它只提供待验证的问题模型与行动路径，不替代产品、合规、安全、生产、测试或 Owner 证据。

## 使用时机

- 同一症状经多轮局部修复仍反复出现，或修复把成本转移给其他主体、阶段或系统边界。
- 指标、规则、激励与行为相互反馈，并存在明显时间延迟、政策阻力或二阶后果。
- 目标态明确但未来监管、规模、组织或外部依赖不确定，需要 Backcasting 与前向校验共同约束当前行动。

## 不适用场景

- 根因已定位、路径线性、单点可逆且能由一个失败测试闭合的 Bug，直接测试和修复，不构造系统干预卡。
- 只有一次异常、单期指标或相关性线索，尚不足以建立反馈关系。
- 产品目标、法域、生产授权或责任 Owner 未定；本方法不能替代这些前置确认。

## 读取后必须产出

- 区分事实、推断、待确认和系统边界；所有回路与关系保持为待验证模型。
- 对反馈问题显式给出强化环、平衡环、时间延迟和真正杠杆点；对未来问题给出多个情景、早期信号、复核条件、Owner 与可控性。
- 逐项保留任务明示的不可退让约束，只承诺一个含观察窗口、反馈、成功 / 失败信号、停止与回退的最小可逆干预。

## 1. 系统反馈模型

先描述行为随时间如何变化，再界定主体、边界、证据与遗漏视角。只保留会改变决策的关键变量，标明关系方向、强化环、平衡环、时间延迟和可能的政策阻力；无法回到日志、指标、流程、源码或 Owner 事实时，保持待确认。

强化环解释偏差为何自行放大；平衡环解释什么约束、反馈或止损机制会抑制偏差；时间延迟解释为什么局部改动看似有效、真实后果却晚到。杠杆点应改变反馈结构、信息流、责任或约束，不等于增加 guard、流程、会议或指标数量。

## 2. 战略前瞻与回溯

战略前瞻列出多个可能情景、关键不确定性、早期信号和复核条件，不把路线图写成预测。目标态和 Owner 确认后，Backcasting 才能反推差距、里程碑、前置条件及可控 / 部分可控 / 不可控因素。

反推完成后必须从当前状态向前校验：检查依赖、跳步、责任交接、证据门和退出条件。当前只选择能验证关键假设的最小试片，不因目标远大而提前搭建多区域、平台化或全量治理能力。

## 3. 最小可逆干预

```text
问题行为与时间范围：
系统边界、主体、证据状态与不可退让约束：
强化环 / 平衡环 / 时间延迟 / 待证假设：
可能情景、早期信号与复核条件：
目标态、Owner、可控性与前向校验：
最小可逆干预、观察窗口、反馈源：
成功 / 失败信号、停止与回退：
```

卡片没有改变干预位置、验证动作或停止决策时立即丢弃，不为完整而补图。一个干预不能同时检验多个核心机制；需要多项动作时，先选最能区分假设的一项，其余保持候选。

## 4. 确定性结构门

正式输出前，把系统干预卡写成一个 JSON 文档，通过 stdin 交给：

```bash
python3 senior-software-architect/scripts/check_system_intervention_card.py < card.json
```

- `mode=feedback` 校验问题、证据、强化环、平衡环、延迟、杠杆点和最小干预。
- `mode=backcasting` 校验问题、证据、至少两个情景、早期信号、复核条件、Owner、可控性、前向校验和最小干预；`mode=combined` 同时校验两组字段。
- `problem.non_negotiable_constraints` 必须逐项收集任务明示的唯一权威、授权、安全、可访问性、失败恢复和证据边界等约束，不得用 `N/A`、概括性“遵守红线”或遗漏代替。
- 退出码 `0` 时，以 `rendered_markdown` 作为回答骨架，不再摘要掉与当前 mode 有关的强化环、平衡环、延迟、可控性、Owner、观察窗口、信号、停止或回退字段。
- 退出码 `0` 只证明字段结构完整；`1` 表示结构缺失；`2` 表示输入不是合法 JSON。固定的 `proof_limit=structure_only` 和确定性转写不能证明因果成立、方案正确、已获授权或可生产准出。

线性局部 Bug 不调用该脚本。脚本只读取 stdin、只写 stdout，不访问网络、不写文件、不读取密钥。

## 来源边界

- 微信文章《系统思维：解决复杂问题的7种工具》只作为二次整理入口，不作为完整方法或有效性证据。
- Government Office for Science 的 Systems Thinking Toolkit 与 Futures Toolkit 用于校准系统边界、因果回路与 Backcasting。
- WHO 的 Causal Loop Diagrams 课程用于校准强化环、平衡环、时间延迟与杠杆点；OECD Strategic Foresight 用于校准多个可能未来。
- 察实、正名、审时、取舍、行验与知止只校准判断，不替代专业事实、测试、CR 或 Owner。
