# 东方幻想视觉设计

## 使用时机

当用户明确要求仙侠、玄幻、武侠或其他东方幻想方向，并需要设计或审查人物、服饰、建筑、兵器、器物、植物、药物、灵物或生物时，在通用方法之后读取。

## 不适用场景

- 不把“东方”“古风”“水墨”当成完成的设计方向。
- 不替代服制史、建筑史、兵器史、植物学、药学或图像学考证。
- 不用本专项发明小说正典、能力规则、人物命运或器物来历。
- 用户未要求东方幻想时，不把本专项的母题和形制套入通用设计。

## 读取后必须产出

- 当前对象的真实原型、结构或生态依据，以及无法核验的部分。
- 文化母题的含义、适用范围和禁用方式。
- 从真实原型到幻想变形的完整因果链。
- 可见的功能、代价、磨损、维护或历史痕迹。
- 对象分类、连续性锚点和反套路负面约束。

## 需要继续读取的 reference

- 通用五轴、对象专项和图像验收以 `visual-design-method.md` 为权威。
- 需要复核外部 Skill、制作文章、一手资料、许可或读取状态时，读取 `source-map.md`。
- 需要形成设计单时，按任务裁剪 `../assets/visual-design-sheet-template.md`。

## 一、证据与转译

### 1.1 证据优先级

按当前具体主张选证据，不以来源名气替代适配性：

1. 博物馆藏品、传统工艺记录、植物数据库、建筑遗产记录等一手对象资料。
2. 专题研究、馆藏图录、专业机构说明和可核验的制作记录。
3. 主创访谈、制作复盘和专业教学，用于理解设计过程，不作为唯一史实来源。
4. 外部 Skill 或工作流，只吸收可独立验证的抽象方法。
5. 搜索标签、流行印象和模型记忆只能提供检索词，不能支撑事实。

资料不足时，把结论标成待核验或文学虚构，不拼接成“传统上必然如此”。

### 1.2 主张分层

每个会影响对象身份、形制或文化含义的判断标成以下一层：

- **真实依据**：可回到具体实物、结构、生态或一手记录。
- **传统表达**：存在于特定时代、地域、媒介或图像传统，不外推为全部中国文化。
- **合理推演**：由已知结构、功能、环境和社会关系推出，仍可被新证据修正。
- **文学虚构**：为作品目标新增，并说明与真实原型的差异。

### 1.3 转译链

东方幻想变形遵循：

```text
真实原型
-> 结构与工艺
-> 文化母题及使用边界
-> 故事功能
-> 有限幻想变形
-> 可见代价、磨损与历史痕迹
```

幻想变形优先改变一个真正承载故事功能的结构、材料、尺度、生态关系或使用条件。每次改变都回答：为何存在、怎样运作、谁承担代价、日常如何维护、失败后留下什么痕迹。

## 二、共享视觉语言

跨人物、建筑、器物和生物只共享少量可变形语法：

- **材质语法**：资源从哪里来，怎样加工、维护、老化，并如何体现地域和阶层差异。
- **结构语法**：连接、层叠、承重、留空、开合、收束和轮廓怎样随对象功能变化。
- **母题语法**：纹样、自然形态、礼仪或历史记忆为何出现，在哪些对象和位置上才成立。

不要把同一颜色、纹样和发光效果铺满所有资产。共同语言用于说明它们属于同一世界；对象差异仍由身体、用途、场地、生态和经历决定。

## 三、对象专项

### 3.1 人物与服饰

- 先定时代或混合时代边界、地域、气候、身份、职业、礼仪和当场动作，再选择服装结构。
- 服装层次、领襟、袖型、腰部、下摆、鞋履、束发和携物必须支持身体活动与生活方式。
- 人物经历通过体态、手部、肤发状态、穿着习惯、修补和负重显现，不靠脸型模板判断德性或阵营。
- 借用戏曲、宗教、军旅或少数族群表达时，说明媒介与语境，不把舞台程式当日常服制。
- 长发、广袖、飘带和素袍不是仙侠人物的默认组件；使用时必须有身份、动作或环境理由。

### 3.2 建筑与环境

- 从选址、水源、地形、气候、材料供应和交通进入设计，再判断木构、砖石、夯土或幻想结构。
- 承重、连接、屋面、排水、防火、维护和扩建逻辑必须能支持尺度与使用。
- 以流线、门槛、视线、可达性、储存和仪式空间表达权力与秩序，不只放大体量。
- 炊烟、排水、货物、工具、修补、晾晒、牲畜、废弃物和后期占用让空间显出生活与历史。
- 悬浮、倒置、超大跨度或云上建筑必须有支撑机制、进出方式、资源来源、灾害风险和维护代价。

### 3.3 兵器与器物

- 先正名器类：剑不是刀，枪不是矛的无条件别名，法宝也不能用特效回避其物理载体。
- 检查器身、锋刃或工作面、脊与截面、茎或连接、护手、握持、配重、鞘装和悬挂之间的关系。
- 长度、重量、重心、刚柔、握法、使用空间和穿着共同决定动作；造型不能与使用方式互相否定。
- 工艺、装饰、铭文和材料应与制造者、使用者、资源和时代相称，并留下磨损、保养、修复和易手痕迹。
- 神异状态只沿已确认的能力、发动条件、代价、反制和次数出现；剑气、符光、悬浮或变形不是默认配置。

#### 3.3.1 神异、载文与纹样工器

只有上游已经确认器物的职事、能力、人器关系或历史边界时，才做视觉转译；本节不建立通用品阶、五行配色、器灵成长树或战技表。

先用四种证据镜片约束设计：

| 镜片 | 提取内容 | 不可外推 |
| --- | --- | --- |
| 神话与礼仪 | 职事、禁忌、人器关系和仪式语境 | 神名、传说和祭祀不自动变成器物能力 |
| 历史实物 | 器类、尺度、部件、载文方式、使用和修补痕迹 | 单件藏品不代表全部时代与地域 |
| 建筑营造 | 骨架、承力、层位、节点、接口、装拆和维护 | 不把斗拱、飞檐等建筑外形缩小贴到器物上 |
| 工器制作 | 材料、工具、成形、接合、修整、校准和失败痕迹 | 不把铸造、锻造、雕琢、书写和祭炼混成同一工序 |

再完成五层视觉转译：

1. **器类与职事**：正名为兵器、礼器、凭信、工具、容器、镇物或其他实际器类，说明谁在何种行动中使用。
2. **器骨与接合**：拆出工作、承力、感应、握持、保护、收纳和配套部分，说明连接、装拆、运输及失效节点。
3. **材料与成器**：把材料落实到部件、工序、表面、触感、弱点、维护和修复；没有证据时不伪造温度、配比和年代。
4. **灵机与行用**：只沿已确认规则说明力量来源、器身载体、运行路径、触发、维持、阻断、越限与余波；五行阴阳不直接等于固定颜色。
5. **状态与承续**：区分常态、预备、发动、维持、过载、受损、修复或重铸中实际需要的状态，并保留易手和历史改造留下的连续痕迹。

篆文、铭文、云纹、雷纹、如意纹及其他祥纹、符箓、印玺、符节、图箓、碑刻和阵图须先分型：

- **载文构件**：文字依附在剑、鼎、钟、甲胄、建筑或其他本体上。分别说明文字内容、书体或图式、载体、书写或铸刻方法、位置、可读者、磨损与后世误读；载文不自动具有法力。
- **纹样与文饰工艺**：云纹、雷纹、如意纹及其他祥纹先核对时代、地域、媒介与使用语境，再说明基本单元、组织方式、所在部位、载体工艺、使用资格、磨损和修补。纹样可以参与辨认、礼序或审美，但不自动成为文字、凭证、术式、祥瑞事实或神异能力。
- **凭证验合器**：印、玺、符、节、牌、券等以授信、授权、传令、验合或防伪为职事。检查成对或成套关系、保管与调用、验合动作、篡改痕迹、伪造门槛和失效后果，不用“认主”包揽权限。
- **术式媒介**：符箓、图箓、法印等只有在作品规则确认后才承载神异。说明纸、帛、木、金石或其他载体，书写、折叠、钤印、佩挂、张贴、焚化或布设动作，以及触发、耗尽、残留和回收状态。
- **空间型工器**：碑、界石、坛、阵眼或建筑构件需要同时检查场地、朝向、可达性、安装节点、人员流线、维护和破坏路径，不能只画一个孤立符号。

同一对象可以兼具多类身份，但逐项说明实际职事和接口；不要把“文字内容”“书体”“纹样母题与组织”“载体工艺”“权限凭证”和“神异能力”混为一件事。器灵只按上游已确认的无灵、有限响应、寄灵或独立主体关系转译，不默认从初醒升级到化形。

### 3.4 植物与药物

- 区分整株、药用部位、采收状态、干品、切片、炮制品和储存形态，不用药材图代替原植物。
- 叶序、叶形、根茎、花果、孢子或菌丝应与其生境、水分、光照、土壤、季节和生命周期互相解释。
- 药性进入视觉设计时，至少改变生长、采制、保存、剂量、交易、照料或生态中的一个真实环节。
- 珍稀来自繁殖、生境、采集风险、加工损耗或制度控制，不等于换色、发光和增加粒子。
- 无植物学或药学证据时，使用“虚构植物”或“参考某形态”，不声称真实功效。

### 3.5 生物、灵物与图像母题

- 先区分传统图像母题、文学身份和生物实体；图像中的组合特征不自动构成可信解剖。
- 骨骼、关节、肌肉、体表、感官、呼吸和保温结构必须支持体型、运动和栖息环境。
- 食性、繁殖、育幼、领地、迁徙、天敌、疾病及人与其关系形成当前故事所需的最小生态闭环。
- 角、翼、甲壳、触须、发光或多肢结构必须有身体媒介、功能、发育路径和运动代价。
- 神异能力需要触发条件、可见反馈、持续限制和恢复成本；传统象征只在作品确认后成为该个体的意义。

## 四、反套路负面约束

- 不用长发、广袖、云海、悬浮、背影和发光组成无身份差异的“仙气”。
- 不随机添加龙、凤、饕餮、云雷等纹样；先说明来源、对象、位置与使用资格。
- 不以更多颜色、宝石、粒子、材料和纹样表示更高稀有度或力量。
- 不以巨大建筑和空旷广场代替功能、人口、流线、维护与权力关系。
- 不把普通植物换色或发光后称为灵药。
- 不把普通动物拼上角、翼、鳞片和粒子后称为灵兽。
- 不用“古老、东方、水墨、神秘”之类标签替代可见结构、材质、环境和状态。

## 五、专项交付与停止条件

在通用设计单中额外写清：

```text
真实原型与证据层级：
传统表达及适用范围：
结构、工艺或生态约束：
故事功能：
幻想变形及必要性：
代价、维护、磨损与历史痕迹：
分类红线与反套路约束：
待核验项：
```

遇到以下情况停止扩写：

- 关键史实、器类、物种、药用或文化含义无法核验，却会决定设计方向。
- 正典没有确认能力、象征或历史，继续会替作者补写。
- 真实原型与幻想变形之间只剩风格词、装饰或特效，没有功能和代价。
- 当前单件设计已经足够，不再扩成门派、朝代或全世界视觉圣经。
