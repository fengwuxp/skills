# 人物视觉设计

## 使用时机

当任务需要把小说人物语义转成外形、体态、服饰、动作、关系表现、跨图身份锚点或阶段状态时读取。单张插图只做到当前画面够用；连续插图、阶段变化或群像再增加对应的一致性规格。

## 不适用场景

- 人物事实、性格、关系、选择与弧光由作者或 `novelist` 持有，本方法不补写。
- 正文中的人物塑造由 `novelist` 处理，不用绘画术语替代场景。
- 已确认设计的纯图片生成由 `imagegen` 执行。
- 用户未要求视觉设计时，不主动制作人物设定集。

## 需要继续读取的 reference

- 人物设计已经在当前范围内确认，用户要求实际生成、编辑、延展或验收人物图片时，读取 `character-rendering.md`。
- 通用五轴、材质、环境与图像验收以 `visual-design-method.md` 为权威；东方幻想与传统审美仍按 `SKILL.md` 路由读取。

## 一、责任与输入

视觉侧只接收人物语义，不接管人物正典。开始前冻结当前权威状态，按任务读取人物视觉交接卡中的故事阶段、稳定底色、当场关系与意图、知情边界、身体事实、经历痕迹、身份锚点、允许变化和禁止推断。

- 会改变人物身份、主体结构或当前主要动作的缺口，回交作者或 `novelist`。
- 不影响主方向的缺口保持未知，或给少量标明前提的视觉候选。
- 旧图与参考图只有实际加载并确认用途后，才能承担身份、结构、材质、动作或风格参考。
- 不把完整人物档案压进生成提示词，只传当前画面必须可见和必须保持的内容。

## 二、从人物语义到可观察证据

先按场景推演，再选择画面证据：

```text
人物底色与经历
+ 当场关系与具体意图
+ 时间、地点、身体、知情和资源
+ 刚刚发生的事件
-> 动作、姿态、目光、距离、物件、服饰状态和空间选择
```

每条承重语义都写成：

```text
语义事实 -> 当前场景 -> 可观察证据
-> 不可变锚点 / 可变状态 / 一次性效果
-> 验收条件与禁用捷径
```

具体意图回答“此刻想让对方做、感受或说出什么”，不等于给人物贴一种情绪。同一意图可以通过不同姿态、动作与距离实现；同一人物面对亲近者、下属、敌手或陌生人，也不应复用一套固定表情与姿势。

不得使用以下捷径：

- 从寡言、谨慎、善良、冷酷、坚毅等标签直接决定脸型、眼神、体型、肤色、颜色或服装。
- 用低眉、抱臂、黑衣、伤疤、华服等单一符号代替关系、选择和经历。
- 把观察者的第一印象写成人物本质。需要第一印象时，同时说明观察距离、关系与近看后由何种证据修正。

## 三、东方古典人物的形神与衣装

用户要求中国古典、古风、仙侠或传统服饰审美时，先确定采用的时代边界或混合时代原则、地域与气候、人物身份、当场行动、资源和礼制。馆藏只证明具体对象；不得把单件女俑、卷轴画、宫廷服饰或宗教造像外推成统一的“中国式人物”。

古典人物设计按“形、势、衣、神、境”推进：

1. **形**：先锁骨架、比例、脸部结构、发量与发际等身份事实；外形不承担德性判断。
2. **势**：用重心、步态、肩颈、手部、呼吸感、距离和当场动作表现人物如何处世。
3. **衣**：让装束包覆真实身体并支持活动，先成立穿着结构、材料重量和维护状态，再谈纹饰与飘逸。
4. **神**：将第一印象与近看后的修正同时落到可观察证据；“以形写神”不是用脸型为性格定论。
5. **境**：光线、视角、人与物的距离及留白共同组织观看，不用空白背景或文字说明冒充意境。

### 3.1 轮廓最低契约

去掉姓名、说明文字和颜色后，人物仍须通过以下信息被识别和比较：

- 头身比例、肩胯关系和身体重心；
- 发量、发际与发式外轮廓；
- 肩颈、肩袖和腰线的连接；
- 站姿、步态、惯用侧和动作词汇；
- 至少一项来自生活或阶段的稳定痕迹。

纯几何人形只能检查占位、画面比例或大致宽窄；缺少上述信息时，不得宣称人物轮廓、身份差异或古典气质已经通过。

### 3.2 衣装最低契约

一套可验收的服饰至少能辨认：领与襟、开合和系结、肩袖连接、腰部固定、上装与下装或袍裙结构、下摆层次、鞋履、携物接口，以及主要材料的厚薄、重量和垂坠。结构由行动、气候、身体、资源、身份与礼制共同决定。

- 纹饰沿真实部件、受力边界、织绣或镶嵌工艺组织，不覆盖结构缺失。
- 广袖、窄腰、飘带、层叠薄纱和长发都须有行动与环境理由，不把“女式”缩写成纤细、轻薄或繁饰。
- 同一人物换装时，衣服可以改变轮廓，但不得顺带改变骨架、体量、脸部结构与惯用侧。

### 3.3 发式与饰物

发式服从行动、身份、维护条件和阶段状态。簪负责单向插固，钗或叉形构件以双股固定，冠、巾、带各自承担束发或礼仪职能；所有构件都必须在头发上有可见连接，不作为悬浮珠宝堆叠。华丽只在人物拥有对应资源、场合和整理时间时成立。

### 3.4 媒介适配门禁

| 要验证的内容 | 最低有效证据 | 不能充当证据 |
| --- | --- | --- |
| 版面与相对尺度 | 线框、几何占位或网页布局 | 人物审美已经成立 |
| 人物轮廓差异 | 有真实头身、发式、肩袖与姿态信息的剪影或草图 | 同一种几何人形换颜色、加标签 |
| 脸、发、衣装和古典气韵 | 可看清人物结构的参考拼贴、概念草图或生成图 | CSS 色块、说明文字、调色板 |
| 材质、垂坠和完成画面 | 达到目标细节等级的实际图像 | 提示词、设计文案或低细节缩略图 |

网页可以承载比较与批注，但不能替代人物图像。审美预检若看不清脸部结构、发式连接、衣装结构和材料垂坠，结论只能是“无法验证”。

## 四、身份锚点与变化

只锁定少量跨图仍须保留的身份锚点：轮廓与比例、脸部结构、发量与发际、稳定身体特征、惯用侧或永久物件。锚点应能从已确认事实或已通过图片追溯，不为制造“主角感”增加。

变化分两层：

- **可变状态**：年龄、伤病、训练、疲劳、资源、关系、天气、妆发、衣着、清洁和修补造成的变化。
- **一次性效果**：当场光线、尘水、血迹、动作、镜头、临时携物和短暂情绪。

阶段变化沿真实事件留下证据：

```text
上一个已确认状态 -> 实际经历 -> 身体 / 资源 / 关系 / 衣着变化
-> 当前可见痕迹 -> 后续仍须继承的部分
```

年轻或驻颜不等于没有时间痕迹；变化可落在动作效率、旧伤规避、物件维护、衣物改制、资源取舍、注视顺序和与人保持距离的方式。更换服装不得顺带改变骨架、体量、脸部结构或惯用侧。

### 4.1 图片角色与效力

人物图片按三轴记录：图片角色说明被用来验证什么，制作轴说明图片是否完成视觉验收，采用轴说明哪些属性获得作者确认或正典效力。三轴不得互相替代。

| 图片角色 | 主要作用 | 不自动确认 |
| --- | --- | --- |
| 审美基准图 | 比较年龄感、气质、配色、造型密度和整体方向 | 具体脸型、体态、发式、衣制和饰物 |
| 身份锚图 | 锁定作者已确认的脸部结构、体态比例、发量发际和稳定身体特征 | 阶段服饰、临时动作和场景效果 |
| 服饰状态图 | 锁定特定阶段、行动、气候、资源和礼制下的穿着状态 | 人物终身衣柜或身份本质 |
| 场景表现图 | 表现具体关系、意图、动作、距离和环境 | 新人物事实、关系、能力或命运 |

一张图可以承担多个角色，但必须逐项声明。作者接受一张审美基准图时，只继承其明确采用的年龄感、气质、配色或其他属性；未确认的脸、身、发、衣仍是候选，不得称为身份锚点。

### 4.2 逐属性采用

需要归档、继续生成或建立跨图参考时，按任务裁剪记录：`属性 / 图片角色 / 采用、保留候选、拒绝或无法验证 / 可见证据 / 后续效力`。图片完整不等于全部属性被采用，图中随机饰物、身份暗示、衣装异常和未确认身体特征不自动进入后续设计或正典。

## 五、按用途停止

| 用途 | 最小交付 | 不默认增加 |
| --- | --- | --- |
| 单张插图 | 一张与当前确认范围匹配的全身人物图，加一个真实故事时刻 | 完整转面、表情表、全阶段设定 |
| 连续插图 | 锁定轮廓比例、脸部结构、发际、惯用侧和永久物件，再按需补视图 | 机械凑齐正侧背 |
| 表情与动作 | 用真实关系、具体意图和事件触发形成动作候选 | 固定“喜怒哀乐”表情格 |
| 长篇阶段变化 | 保留身份锚点，追踪年龄、伤病、资源、关系和服饰状态 | 只靠换装表示成长 |
| 群像 | 先比较轮廓、重心、动作词汇、距离和空间权力 | 先把所有人精修成相似面孔 |

服饰始终从当场行动、气候、身体限制、资源、身份与礼制反推。伤病至少通过一种行动限制和一种适应方式显影，例如步态与路线、惯用侧转移、开合方式、支撑物或衣物改制；不把伤病只画成伤疤或装饰。

## 六、生成交接与验收

设计经作者确认后，才把当前画面需要的图片角色、身份锚点、关系、动作、服饰与道具状态、允许变化、负面约束和可观察通过条件交给 `imagegen`。实际生成、局部编辑、整图重绘、逐属性采用和迭代上限按 `character-rendering.md` 执行。供应商参数、模型、凭据、额度和生成策略由执行能力决定；图片中未经确认的新细节仍是视觉候选。

生成回执与设计验收分开记录：

- **执行完成**：工具返回或产物落盘，只能进入“已生成待验收”。
- **设计通过**：人物结构、动作语义、衣装、材质、连续性和负面约束逐项通过，才进入“已验收图像”。
- **作者采用**：作者明确接受图片或其中的视觉细节，才允许把它作为后续任务的参考锚点。
- **正典写回**：人物身量、发式、衣制、器物关系或其他故事含义仍由作者 / `novelist` 按权威流程单独确认。

执行失败、额度不足、配置不可用或图片无法读取时，报告真实状态和停止原因；不得用 SVG、CSS、线框或提示词补写“已验收”，也不得自动把生成细节写回人物档案。

验收至少检查：

1. 跨年龄、服饰、视角和场景仍能认出同一人物。
2. 动作、目光、距离和空间选择来自当前关系与意图，不靠性格脸谱。
3. 身体、服饰、伤病、惯用侧与道具状态连续，变化有事件原因。
4. 未知项仍为未知，图片没有新增职业、身世、关系、能力或命运正典。
5. 去掉姓名、文案和颜色后，轮廓与动作仍能区分人物；衣装结构不靠纹饰、飘带或特效补足。
6. 每项“平凡、冷、热烈、古典、仙逸”等方向都能指回图片中的结构或行为；图片不可见的结论不由文案代证。

单图关键契约成立即停止；只有真实复用需求才增加转面、阶段稿或关系动作稿。静态规则和单次出图不能证明人物绘制能力提升，仍须用相同 runner/model 重复生成并独立盲评。
