# 器物成图与多视图连续性

## 使用时机

- 器物视觉设计单已标记为“已确认设计”，用户明确要求生成图片、多视图、器物设计单或展示图。
- 需要让正面、侧面、3/4 和结构细节图保持同一对象身份、结构、材质和状态。
- 需要复核成图偏差、限制重试并把已通过的四张图片确定性拼版。

## 不适用场景

- 视觉设计仍是候选，或对象类型、主结构、材质、状态尚未确认。
- 用户只要通用单图、改图或风格探索，没有器物设计契约与跨图连续性要求；直接使用 `imagegen`。
- 用户要求 CAD、制造图、真实正投影、毫米尺寸、公差或可直接交付 3D 建模的精确工程输入。
- 当前会话没有可用图片生成能力；不得用 SVG、HTML、占位图或文字承诺冒充成图。

## 读取后必须产出

- 成图门禁结论和当前可用生成能力。
- 四个视图共享的不变量与各视图必须可见项。
- 实际图片绝对路径、实际提示词或提示词集合、实际生成路径、逐图与跨图验收结果。
- 四图通过后的 `artifact-design-sheet.png`，或明确的失败项、工具限制、未验证限制和停止条件。

## 需要继续读取的 reference

- 对象的结构、材质、连续性或验收契约不完整时，读取 `visual-design-method.md` 对应章节。
- 仙侠、玄幻、武侠等东方幻想器物需要原型与文化边界时，读取 `eastern-fantasy.md`。
- 需要复核外部 Skill、文章、许可或工具能力来源时，读取 `source-map.md`。
- 需要形成或补全设计单时，裁剪 `../assets/visual-design-sheet-template.md`。

## 输入门禁

开始成图前必须从设计单取得：

```text
状态：已确认设计
对象类型与用途：
不可变锚点：
结构、比例和主要部件：
材质、工艺与当前状态：
尺度参照：
必须可见：
禁止新增与特效禁区：
输出用途：预览 / 项目资产
写入位置：
```

`视觉候选` 不授权图片生成。只有缺口会改变对象类型、主结构、材质、状态或视图任务时，才询问一个关键分叉；不机械补齐模板。

## 默认交付

```text
01-front.png
02-side.png
03-three-quarter.png
04-detail.png
artifact-design-sheet.png
artifact-beauty.png       # 可选
```

- 正面：检查轮廓、对称关系、正面连接和部件数量。
- 侧面：检查厚度、弧度、重心、截面趋势和前后关系。
- 3/4：身份锚图，综合展示体积、材质、工艺和当前状态。
- 结构细节：展示最关键的连接、握持、鞘装、工作面或发动媒介。
- 展示图只表现使用情境和氛围，不替代功能视图或成为正典依据。

## 生成循环

1. 预检设计状态、`imagegen` 可用性、输出用途和写入位置。
2. 编译四图共享不变量，以及每个视图必须显露的结构。
3. 通过 `imagegen` 先生成无文字、无水印、均匀光照、中性背景的 3/4 锚图。
4. 验收对象类型、轮廓、主结构、材质、工艺、尺度感和状态。承重偏差未关闭前不生成其余视图。
5. 以通过的 3/4 图作为身份参考，分别生成正面、侧面和结构细节图；不同视图使用不同任务，不用同一提示词的随机变体代替。
6. 逐图和跨图验收后，只修订失败视图，并明确只改变视角或错误部位。
7. 每张图最多一次针对性重修；再次失败就报告模型限制，不无限重试，也不降低设计标准。
8. 四图全部通过后才拼版。需要展示图时最后生成并单独验收。

## 交接规格

本 Skill 形成媒介中立任务，具体模型、参考图参数、尺寸和编辑语法由当前 `imagegen` 按真实能力决定：

```text
画面任务：
对象与数量：
共享不变量：
当前视图必须可见：
材质、工艺与状态：
中性背景与参考光线：
允许探索：
禁止新增：
不得出现文字、水印、结构遮挡和无依据特效：
可观察验收条件：
```

工具不支持参考图、编辑或所需尺寸时如实报告，不发明调用方式。

## 跨图验收

逐项检查：

- 对象类型与主要轮廓是否一致。
- 部件数量、连接关系、长宽厚比例和尺度参照是否一致。
- 材质、纹样、磨损、损伤、修复与神异状态是否继承。
- 正面、侧面和细节图是否真正增加结构信息，而不是重复 3/4 构图。
- 是否新增文字、水印、装饰、特效、能力暗示或故事事实。

图片漂亮但对象误认、主结构漂移或锚点冲突时不得通过。

## 确定性拼版

四张源图通过后，先把 `FVD_SKILL_ROOT` 解析为当前实际加载的 `fiction-visual-designer` Skill 目录，不依赖当前工作目录。先用当前 Python 执行 `python3 -c 'from PIL import Image'`；若失败，在 Codex Desktop 中调用 `codex_app__load_workspace_dependencies` 取得含 Pillow 的 Python 实际路径。不得硬编码缓存路径，也不得自动安装依赖。

```bash
FVD_PYTHON="/absolute/path/to/python-with-pillow"
FVD_SKILL_ROOT="/absolute/path/to/loaded/fiction-visual-designer"
"$FVD_PYTHON" "$FVD_SKILL_ROOT/scripts/compose-design-sheet.py" \
  --front 01-front.png \
  --side 02-side.png \
  --three-quarter 03-three-quarter.png \
  --detail 04-detail.png \
  --output artifact-design-sheet.png
```

源码仓库中的 Skill 根目录是仓库下的 `fiction-visual-designer/`；安装后则使用本次实际加载 `SKILL.md` 的所在目录。脚本只读取单张不超过 2500 万像素的 PNG、JPEG 或 WebP，按 `FRONT / SIDE / 3Q / DETAIL` 固定顺序等比缩放、居中并输出 1600x1600 PNG。它不重绘、不修图、不覆盖输入或既有输出，也不自动安装 Pillow。

## 失败与停止

| 失败 | 处理 |
| --- | --- |
| 设计未确认 | 停止生成，返回会改变成图方向的缺失确认项 |
| `imagegen` 不可用 | 返回任务包和工具阻塞，不伪造成图 |
| 3/4 锚图对象误认或主结构错误 | 一次最小修订；仍失败则停止其它视图 |
| 单个分视图漂移 | 只修订失败视图，保留已通过图片 |
| 跨图无法收敛 | 返回通过项、冲突项和模型限制，不拼成“已验收” |
| Pillow 不可用 | 保留四张源图，不安装依赖，不声称拼版完成 |
| 分辨率、遮挡或视角不足 | 标为无法验证并说明需要补什么 |
| CAD、制造或真实正投影要求 | 停止伪精确交付，说明所需工程输入和专业工具 |
