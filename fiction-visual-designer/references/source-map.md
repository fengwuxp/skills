# 小说视觉设计来源与吸收边界

## 使用时机

当需要复核本能力采用的外部 Skill、制作复盘、一手资料、许可状态、读取日期、适用范围或拒绝内容时读取。

## 不适用场景

- 不把本文件当作外部正文、图像、模板或运行时依赖。
- 不用来源列表代替对当前对象的一手考证。
- 不因列出来源就声称当前设计已经获得史实、植物学、药学或工程学证明。

## 读取后必须产出

- 对具体方法或事实主张的来源归因、证据层级和适用边界。
- 对许可、时效、读取范围和未核验内容的明确标注。
- 对已吸收方法与明确拒绝内容的区分。

## 需要继续读取的 reference

- 通用设计流程读取 `visual-design-method.md`。
- 东方幻想的证据分层与转译规则读取 `eastern-fantasy.md`。
- 已确认器物的多视图生成、连续性与拼版读取 `artifact-rendering.md`。
- 外部页面仅在任务需要复核且已获得联网授权时重新访问。

## 五、已吸收

- 先继承故事语义，再做视觉转译；视觉完整度不创造正典。
- 以叙事身份、结构功能、材质工艺、环境关系、状态连续性约束所有对象。
- 跨对象视觉体系只共享材质、结构和母题语法，不强制同色同纹。
- 人物先从故事阶段、当场关系与具体意图推演可观察证据，再以形、势、衣、神、境组织古典人物设计，用少量身份锚点、身体动作和服装状态保持连续性。
- 人物轮廓、衣装结构、脸发与材质分别设置最低信息契约；几何占位只验证版面，不能证明人物审美、古典气韵或绘制质量。
- 建筑从场地、结构、流线、秩序、生活和历史层成立。
- 兵器先正名器类，再检查结构、重量、握持、动作、维护和鞘装。
- 神异器物以神话职事、历史实物、建筑营造和工器制作四类证据约束器类、器骨、成器、灵机与承续，不把文化来源变成外形拼贴。
- 载文构件、纹样与文饰工艺、凭证验合器、术式媒介和空间型工器分别检查文字、母题与组织、载体、工艺、权限、接口、发动与损耗，不把篆文、云纹和符箓降为同一种发光纹样。
- 植物与药物区分整株、使用部位、生命周期、采制和储存状态。
- 生物与灵物以解剖、运动、生态和能力代价约束幻想变形。
- 东方幻想遵循“真实原型到有限变形再到可见代价”的转译链。
- 东方审美以形、纹、色、虚实、意境、文字与宗教图形、营造和造器的关系成立；传统名词必须回到媒介、部位、组织、工艺和证据边界，不形成固定元素包。
- 生成交接保持媒介中立，图片按对象、结构、材质、连续性、环境和视觉方向验收。
- 参考图反推只重建可见视觉关系，按空间骨架、动作与接触、光色材质和装饰细节排序，再将偏差归入观察遗漏、交接表达或模型执行。
- 已确认器物先生成并验收 3/4 身份锚图，再用锚图生成独立视图；功能设计单与展示图分离，四图通过后才确定性拼版。
