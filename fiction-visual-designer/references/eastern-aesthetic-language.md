# 东方审美与造物语言

## 使用时机

当东方幻想视觉任务明确要求传统纹饰、颜色、留白、意境、篆书或符箓、道家或道教视觉、古建筑、工艺与造器审美时，在 `visual-design-method.md` 和 `eastern-fantasy.md` 之后按需读取。

## 不适用场景

- 不把本文件当成跨时代、跨地域的“中国风”模板。
- 不替代书画史、服饰史、建筑史、宗教史、文字学、材料学或工艺考证。
- 不为普通视觉任务强加道家思想、道教图形、五行配色或吉祥寓意。
- 不提供现实宗教符式、仪轨、效力或可用于仿造文物的精确图样。

## 读取后必须产出

- 当前对象实际需要的审美关系，不机械填写全部维度。
- 每项传统表达的来源语境、媒介、位置、组织、工艺、作用与禁用方式。
- 形、纹、色、虚实和意境的可观察条件，而不是风格形容词。
- 道家思想、道教宗教图形、历史实物和文学虚构之间的边界。
- 古建筑或器物从结构、营造、使用到维护成立的设计链。

## 需要继续读取的 reference

- 通用五轴、对象结构和图像验收以 `visual-design-method.md` 为权威。
- 东方幻想的证据等级、对象分类和有限变形以 `eastern-fantasy.md` 为权威。
- 本文件涉及的馆藏、营造、色彩、书画和宗教图形来源读取 `source-map.md`；具体历史主张仍回到对象条目。
- 已确认器物进入多视图成图时读取 `artifact-rendering.md`。

## 一、关系先于元素

东方审美不是可直接调用的元素库。先写清对象、媒介、时代或混合时代边界、地域、身份、用途、观看距离和当前状态，再选择少量真正有作用的关系。

用以下契约代替“中国风、古雅、空灵、道韵、大师感”等完成式标签：

```text
主视觉命题：观者第一眼看见什么关系
形与势：主从、重心、方向、开合与节奏
纹饰：来源语境、单元、组织、部位、工艺与边界
颜色：材料基底、主辅关系、明度纯度冷暖与状态变化
虚实留白：留在何处、承载什么、怎样引导观看
意境链：人 / 物 / 空间 / 时间 / 天候 / 动作 / 未显之物
文字与宗教图形：类别、内容、语境、权限与虚构边界
营造或造器：结构、工序、接合、使用、维护与失效
禁用捷径：本任务最容易落入的套件与误读
```

每个对象只选一个主视觉命题，其他关系为其服务。无法说明某项细节改变了识别、使用、观看节奏或当前状态时，删去该细节。

## 二、形与势

先在无纹饰、低饱和或剪影状态下检查整体，再进入表面细节：

- **主从**：一个主形承担身份，其余部件构成承接、对照或收束；不能所有部位同时争夺视觉中心。
- **重心**：视觉重心与实际承重、握持、穿着、进入或停留关系相容。
- **开合**：入口、展开、收束和转折对应真实动作或观看次序，不把“开合”写成抽象赞语。
- **曲直**：曲线与直线分别承担运动、稳定、柔化、边界或受力；不因东方题材默认全部使用飘带和曲线。
- **疏密**：密处聚焦结构或信息，疏处让主形、动作或材质成立；疏密必须能在远、中、近至少一个观看尺度被辨认。
- **藏露**：遮挡、门洞、鞘装、层叠和转面用于延迟信息或保持层次，不用雾、暗角和裁切掩盖结构缺口。

通过条件不是“有气韵”，而是主形可辨、观看顺序明确、重心可信、细节密度不破坏结构。

## 三、纹饰语法

传统纹饰按以下字段建模，不从名称直接推出意义：

```text
对象与媒介：建筑构件 / 织物 / 漆器 / 金属 / 玉石 / 陶瓷 / 纸帛等
时代、地域与使用语境：已核验 / 候选参考 / 文学虚构
基本单元：实际可描述的形态，不只写“云纹”“祥纹”
组织方式：独立 / 边饰 / 带状连续 / 满地 / 团窠 / 适合某轮廓
所在部位：边、面、节点、开口、接合、受力或非受力区域
与结构线关系：顺势 / 截断 / 包边 / 对称 / 错位 / 转面承续
尺度、密度与留白：远中近哪个尺度可辨
载体工艺：织、绣、绘、刻、铸、錾、嵌、髹饰或其他已核验工艺
使用资格、磨损与修补：谁能用，怎样衰败和续补
含义等级：对象事实 / 特定传统表达 / 作者赋义 / 纯审美
禁止新增：不因此产生的身份、祥瑞、权限或能力
```

- 云纹、雷纹、回纹、如意纹、龙凤、花卉等名称只提供检索入口；不同年代、地域、媒介和组织方式不可互换。
- 纹饰先服从构件边界和制作方法。需要跨接缝、转面或受磨区域时，说明工艺怎样成立及使用后如何变化。
- 同一母题可以通过尺度、疏密、方向、断续和工艺形成家族关系，不要求跨对象复制同一图案。
- 现代原创纹样应写明借用的关系和变形幅度，不冒充复原纹样。

## 四、颜色关系

传统颜色先是材料、颜料、染料、釉、漆、氧化和光线共同形成的可见状态，不是脱离媒介的色名或固定色值。

```text
材料基底与表面：
颜色来源与工艺：本色 / 染 / 绘 / 髹 / 釉 / 锈蚀 / 神异状态
主色作用：建立对象或空间基调
辅色作用：区分层级、部件或远近
点色作用：提示动作、权限、读数或视觉焦点
底色与留色：承接其他颜色并保留材料身份
明度关系：最亮、最暗和中间层落在哪里
纯度关系：何处克制、何处集中，不设通用百分比
冷暖关系：受材料、环境光、季节和状态怎样改变
邻接与间隔：颜色如何交替、包边、分隔或跨构件承续
常态与状态色：变化从哪里开始、向何处过渡、在哪里停止
```

- 传统色名必须附时代、文献或具体对象来源；无法核验时改写为可观察的色相、明度、纯度、冷暖和材质光泽。
- 五色、五行、方位和德性等对应只在具体制度、文本、仪式或正典确认后使用，不生成通用配色表。
- 不用固定配色数量、面积百分比、蓝绿水墨或红黑金组合证明东方性。
- 图片生成时保留材质本色和颜色层级；神异光色不能覆盖结构、纹饰和边缘。

## 五、留白与意境

留白是被组织的未占区域，不必是白色，也不只存在于画面背景。它可以是素面、暗部、天空、水面、雾隙、门洞、构件间隙、未刻区域或动作前后的停顿。

为每处关键留白说明：

```text
位置与边界：
由哪些实体围合：
观看条件与尺度：
承载内容：空气 / 光 / 水 / 远景 / 动作路径 / 未显对象
作用：聚焦 / 分隔 / 延伸 / 框景 / 停顿 / 尺度对比 / 状态预留
失效方式：空洞 / 误留 / 被特效填满 / 遮住必要结构
```

意境不是纹样、配色或雾效的总和。用关系链说明它怎样出现：

```text
具体人或观察位置
-> 看见、听见或经过的对象
-> 空间开合与观看顺序
-> 时辰、季节、天气和光线
-> 当场动作与使用痕迹
-> 有意不显露的部分
-> 形成的感受与叙事作用
```

- “清、远、静、幽、苍、润、峻”等词必须分别对应空间距离、声音密度、材质湿度、轮廓力量、光线或人物行动。
- 满构图、强色和繁密纹饰也可以形成东方视觉；留白不是所有题材的必选项。
- 不自动把留白解释成道家、禅宗、人格修养或宇宙真理。

## 六、文字与道教图形

先分型，再决定是否进入视觉设计：

| 类型 | 设计检查 | 不得混同 |
| --- | --- | --- |
| 篆书或其他书体 | 可读文字、字形来源、书写者、载体、排布和时代 | 不等于符箓、纹样或天然具有古意 |
| 篆文、铭文与题额 | 文字内容、书体、位置、制作、可读者和磨损 | “篆文”不能替代实际内容和书体判断 |
| 篆刻、印章与玺印 | 印面、章法、刀法、印材、钤用与凭信语境 | 不自动成为法印、权限或防伪机制 |
| 云纹及其他纹样 | 基本单元、组织、部位、工艺与适用语境 | 不等于云篆、文字或神异媒介 |
| 云篆及符字、墨篆、丹书、符箓等称谓 | 分别核对具体宗教传统中的所指、职事、载体、书写与使用动作 | 不预设彼此同义，也不作为普通装饰字体或通用“道家符文” |
| 小说术式符文 | 作品自有语法、触发、权限、损耗和视觉状态 | 必须标为文学虚构，不冒充历史宗教图形 |

道家思想和道教宗教也必须分开：

- 道家思想可以作为取舍镜片，帮助检查自然条件、反向关系、虚实、克制和不强作；它不直接生成太极、八卦、云纹、符箓、黑白配色或任何固定造型。
- 道教视觉必须回到具体时代、地域、宫观、派别、斋醮、法器、符箓或信众实践。没有这些语境时，不复制现实神名、敕令、符式和宣称效力。
- 不能取得可靠字形或符式来源时，用原创非文字纹样，或建立明确标为文学虚构的术式系统；不得生成似是而非的“古篆字”。

## 七、古建筑与营造

古建筑设计按以下链条推进：

```text
场地、气候与水源
-> 建筑职事、使用者与制度
-> 总体布局、院落、轴线、路径与门槛
-> 尺度模数、开间和主要结构体系
-> 柱、梁、枋、檩、屋面、墙体、台基与节点
-> 排水、防火、防潮、通风、采光与维护
-> 木作、瓦作、砖石作、油漆作、彩画作等实际需要的工种
-> 色彩、纹饰、陈设、生活痕迹和历史叠加
```

- 中轴、对称、院落、曲折路径和框景都是条件化方法，不是所有中国建筑必须同时具有的特征。
- 屋顶等级、彩画、斗栱、雕饰和台基必须与建筑职事、地域、时代、资源和结构相称；不把宫殿语法默认赋给民居、道观、门派或小型工房。
- 建筑审美来自场地、群体组合、结构尺度、进入顺序、光影和使用共同作用，不靠飞檐、灯笼、云海和巨构体量。
- 建筑结构只能迁移为器物的骨架、层位、节点、接口和装拆逻辑；不得把屋顶、斗栱或门楼外形缩小粘贴到兵器、首饰或法宝上。

## 八、造器与精工

造器从“怎样被做成并长期使用”进入审美：

```text
器类与用途
-> 工作、承力、握持、保护、收纳和配套部分
-> 材料选择及其重量、韧性、触感和弱点
-> 成形、接合、修整、表面处理与校准
-> 人体接触、动作、声音、气味和使用环境
-> 磨损、清洁、保养、替换、修补与失效
-> 纹饰、载文和神异状态的有限进入
```

- 装饰位置服从成形、接合、受力、握持和磨损；不能在会破坏结构或使用的地方为了“华丽”增加浮雕、镂空和镶嵌。
- “大师作品感”由比例、转折、接合精度、材料顺性、触手部位、校准和修复便利共同证明。
- 材料名称必须转成可见的厚薄、边缘、纹理、光泽、声音和使用痕迹；稀有材料不自动比常见材料更高级。
- 神异只改变已确认的材料、结构、运行或状态，不让特效替代器骨和工艺。

## 九、跨对象合用

人物、服饰、建筑和器物共享的不是同一套图案，而是少量关系：

- 共享一种结构关系，例如外稳内动、先收后放或层层递进。
- 共享一种材料处理关系，例如素面承底、接合处显工、触手处见使用。
- 共享一种母题变形规则，例如同一基本单元在织、刻、铸、绘中按工艺改变。
- 共享一种颜色秩序，例如共同底色与不同对象的功能点色，而不是全员同色。
- 共享一种留白方式，例如在入口、工作面或视觉中心附近保留有具体用途的未占区域。

验收时遮去小纹样和文字：对象仍应通过轮廓、结构、材质、空间秩序和使用关系属于同一世界，同时保持自身器类和功能可辨。

## 十、停止与验收

出现以下情况停止增加传统元素：

- 只能说出文化名词，不能说明对象、时代、媒介、部位和工艺。
- 纹饰、色彩、留白或宗教图形没有改善对象识别、使用、观看节奏或状态表达。
- 具体符式、文字、建筑等级或工艺事实尚未核验，却会决定设计方向。
- 已确认结构足够成立，继续添加只会提高装饰密度。

最终按以下问题验收：

1. 去掉风格词后，是否仍有可见的形、色、纹、虚实和工艺关系？
2. 每种传统表达能否说明来源语境、媒介、部位、组织、工艺和禁用方式？
3. 颜色是否保留材料与层级，留白是否承担具体作用，意境是否由场景关系产生？
4. 篆书、载文、纹样、云篆、符箓和文学术式是否分型清楚？
5. 建筑是否能被进入、使用和维护，器物是否能被制造、握持和修复？
6. 删去一半装饰后若设计更清楚，就采用删减后的版本。
