# 通用叙事视觉设计方法

## 使用时机

当任务需要设计或审查人物外形、服饰、环境、建筑、兵器、器物、植物、药物、灵物、生物，建立跨对象视觉体系，延展同一对象的状态，或验收生成图片时读取。

## 不适用场景

- 小说正文、剧情、人物命运、器物来历和能力代价由 `novelist` 或作者裁决。
- 已确认设计的纯图片生成由 `imagegen` 执行。
- Web UI、浏览器应用和产品交互由 `ui-design-expert` 负责。
- 纯史实考证先回到一手资料，不用本方法替代领域研究。
- 用户只要求整理已确认设定时，不重新设计。

## 读取后必须产出

- 任务类型、权威来源、设定状态、必须保留、允许改变和未知项。
- 只覆盖当前对象所需的五轴设计、不可变锚点、可变状态和负面约束。
- 事实、传统表达、合理推演和文学虚构的边界。
- 当前状态对应的交付：视觉候选、生成交接规格、已生成待验收回执或图像验收结论。

## 需要继续读取的 reference

- 人物任务涉及语义交接、关系动作、跨图连续性、阶段变化或群像时，继续读取 `character-visual-design.md`。
- 用户明确要求仙侠、玄幻、武侠或其他东方幻想时，继续读取 `eastern-fantasy.md`。
- 需要核对外部方法、参考资料、许可证或读取状态时，读取 `source-map.md`。
- 需要形成可复用设计单时，按任务裁剪 `../assets/visual-design-sheet-template.md`。

## 按任务读取索引

| 任务 | 优先读取 | 跳过 |
| --- | --- | --- |
| 单个人物或服饰 | `character-visual-design.md`、`人物`、`服饰`、`连续性` | 无关建筑、植物和生物细节 |
| 建筑、环境或聚落 | `建筑与环境`、`视觉体系` | 无关人物身体细节 |
| 兵器、法宝或日用器物 | `兵器与器物`、`连续性` | 无关生物和植物细节 |
| 灵药、植物或药材 | `植物与药物`、`连续性` | 无关服饰和建筑细节 |
| 灵物、怪物或灵兽 | `生物与灵物`、`环境与关系` | 无关服饰细节 |
| 多对象共享视觉语言 | `视觉体系` 后按对象读取 | 不为每件资产独立发明风格 |
| 参考图关系反推 | `参考图关系反推`、当前对象专项 | 不恢复原 Prompt，不自动生成或编辑 |
| 生成图片验收 | `图像验收`、当前对象专项 | 不重新设计已确认故事语义 |

## 一、权威与任务类型

先判断当前输入是什么，而不是先构思画面：

| 输入状态 | 处理 |
| --- | --- |
| 已确认正典 | 完整继承，不为视觉效果改写 |
| 工作骨架或视觉方向 | 可以具体化，但新增含义保持候选 |
| 作者提案 | 提供可比较方向与推荐，不当作定案 |
| 未知或待确认 | 只有影响主方向时提问，其余保留空位 |
| 旧稿或参考图 | 只提取可迁移视觉功能，不自动继承事实 |

任务类型决定交付深度：

- **视觉体系**：多个对象需要共享识别语言时，先稳定少量共性，再保留对象差异。
- **单件设计**：只完成当前对象，不为完整感扩写整部作品的视觉圣经。
- **状态延展**：继承身份锚点，说明变化原因、过程和可见结果。
- **现有设计审查**：以当前权威和目标为准，先给影响最大的偏差。
- **生成结果验收**：验证图片是否实现契约，不重新定义契约。

参考图只有在本轮实际加载、可见并完成检查后，才能作为设计证据。先标明它承担的是对象身份、轮廓、结构、材质、纹样、状态或构图中的哪一种作用；无法加载时标为不可用，不得声称已向用户展示，也不得从文件名、缩略图或搜索摘要推断其内容。

### 1.1 参考图关系反推

参考图关系反推用于把当前可见图像中让画面成立的关系，转成可审查、可修改、可交给 `imagegen` 适配的媒介中立规格。它遵循：

```text
可见事实 -> 关系建模 -> 优先级 -> 生成交接 -> 返图归因
```

它不恢复原作者实际写过的 Prompt，不承诺 1:1 复刻，也不从画面猜人物身份、品牌、相机型号、不可见区域或准确文化出处。真人参考还要确认来源和使用边界；无法确认时只分析不涉及身份识别的视觉关系。

按以下层级读取并压缩，统一使用观者坐标描述画面左、右、上、下：

1. **空间骨架**：真实画幅、机位、焦段感、主体位置与占比、重心、裁切、倾斜、对角线、前中后景和主体可见窗口；人物任务再细化脸部窗口。
2. **动作与接触**：记录对象怎样连接、接触、遮挡和承重；人物任务再区分头部朝向、脸部朝向、虹膜方向、视线目标、肢体从哪里进入以及手和道具怎样接触。
3. **光色材质**：区分固有色、主光、环境光、曝光、后期质感和材质反应；色卡只表达环境基底、结构暗色、高光与小比例强调色等语义角色，不承诺像素锁色或无依据的精确比例。
4. **装饰细节**：只保留影响身份、轮廓、结构或视觉节奏的装饰，其余允许生成器探索。

默认关系优先级为：`空间骨架 > 动作与接触 > 光色材质 > 装饰细节`。具体任务可以调整，但必须说明证据；不要同时锁死脸、眼、肩、手臂、手掌、手指、道具和所有装饰，使局部约束互相竞争。交付至少包含：

- 可见事实与推断禁区。
- 空间骨架、视线目标、接触与遮挡关系。
- 必须保留、允许探索和负面约束。
- 可选语义色卡及其角色关系。
- 媒介中立生成交接和可观察验收条件。

用户只要求反推时，不调用生成或编辑能力。用户明确要求返图或校准后，按同一关系层级比较结果，并把偏差归入 `观察遗漏 / 交接表达 / 模型执行`：未观察到的关系回到视觉分析；已观察但位置靠后、表达含糊或相互竞争的关系回到生成交接；交接已经明确而模型仍简化或漂移时记录实际工具限制。只修最早失败层，不通过随机抽图、堆叠形容词或连续追加负面词掩盖根因。

## 二、通用五轴

### 2.1 叙事身份

回答：对象是谁、属于谁、为谁所用、进入什么行动、应让读者先认出什么。

最低要求：

- 区分对象自身身份、当前使用者状态和观察者可能产生的印象。
- 不把造型设计自动升格为性格、本质、阵营善恶、神秘身世或主题结论。
- 识别性来自少量稳定锚点，不靠每处细节都承担象征。

### 2.2 结构与功能

回答：对象由哪些承重部分构成，怎样活动、握持、穿着、使用、生长或移动，在哪些条件下失效。

最低要求：

- 结构能够支持主要动作与使用环境。
- 重要比例、连接、开合、受力、活动范围或生长关系可以被复核。
- 幻想结构可以违反日常经验，但必须说明作品内的支撑条件、限制与可见后果。

### 2.3 材质与工艺

回答：材料从何而来，怎样加工、连接、表面处理、维护、衰败和修复。

最低要求：

- 材质差异通过光泽、纹理、边缘、厚度、重量感和磨损显现，不只写材料名称。
- 工艺与身份、资源、地域和使用频率相称。
- 特殊材料说明它改变的结构或使用条件，不把昂贵、稀有等同于堆装饰。

### 2.4 环境与关系

回答：气候、地形、生态、制度、阶层、职业、仪式和使用者怎样改变对象，对象又怎样影响周围生活。

最低要求：

- 环境留下适应、维护、污染、磨损、修补、储存或交通痕迹。
- 重要对象进入真实关系：谁能拥有、制造、照料、进入、使用、交换或破坏。
- 不把对象设计成脱离生产、生活和行动的陈列品，除非故事确认其本来就是陈列或祭祀对象。

### 2.5 状态与连续性

回答：什么始终可辨，什么随时间、场景、身体、所有权和使用而变，变化怎样留下痕迹。

最低要求：

- 把身份锚点、当前状态和一次性效果分开。
- 只有实际发生的使用、损伤、修复、成长或改装才能改变状态。
- 跨图、跨场景和跨时期的变化能回到原因，不靠每次重新描述维持一致性。

## 三、视觉体系

多个对象共享语言时，只建立会真正复用的三类共性：

1. **材质语法**：常用材料、表面处理、维护方式及阶层差异。
2. **结构语法**：比例、连接、层叠、开合、轮廓和留空方式。
3. **母题语法**：来源明确、与职责或历史有关的少量形态与纹样关系。

为每类共性写清：

- 不变量：跨对象仍能识别的部分。
- 变化轴：人物、建筑、器物、生物怎样按功能改变表达。
- 禁用方式：哪些套用会损害功能、时代、身份或辨识度。

视觉体系不要求全体使用同一颜色、纹样、轮廓或材质。共性应让对象属于同一世界，差异应让对象仍然是自己。

## 四、对象专项

### 4.1 人物

- 人物事实、关系、选择和弧光先由作者或 `novelist` 确认；需要语义交接、关系动作、跨图或跨阶段设计时按 `character-visual-design.md` 执行。
- **身份锚点**：脸部结构、体态、比例、发量与发际、身体特征、惯用侧或固定物件中选择少量稳定项。
- **轮廓与比例**：先检查远距离轮廓和身体重心，再进入五官、纹样与小配件。
- **身体与动作**：年龄、职业、训练、伤病、疲劳和情绪通过站姿、步态、手部使用和动作范围显现。
- **可变状态**：妆发、衣着、清洁、伤势、天气和阶段情绪可以变化，不覆盖身份锚点。
- **视图**：需要跨图复用时提供正、侧、背或局部结构说明；视图服务连续性，不机械凑齐。

不得从单一外貌直接推导人格、德性、性取向、阶层本质或命运，也不以脸型、体型和肤色模板代替人物生活。

### 4.2 服饰

- 先定穿着者当场任务、气候、身体限制、资源、身份和礼仪，再定层次与装饰。
- 检查领、襟、袖、腰、下摆、开衩、系结、鞋履和携物怎样共同支持动作。
- 材料体现重量、保暖、透气、防护、吸水、耐磨、声音和维护成本。
- 服装可以只承担审美与生活质感，不把每件衣饰都强迫变成身份线索、象征或伏笔。
- 状态至少区分整洁、日常使用、恶劣环境、损伤和修补中实际需要的部分。

### 4.3 建筑与环境

- **场地**：地形、水源、风、日照、灾害和对外联系怎样决定选址。
- **结构**：承重、跨度、连接、屋面、排水、防火、防潮和材料供应怎样成立。
- **流线**：谁从哪里进入、停留、工作、储存、撤离和被限制。
- **秩序**：礼仪、权力、职业和安全如何通过轴线、门槛、尺度、视线与可达性显现。
- **生活**：炊烟、排水、工具、货物、废弃物、修补、晾晒、牲畜和声音留下被使用的痕迹。
- **时间**：扩建、灾害、改制、占用和修缮形成历史层，不把建筑冻结在落成瞬间。

环境图需要服务叙事时，构图还应回答人物从哪里来、要去哪里、什么遮挡或吸引视线，以及空间怎样改变行动。

### 4.4 兵器与器物

先正名对象类型，再检查：

- 工作部、受力部、握持部、连接部、保护部、收纳或鞘装怎样组成。
- 长度、重量、重心、硬度、韧性、刃口或工作面怎样改变动作。
- 使用者的身体、训练、惯用侧、衣着和空间是否支持其使用。
- 制造、维护、磨损、缺口、变形、修补和所有权变化是否留下连续痕迹。
- 法宝或特殊器物的视觉变化只能沿已确认的发动条件、代价、次数、反制和状态出现。

设计图按需要给出整体比例、正侧视、截面、连接、握持、鞘装和状态局部，不用大段特效遮住结构。

#### 4.4.1 名实、分层与最小修订

“大气”“古雅”“女性持用”“大师作品”等方向词只是待证明的主张，必须先转成可观察条件：

```text
方向词 -> 比例 / 轮廓 / 握持 / 接合 / 材质 / 表面 / 留白等可见证据 -> 禁用捷径
```

- 大气可由稳定尺度、完整长线、宽窄关系和留白成立，不等于放大所有部件或增加装饰。
- 女性持用先检查具体使用者的手型、握法、重心、动作和线条关系，不默认纤细、花形、宝石或柔弱。
- 大师作品感优先来自比例控制、部件过渡、接合精度、材料处理和维护细节，不来自昂贵材料或纹样数量。

按当前任务只推进必要层级：

```text
器类与用途 -> 轮廓比例 -> 部件与接合 -> 材质与表面 -> 载文与纹样 -> 状态与神异 -> 成图
```

作者已确认的层级保持为不变量，除非明确重开。反馈涉及多个层级时，先修最早失败层，不用后层装饰遮盖前层问题。每轮修订先形成最小差异契约：

```text
当前锁定层：
必须保留：
本轮只改变：
可观察通过条件：
禁止顺带改变：
失败时退回的层级：
```

### 4.5 植物与药物

- 明确整株形态及根、茎、叶、花、果、种子、菌丝或孢子中实际存在的部分。
- 生境、季节、水分、光照、土壤、海拔、共生与竞争关系必须能够解释形态。
- 区分活体、适采、过早、过熟、采后、运输、加工、炮制、储存和腐败中故事需要的状态。
- 说明使用部位与整株关系，不把药材切片、干品或炮制品误画成原植物。
- 幻想药性要改变生长、采制、交易、照料或生态中的至少一个真实环节，不能只有颜色和光效。

### 4.6 生物与灵物

- 骨骼、肌肉、关节、体表、感官、呼吸、保温和体型支持其主要运动与环境。
- 食性、捕猎或取食、栖息、繁殖、育幼、迁徙、天敌与疾病形成足够当前故事使用的生态闭环。
- 异常肢体、角、翼、甲壳、触须或发光结构必须有功能、发育和运动代价。
- 神异能力说明身体媒介、触发条件、持续时间、可见反馈和恢复成本。
- 人与其关系可以是捕食、驯养、贸易、敬畏、竞争或互利；没有故事依据时不自动写成伙伴、神兽血脉或守护神。

## 五、连续性设计

为需要复用的对象建立三层状态：

```text
不可变锚点：丢失后会变成另一个对象的特征
可变状态：由年龄、时间、场景、使用、伤病、所有权或环境导致
一次性效果：光、尘、水、血、姿态、镜头和临时附着物
```

状态延展遵循：

```text
上一个已确认状态
-> 实际发生的事件或使用
-> 结构、材质、身体或关系变化
-> 新状态
-> 后续仍须继承的痕迹
```

不要用固定颜色、固定姿势或完整复制所有细节维持一致性。真正连续的是身份、结构、经历与可追踪变化。

## 六、生成交接

只有设计确认后，才交付媒介中立规格：

- 主体与对象数量、相互关系和画面任务。
- 必须可见的身份锚点、结构、材质与当前状态。
- 构图、视角、景别、动作、环境和光线的功能。
- 可变化项及允许生成器探索的范围。
- 禁止对象误认、结构漂移、无依据新增和特效遮挡的负面约束。
- 验收时能观察的通过条件。
- 同一对象需要多视图时，先生成并验收一个能暴露体积、结构、材质与状态的锚图，再以通过图为参考生成其余视图；每个失败视图只作一次最小定向修订，仍失败则报告工具限制，不把冲突结果标为已验收。

供应商语法、模型参数、种子和调用方式由 `imagegen` 决定，不写入通用设计权威。

## 七、图像验收

按以下顺序检查，不先评价“好不好看”：

1. **对象识别**：类型、数量、身份与主要关系是否正确。
2. **结构功能**：比例、连接、受力、动作、生长或运动是否实现设计。
3. **材质工艺**：材料外观、厚度、边缘、重量感、表面处理和磨损是否可信。
4. **状态连续性**：不可变锚点是否保留，变化是否来自已确认原因。
5. **环境关系**：空间、气候、生态、生活和人物行动是否互相支持。
6. **视觉方向**：构图、色彩、光线、母题和情绪是否服务当前任务。

验收结论只使用：

- **通过**：关键契约全部可见且无承重冲突。
- **需修订**：指出影响最大的偏差、保留项和下一次生成的最小修正。
- **无法验证**：图片遮挡、分辨率、视角或输入证据不足，说明需要补什么。

把问题归因到正确层级：设计契约缺失由视觉设计补；生成结果偏离由生成交接修正；模型做不到则报告工具限制；故事语义冲突回交 `novelist` 或作者。

定向修订时沿用差异契约：保留已通过层，只改失败层，并用同一组可观察条件复验；不得重写整套方向后让已确认部分随之漂移。

## 八、停止与克制

- 正典冲突未决时不靠造型选择替作者裁决。
- 证据无法取得时不声称史实、传统或唯一正确形制。
- 单件对象能解决时不建立完整视觉体系。
- 已确认设计足够生成时不继续增加装饰、变体和设定。
- 用户只要探索时不强制推荐、确认、生成或写回。
