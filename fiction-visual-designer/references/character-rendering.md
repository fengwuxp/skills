# 人物成图与定向修订

## 使用时机

人物视觉设计已经在当前图片角色所需范围内获得确认，用户明确要求生成、编辑、延展或验收人物审美基准图、身份锚图、服饰状态图或场景表现图时读取。

## 不适用场景

- 人物事实、关系、选择和弧光仍由作者或 `novelist` 持有。
- 当前只是文字造型候选，或会改变人物身份、主轮廓、主要衣装结构和当场行动的分叉尚未确认。
- 无设计契约的普通单图直接交给 `imagegen`；本方法不为纯生成请求补人物正典。
- 当前没有可用图片生成能力时，不用 SVG、CSS、网页线框、占位图或提示词冒充成图。

## 读取后必须产出

- 成图门禁、当前图片角色和已确认范围。
- 媒介中立的成图或编辑任务包，以及 `imagegen` 的真实执行回执。
- 实际图片路径、逐属性采用矩阵、验收结论和必要的最小修订。
- 一次定向修订后仍失败时的工具限制与停止结论。

## 需要继续读取的 reference

- 图片角色、人物外貌、衣装、身份锚点和阶段连续性以 `character-visual-design.md` 为权威。
- 通用五轴、材质、环境和图像验收以 `visual-design-method.md` 为权威。
- 仙侠、玄幻、武侠或传统人物审美按任务读取 `eastern-fantasy.md` 与 `eastern-aesthetic-language.md`。
- 外部参考图、来源和许可需要复核时读取 `source-map.md`。

## 一、输入门禁

生成前只冻结当前图片角色需要的内容：

```text
设计状态：已确认设计
图片角色：审美基准图 / 身份锚图 / 服饰状态图 / 场景表现图
适用人物、阶段、场景与用途：
已确认并必须保留的属性：
允许探索与仍未知的属性：
当前参考图及其实际作用：
本轮只改变：
禁止顺带改变与禁止新增：
可观察验收条件：
输出用途与写入位置：
```

- “已确认设计”只对当前图片角色和已列属性生效，不要求人物全部外貌与服饰成为正典。
- 参考图必须在本轮实际可见，并说明它承担身份、审美、服饰、动作、材质或构图中的哪一项作用。
- 作者只采纳年龄感、气质或配色时，当前图仍是审美基准，不得因整图可见而把脸、身、发、衣锁成身份锚点。

### 1.1 参考图关系编译

人物参考图先统一观者坐标，再分别记录头部朝向、脸部朝向、虹膜方向、视线目标和眼睑 / 嘴唇状态，不用“侧脸”“看左边”“有情绪”等短标签合并不同关系。继续记录手、道具、接触、遮挡、支撑和肢体连接；人物身份、性格、品牌、设备、不可见身体与文化出处没有权威证据时保持未知。

生成交接先锁空间骨架和脸部可见窗口，再锁视线、动作与接触，然后处理光色材质，最后保留必要装饰。允许生成器自然组织手指角度、微表情和非承重装饰，但不得改变已确认身份锚点、动作语义或主体关系。色卡只描述主色、结构暗色、高光和强调色的语义作用；没有可靠提取方法时不填写精确百分比或像素色值。

返图比较先判断关系是否保住，再评价细节和审美。偏差按 `观察遗漏 / 交接表达 / 模型执行` 归因，并沿用一次最小定向修订预算；不通过随机抽图、换窗口或重复生成把偶然命中包装成通过。

## 二、首图与锚定顺序

### 2.1 审美基准图

需要先判断人物整体方向时，生成一张中性背景、结构可读、四分之三全身图；保持人物数量单一，避免未确认兵器、法宝、身份徽记和复杂场景抢占判断。

审美基准图优先暴露年龄感、体态轮廓、发式外轮廓、衣装结构、材料垂坠、姿态和配色秩序。它可以被作者采用为后续方向，但不自动提供跨图身份约束。

### 2.2 身份锚图

只有作者已经逐项接受少量身份锚点时，才把图片角色标为身份锚图。生成时必须保留已确认的脸部结构、体态比例、发量发际、稳定身体特征、惯用侧或永久物件；阶段服饰和一次性动作不得反向成为永久身份。

### 2.3 服饰与场景延展

服饰状态图从具体阶段、行动、气候、身体、资源、身份和礼制延展；场景表现图从关系、具体意图、动作、距离和空间选择延展。二者需要人物连续性时引用已经通过的身份锚图，不用审美基准图中的未确认脸、身、发、衣维持一致性。

## 三、生成循环

1. `fiction-visual-designer` 编译主体、图片角色、必须可见、必须保留、只改变、允许探索、禁止新增和可观察验收条件。
2. `imagegen` 选择真实可用的模型、参考图或编辑方式，持有提示词语法、参数、凭据、额度与执行失败状态。
3. 工具返回或文件落盘后只记录为“已生成待验收”，同时保留实际路径和足以复现或诊断的执行回执。
4. 先检查人物、年龄、身体与主轮廓，再检查衣装结构、发饰连接、材质、动作关系、配色和生成瑕疵。
5. 用逐属性采用矩阵记录结果；未确认属性不能由图片成功生成自动升级。
6. 图片存在可修订偏差且工具支持时，使用这张人物图唯一的一次定向修订预算；修订后按同一矩阵复验。
7. 关键契约通过即停止。一次定向修订后仍漂移、工具不支持或图片不可验证时，报告限制并停止。

## 四、逐属性采用矩阵

每张图按任务裁剪记录：

| 图片 ID 或路径 | 属性 | 图片角色 | 结论 | 可见证据 | 后续效力 |
| --- | --- | --- | --- | --- | --- |
| 当前图片 | 年龄感、整体气质、配色、轮廓、脸、体态、发式、衣制、饰物或动作中的当前承重项 | 当前声明的图片角色 | 采用 / 保留候选 / 拒绝 / 无法验证 | 图片中实际可见内容 | 可作为后续约束 / 不得继承 / 需要补图或确认 |

- “作者采用”必须落到具体属性；没有逐项证据时只采用作者明确说出的范围。
- 采用轴独立于整图制作轴；作者可以先采用年龄感、气质或配色，同时把整图保持为“需修订”。
- 同一图片可以承担多个角色，但每个角色分别记录采用范围，不用整图状态覆盖属性状态。
- 图片中的随机饰物、衣缘异常、错误文字、身份暗示和未确认身体特征优先标为拒绝或候选，不进入后续锚点。

## 五、局部编辑与整图重绘

先修最早失败层，不以表面修补掩盖主结构问题：

| 失败范围 | 默认动作 |
| --- | --- |
| 年龄、脸、骨架、主轮廓、主要衣装结构、全身姿态或主体关系错误 | 带已通过项重新生成 |
| 局部饰物、衣缘、单处纹样、手部或小范围生成瑕疵 | 工具支持时优先局部编辑 |
| 多个局部问题共同改变衣装结构或全身动作 | 重新生成，除非工具能可靠联合编辑且不破坏已通过项 |
| 工具没有编辑、参考图或遮罩能力 | 使用同一最小差异契约重新生成一次，不发明工具能力 |

局部编辑任务包增加：源图、编辑区域或遮罩、边缘过渡、必须保留、只改变、禁止新增和复验条件。遮罩外保持只是一项执行约束，不把未确认的脸、身、发、衣升级为作者采用或身份锚点。整图重绘任务包明确锁定已通过的年龄感、身份锚点、配色、材质或构图，不用重写整套方向制造新漂移。

每张人物图默认只有一次定向修订总预算，不把多个失败层拆成多次重试。再次失败不改成“基本通过”，不追加随机抽图，不为了迁就模型降低人物、衣装和正典标准。

## 六、验收与停止

验收结论沿用 `通过 / 需修订 / 无法验证`，并同时给出：图片 ID 或路径、图片角色、逐属性采用矩阵、修订预算、已通过项、承重偏差、工具限制和下一状态。`需修订` 或 `无法验证` 时制作状态保持“已生成待验收”，只有当前图片角色的关键契约通过后才进入“已验收图像”。多图逐张记录，不共享制作状态和修订预算。

出现以下任一条件即停止：

- 当前图片角色所需关键契约已经通过。
- 这张人物图的一次定向修订总预算已经用完，仍发生身份、衣装、动作或无依据新增漂移。
- 当前工具无法执行所需编辑、参考继承或分辨率，继续只会随机重绘。
- 图片被遮挡、裁切、分辨率不足或不可读取，无法完成可观察验收。
- 继续需要作者确认新的身份锚点、主要衣装结构、关系意图或正典事实。

单次文本检查、静态 fixture 和一组成功图片都不能证明人物成图能力已经提升；准入仍需同一 runner/model 的重复 baseline/candidate 生成与独立盲评。
