# 视觉方向与东方审美

## 使用时机

当任务需要建立新的视觉方向、比较设计风格、学习参考页面或截图，或用户明确要求东方审美、中国文化、器物、展陈、传统品牌等 Web 表达时读取。东方审美不是国风皮肤，只在真实产品、内容和品牌证据支持时使用。

## 不适用场景

- 局部功能应继承现有设计系统，没有重设计授权。
- 用户只要文化、美学或历史研究报告，不涉及界面设计。
- 用传统概念替代产品事实、可访问性标准或浏览器验证。

## 读取后必须产出

- 产品情境、真实资产和所选视觉方向的因果关系。
- 可落到层级、排版、色彩、空间、材质、图像和动效的变量。
- 参考设计任务先给来源模式、观察、推断、待确认、来源归因、可采用轴和不采用项。
- 明确不用什么、为什么不用，以及响应式、内容和可访问性验证。

## 需要继续读取的 reference

- 基础规则读 `design-foundations.md`。
- 页面结构与状态读 `design-and-review-workflow.md`。
- 经典镜片的现代工程转译与证据边界复核 `source-map.md`，需要古籍训诂时转 `hanzi-philology`。

## 一、先按情境选风格

| 方向 | 适合 | 表达重点 | 常见误用 |
| --- | --- | --- | --- |
| 克制任务型 | 运营、财务、CRM、审批 | 扫描、比较、密度、熟悉操作、明确状态 | 营销大标题、卡片套卡片、装饰性首屏 |
| 安静产品型 | 通用 SaaS、协作、设置 | 清楚层级、稳定 tokens、少量品牌细节 | 全页面同色、过度圆角和留白 |
| 编辑阅读型 | 文档、研究、媒体、知识 | 排版、目录、引用、连续阅读、内容节奏 | 正文展示字号、长段居中、装饰压过内容 |
| 商品目录型 | 电商、器物、作品与地点 | 真实对象、比较、规格、信任与行动 | 氛围图替代可检查对象、信息藏在轮播 |
| 品牌叙事型 | 发布、文化机构、目的地 | 真实资产、叙事节奏、识别度和转化证据 | 把视觉冲击当价值证明 |
| 沉浸媒介型 | 游戏、互动展陈、视听体验 | 媒介质量、空间关系、动效和参与 | 牺牲加载、输入、减弱动效和退出路径 |

视觉方向可以组合，但主方向只有一个；每个偏离既有系统的决定都要回指受众、任务、内容或品牌资产。

### 风格名词的正交使用

风格名只作检索坐标，先正名它究竟描述布局、页面目标、数据任务、视觉语言、交互方式还是横切约束，再决定能否组合。不得把不同类型的词放进一个互斥单选，也不得用风格名替代产品情境、信息结构、真实内容和验证。

最小风格语义卡：

```text
风格名 / 类型：
目标用户与页面任务：
可观察变量：层级、排版、色彩、空间、图像、动效中的哪些值会改变
可组合方向：
禁配义：不能被误写成什么
验证：真实内容、关键状态、目标视口、任务与可访问性证据
```

以下名词只作为精选检索索引，不是完整风格目录或推荐排名：

| 名词 | 类型与适用 | 应落到的变量 | 禁配义与停止线 |
| --- | --- | --- | --- |
| `Bento Box Grid` | 布局；多功能、多信息模块的分组 | 非均匀网格、跨列、组间层级、响应式重排 | 不等于所有内容卡片化；出现卡片套卡片或扫读路径破碎时停止 |
| `Minimalism & Swiss Style` | 视觉秩序；专业工具、文档和研究内容 | 网格、排版角色、对齐、对比、有限色彩 | 不等于删掉必要状态、数据和操作，也不以大面积空白冒充专业 |
| `Hero-Centric` | 首屏结构；单一价值或对象需要立即建立 | 真实主对象、首屏层级、单一主行动、下区提示 | 不用于后台主工作区，不做左右分栏卡片式营销模板 |
| `Conversion-Optimized` | 页面目标；注册、留资、购买等明确转化 | 摩擦、信任证据、表单长度、主次行动和失败恢复 | 它不是视觉风格；不得使用暗黑模式、虚假稀缺或隐藏退出 |
| `Interactive Product Demo` | 交互表达；复杂产品需要边做边懂 | 一条可信任务、真实状态、即时反馈、退出和重置 | 演示不证明后端、生产或完整产品已经可用 |
| `Data-Dense Dashboard` | 数据任务；高频扫描、比较和重复操作 | 紧凑网格、数字对齐、表格层级、固定控件尺寸 | 不把所有指标拆成卡片，不牺牲可读性和状态区分追求密度 |
| `Real-Time Monitoring` | 时效任务；变化当下需要发现与处置 | 数据时间戳、刷新状态、告警层级、趋势和确认动作 | 无真实刷新、延迟和失效语义时不得称实时 |
| `Drill-Down Analytics` | 信息架构；从总体追到对象与原因 | 层级路径、筛选继承、面包屑、返回与比较上下文 | 下钻必须可返回、可解释；不能用连续弹窗代替分析路径 |
| `Neubrutalism` | 表现型视觉；年轻品牌或创意工具需要鲜明性格 | 硬边界、高对比、粗字重、直接反馈 | 高责任、长时任务和密集后台默认不采用；不能破坏可访问性和熟悉操作 |
| `Organic Biophilic` | 表现型视觉；健康、生态或生活方式有真实内容支撑 | 自然取色、有机轮廓、真实材质与图像、呼吸空间 | 不用绿色、叶片或装饰曲线制造虚假环保含义，不加无功能背景团块 |
| `Micro-interactions` | 交互反馈；操作结果或状态变化需要被感知 | hover/focus/active/loading/success、时长、减弱动效 | 不为每次点击加动画；反馈已清楚时停止增加动作 |
| `Accessible & Ethical / Inclusive Design` | 横切约束；所有界面，公共和高责任服务尤重 | 语义、键盘、焦点、对比、缩放、恢复、非歧视表达 | 不是可选主题或风格装饰；未经验证不得宣称符合标准 |

## 二、风格决策变量

- **层级与密度**：主任务、主要内容和风险信息分别占多大注意力；哪些区域紧凑，哪些区域需要呼吸。
- **排版**：字体角色、字重、行长、CJK/Latin/数字混排、标题与正文比例。
- **色彩与材质**：颜色来自品牌、对象还是状态；材质是内容证据还是装饰模拟。
- **图像与图标**：真实对象如何被检查；图像比例、裁切、替代文本和加载失败怎样处理。
- **形状与空间**：边界、圆角、阴影、轴线和留白是否表达对象关系。
- **动效与声音**：是否解释状态、空间或叙事；如何暂停、跳过和响应减少动效偏好。

### 可视化风格证据包

当 Owner 无法仅凭风格名称形成画面、用户明确要求浏览或比较视觉方向，或文字候选仍明显同构时，可以调用本 Skill 自带的 `assets/style-gallery/`。局部功能必须继承现有设计系统、没有重设计授权、用户已经给出唯一视觉方向，或当前 blocker 属于产品语义、信息结构、状态与失败恢复时不调用；不能用画廊绕过上游问题。

Agent 先检索结构化目录，不能把全部 HTML 加载进上下文：

```bash
python3 ui-design-expert/scripts/style_gallery.py search \
  "<产品、任务、视觉或受众关键词>" --type visual-language --limit 5
```

`--type` 只在类型已经明确时使用，可选 `visual-language`、`data-task` 或 `mobile-system`；页面目标、数据任务、移动系统和视觉语言不得放进同一个互斥排名。同一界面确需跨类型参考时，分别检索、分别说明采用轴，不合并分数；多应用任务还要逐应用核对既有设计权威，一个应用获准探索不等于其它应用获准重设计。检索分数只表示查询与目录元数据的召回相关性，Top 1 不是设计推荐；打开标本并回到任务、受众、内容、现有权威和风险后，可以采用排名更低的候选。检索结果为空时补充任务词或保留待确认，不改为全库扫描。候选上限为 5；通常只打开 3 个，存在真实分叉时最多 5 个。用户点名某一条目时可以直接打开其 `specimen_path`，仍须先核对适用类型和现有设计权威。

需要人类做视觉比较时打开 `assets/style-gallery/index.html`，并保持以下交付：

```text
检索问题与类型：
打开的 3-5 个标本：
共同内容基线：
建议采用轴：层级 / 排版 / 色彩 / 空间 / 材质 / 图像 / 动效
明确不采用：
与现有设计系统的继承或偏离：
仍需真实内容、状态、视口、任务和可访问性验证：
```

画廊是 `local-visual-evidence-only`：只能证明本地标本如何呈现，不证明原网站、品牌、完整交互、浏览器兼容、WCAG、目标用户任务、生产代码或上游推荐正确。不得复制标本 CSS 进入产品；选中的是可观察变量，不是代码。`supplemental` 只表示上游来源状态，不在本地自动升为 active。运行前或来源更新后执行 `python3 ui-design-expert/scripts/style_gallery.py check`；失败时停止使用，不手改生成页或刷新摘要绕过。扩展目录前另执行 `python3 ui-design-expert/scripts/style_gallery.py relevance`；它只证明冻结查询的确定性排序与类型边界，不是目标用户偏好、真实采用收益或完整行为改善证据。

## 三、华夏经世镜片的现代设计转译

以下是现实设计判断镜片，不是古籍训诂、UI 标准或“东方美学定律”：

1. **名实相符**：名称、视觉层级、可操作性和真实任务相称。主行动像主行动，危险状态不能被雅化，所谓“东方”必须落到可观察变量。
2. **时位相称**：区分不变约束与可变表达。任务型后台、文化阅读、品牌转化和对象展示处在不同情境，不能一套古风模板通吃。
3. **文质相称**：形式帮助内容和任务被理解；装饰、品牌情绪与功能清晰度不过与不及。
4. **知止**：装饰止于不损害任务、真实内容和可访问性。删去某项装饰后理解不变时默认不加；层级、识别和反馈已经成立时停止润色。
5. **行验归实**：先把风格名翻译成可观察变量，再用真实内容、关键状态和最小代表页面验证任务、响应式、性能与可访问性；截图好看只能证明一种呈现，不能证明风格选择或产品已经成立。

冲突时先守真实任务、风险、可访问性和项目设计权威，再谈文化表达。

## 四、东方审美的可操作变量

| 变量 | 可执行表达 | 适用 | 反例 |
| --- | --- | --- | --- |
| 留白与虚实 | 给主内容、主路径和章节转换留出明确空间；后台只做局部呼吸区 | 阅读、展陈、品牌叙事 | 大面积空白降低后台信息效率 |
| 疏密与节律 | 密集数据区与低密度解释区有目的地交替 | 表格、仪表盘、长表单、长文 | 全页面同一间距、卡片均匀铺满 |
| 层次与路径 | 以主次、近远和渐进披露组织阅读与行动 | 审批、表单、详情、叙事页 | 仪式化中轴或屏风分栏拉长任务路径 |
| 含蓄与显露 | 品牌情绪可以克制，任务、状态、风险和恢复必须明确 | 品牌、文化内容、展示 | 关键操作只在 hover 出现，低对比隐藏状态 |
| 色彩与材质 | 从真实器物、产品、场所和品牌资产取色并进入 token | 商品、展陈、目的地、品牌 | 默认水墨、米色、红金或仿纸纹理 |
| CJK 排版 | 核对字体许可与回退、行高、断行、标点、长词和数字 | 所有中文 Web 界面 | 书法字体作正文、负字距、长段居中 |

可以形成的方向示例：

- **清简秩序**：克制层级、清楚留白、精确排版，适合文化阅读、专业服务和研究内容。
- **礼序层次**：以入口、主次和渐进路径建立庄重感，适合机构、展陈和高信任事务；不能制造多余仪式步骤。
- **器物工艺**：以真实对象、局部细节、材质和制作过程形成识别，适合工艺、商品和收藏；不得用仿古纹理替代真实素材。

水墨、米色、红金、书法、印章、窗棂和屏风都只能在真实内容或品牌证据支持时成为候选，不能作为“东方审美”的默认组件包。

## 五、参考设计学习

先诊断再决定采用轴：采用轴未明确且会改变结果时才询问 Owner；用户已明确或已授权自决时直接进入设计。

1. **声明来源模式**：URL 实际加载后可以检查 DOM / CSS、资源引用和精确值，但不能只凭代码证明视觉节奏、全部交互状态、响应式表现或使用权；截图可以观察宏观结构、排版角色、色彩锚点和区段节奏，但不能证明精确字体、交互、断点或实现方式。
2. **分层记录**：把结论分成观察、推断、待确认和来源归因；提炼可迁移的设计 DNA，包括宏观结构、信息节奏、排版角色、色彩锚点、图像角色和动效目的，不把风格名称当结论。
3. **处理来源失效**：URL 遇到验证页、登录墙、空正文、SPA 空壳或动态加载失败时停止静默推断，请用户提供截图或可读取证据；不把搜索摘要或标题当页面事实。
4. **控制采用边界**：输出建议采用、不采用和需要用户确认的轴；公开可见不等于允许复制，不做像素复刻，不复制源码、品牌、文案、素材或受保护表达。任务型界面不为追求设计 DNA 而牺牲熟悉结构、标准控件和效率。

## 六、验证与停止

- 把视觉方向写成可对照的层级、排版、色彩、空间、图像和动效变量，不只给风格名称或 moodboard。
- 用真实短/长中文、数字、空/错/载入状态以及桌面/移动视口验证；检查对比、键盘、焦点、缩放和减少动效。
- 让目标用户完成关键任务并复述主次和状态；文化符号的辨识不等于任务可用。
- 当风格需要发明品牌历史、文化含义或对象事实时停止并交回 Owner；需要古籍或字源证据时转交 `hanzi-philology`。
- 不能牺牲任务效率、可访问性和真实内容来证明“东方”；发生冲突时删除装饰而非降低底线。
