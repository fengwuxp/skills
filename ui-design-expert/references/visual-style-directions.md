# 视觉方向与东方审美

## 使用时机

当任务需要建立新的视觉方向、比较设计风格，或用户明确要求东方审美、中国文化、器物、展陈、传统品牌等 Web 表达时读取。东方审美不是国风皮肤，只在真实产品、内容和品牌证据支持时使用。

## 不适用场景

- 局部功能应继承现有设计系统，没有重设计授权。
- 用户只要文化、美学或历史研究报告，不涉及界面设计。
- 用传统概念替代产品事实、可访问性标准或浏览器验证。

## 读取后必须产出

- 产品情境、真实资产和所选视觉方向的因果关系。
- 可落到层级、排版、色彩、空间、材质、图像和动效的变量。
- 明确不用什么、为什么不用，以及响应式、内容和可访问性验证。

- 基础规则读 `design-foundations.md`。
- 页面结构与状态读 `design-and-review-workflow.md`。
- 经典镜片的现代工程转译与证据边界复核 `source-map.md`，需要古籍训诂时转 `hanzi-philology`。

## 一、先按情境选风格

| 方向 | 适合 | 表达重点 | 常见误用 |
| --- | --- | --- | --- |
| 克制任务型 | 运营、财务、CRM、审批 | 扫描、比较、密度、熟悉操作、明确状态 | 营销大标题、卡片套卡片、装饰性首屏 |
| 安静产品型 | 通用 SaaS、协作、设置 | 清楚层级、稳定 tokens、少量品牌细节 | 全页面同色、过度圆角和留白 |
| 编辑阅读型 | 文档、研究、媒体、知识 | 排版、目录、引用、连续阅读、内容节奏 | 正文展示字号、长段居中、装饰压过内容 |
| 商品目录型 | 电商、器物、作品与地点 | 真实对象、比较、规格、信任与行动 | 氛围图替代可检查对象、信息藏在轮播 |
| 品牌叙事型 | 发布、文化机构、目的地 | 真实资产、叙事节奏、识别度和转化证据 | 把视觉冲击当价值证明 |
| 沉浸媒介型 | 游戏、互动展陈、视听体验 | 媒介质量、空间关系、动效和参与 | 牺牲加载、输入、减弱动效和退出路径 |

视觉方向可以组合，但主方向只有一个；每个偏离既有系统的决定都要回指受众、任务、内容或品牌资产。

## 二、风格决策变量

- **层级与密度**：主任务、主要内容和风险信息分别占多大注意力；哪些区域紧凑，哪些区域需要呼吸。
- **排版**：字体角色、字重、行长、CJK/Latin/数字混排、标题与正文比例。
- **色彩与材质**：颜色来自品牌、对象还是状态；材质是内容证据还是装饰模拟。
- **图像与图标**：真实对象如何被检查；图像比例、裁切、替代文本和加载失败怎样处理。
- **形状与空间**：边界、圆角、阴影、轴线和留白是否表达对象关系。
- **动效与声音**：是否解释状态、空间或叙事；如何暂停、跳过和响应减少动效偏好。

## 三、华夏经世镜片的现代设计转译

以下是现实设计判断镜片，不是古籍训诂、UI 标准或“东方美学定律”：

1. **名实相符**：名称、视觉层级、可操作性和真实任务相称。主行动像主行动，危险状态不能被雅化，所谓“东方”必须落到可观察变量。
2. **时位相称**：区分不变约束与可变表达。任务型后台、文化阅读、品牌转化和对象展示处在不同情境，不能一套古风模板通吃。
3. **文质相称**：形式帮助内容和任务被理解；装饰、品牌情绪与功能清晰度不过与不及。
4. **知止**：装饰止于不损害任务、真实内容和可访问性。删去某项装饰后理解不变时默认不加；层级、识别和反馈已经成立时停止润色。

冲突时先守真实任务、风险、可访问性和项目设计权威，再谈文化表达。

## 四、东方审美的可操作变量

| 变量 | 可执行表达 | 适用 | 反例 |
| --- | --- | --- | --- |
| 留白与虚实 | 给主内容、主路径和章节转换留出明确空间；后台只做局部呼吸区 | 阅读、展陈、品牌叙事 | 大面积空白降低后台信息效率 |
| 疏密与节律 | 密集数据区与低密度解释区有目的地交替 | 表格、仪表盘、长表单、长文 | 全页面同一间距、卡片均匀铺满 |
| 层次与路径 | 以主次、近远和渐进披露组织阅读与行动 | 审批、表单、详情、叙事页 | 仪式化中轴或屏风分栏拉长任务路径 |
| 含蓄与显露 | 品牌情绪可以克制，任务、状态、风险和恢复必须明确 | 品牌、文化内容、展示 | 关键操作只在 hover 出现，低对比隐藏状态 |
| 色彩与材质 | 从真实器物、产品、场所和品牌资产取色并进入 token | 商品、展陈、目的地、品牌 | 默认水墨、米色、红金或仿纸纹理 |
| CJK 排版 | 核对字体许可与回退、行高、断行、标点、长词和数字 | 所有中文 Web 界面 | 书法字体作正文、负字距、长段居中 |

可以形成的方向示例：

- **清简秩序**：克制层级、清楚留白、精确排版，适合文化阅读、专业服务和研究内容。
- **礼序层次**：以入口、主次和渐进路径建立庄重感，适合机构、展陈和高信任事务；不能制造多余仪式步骤。
- **器物工艺**：以真实对象、局部细节、材质和制作过程形成识别，适合工艺、商品和收藏；不得用仿古纹理替代真实素材。

水墨、米色、红金、书法、印章、窗棂和屏风都只能在真实内容或品牌证据支持时成为候选，不能作为“东方审美”的默认组件包。

## 五、验证与停止

- 把视觉方向写成可对照的层级、排版、色彩、空间、图像和动效变量，不只给风格名称或 moodboard。
- 用真实短/长中文、数字、空/错/载入状态以及桌面/移动视口验证；检查对比、键盘、焦点、缩放和减少动效。
- 让目标用户完成关键任务并复述主次和状态；文化符号的辨识不等于任务可用。
- 当风格需要发明品牌历史、文化含义或对象事实时停止并交回 Owner；需要古籍或字源证据时转交 `hanzi-philology`。
- 不能牺牲任务效率、可访问性和真实内容来证明“东方”；发生冲突时删除装饰而非降低底线。
