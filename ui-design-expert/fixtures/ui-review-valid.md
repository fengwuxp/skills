# 开户表单可用性评审

## 评审结论与范围

结论：需要修复后复核。范围是移动 Web 端证件上传、校验失败和返回修改路径，不改变开户规则或视觉品牌。

## Findings

[P1] 证件校验失败后页面只显示顶部提示，焦点仍停留在提交按钮。触发条件是服务端返回证件字段错误；用户影响是无法定位失败字段并可能重复提交。证据来自当前页面源码和移动端走查。

## 最小修复方向

把错误绑定到证件字段，保留已填内容与上传结果摘要；错误出现后将焦点移到错误摘要，并提供返回修改和重新提交路径。弱网状态显示上传进度，禁止重复提交。

## 验证与残余风险

复测键盘焦点、读屏错误通知、弱网重试、返回修改、长文件名和权限拒绝。尚未获得真实读屏与目标设备证据，残余风险由 UI owner 复核；证据不足时停止宣称符合 WCAG。
