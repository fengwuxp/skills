# Web 审批浏览器原型计划

## 目标、层级与边界

目标用户是审批运营，验证问题是键盘与窄屏下能否完成退回。选择 L2 浏览器可运行原型；范围覆盖列表、详情、退回和结果，非目标是不接生产数据。当前假设单人审批，由产品 owner 确认规则。

## 页面、状态与真实内容

入口为待办列表，退出为结果页，重置回到同一条待办。页面图与状态图覆盖 default、loading、empty、error、success、权限、弱网和真实长度数据。

## 交互与失败恢复

交互表记录 source、trigger、condition、action、destination、feedback 和 failure。表单校验或请求失败时保留用户输入并把焦点移到错误摘要，可返回详情重试。

## 工程交接与可访问性

设计系统姿态为继承项目现有体系；组件来源、语义 tokens、组件状态、偏离项和 Owner 均写入组件规范。由 `senior-software-architect` 使用项目组件、tokens、路由、状态和数据模式实现；浏览器原型保留真实 URL、表单和请求失败行为。响应式覆盖桌面与移动，并用 Playwright 验证键盘、焦点、可访问名称、对比和 200% 缩放，测试不得依赖生产数据。

## 验证证据与停止条件

在真实浏览器完成成功、校验失败、网络失败、返回和重置的任务走查，保存版本、测试结果和验证证据。截图不证明可点击；请求失败或焦点路径未验证时停止并记录残余风险。
