# 小说人物造型与成图能力设计

## 1. 目标

增强现有 `novelist -> fiction-visual-designer -> imagegen -> fiction-visual-designer -> 作者 / novelist` 链路，使人物外貌、衣饰、整体造型能够从小说语义形成可验收视觉契约，并在真实图片生成中支持审美基准、身份锚定、局部修订、作者采用和正典隔离。

不新建顶层人物 Skill。`novelist` 继续持有人物事实、关系、选择、弧光和正典；`fiction-visual-designer` 持有视觉转译、图片角色、生成编排和视觉验收；`imagegen` 持有模型、提示词适配、参数、生成与编辑执行。

## 2. 失败基线

当前 Skill 已覆盖权威冻结、身份锚点、可变状态、最小差异修订和正典边界，但真实成图暴露出四个稳定缺口：

1. 没有区分审美基准图、身份锚图、服饰状态图和场景图，容易把作者采纳的整体方向误作具体身份确认。
2. 没有逐属性采用矩阵，无法明确记录“年龄感、气质、配色通过，脸、身、发、衣未确认”。
3. 没有局部编辑与整图重绘的明文路由，局部杂物可能引发不必要的全图漂移。
4. 普通人物图片只有结果停止条件，没有一次定向修订的迭代预算。

本轮只修正这四项，不重复现有外貌因果、衣装结构、东方审美和正典治理方法。

## 3. 三轴状态模型

图片角色、整图制作状态与属性采用状态分轴记录，不互相替代。

### 3.1 图片角色

| 图片角色 | 作用 | 不自动确认 |
| --- | --- | --- |
| 审美基准图 | 比较年龄感、气质、配色、造型密度和整体方向 | 具体脸型、体态、发式、衣制和饰物 |
| 身份锚图 | 锁定作者已确认的脸部结构、体态比例、发量发际和稳定身体特征 | 阶段服饰、临时动作和场景效果 |
| 服饰状态图 | 锁定特定阶段、行动、气候、资源和礼制下的穿着状态 | 人物终身衣柜或身份本质 |
| 场景表现图 | 表现具体关系、意图、动作、距离和环境 | 新人物事实、关系、能力或命运 |

一张图可以承担多个角色，但必须逐项声明，不能用“作者采用整张图”省略确认范围。

### 3.2 制作与采用状态

制作轴沿用 `视觉候选 -> 已确认设计 -> 已生成待验收 -> 已验收图像`；采用轴使用 `属性候选 -> 作者采用 -> 正典写回`。图片角色说明它被用来验证什么，制作轴说明整图是否通过，采用轴说明哪些属性获得效力。作者可以先采用年龄感、气质或配色，同时让整图保持需修订。

## 4. 人物视觉能力

### 4.1 权威交接

`novelist` 交付人物阶段、稳定底色、当前关系与意图、知情边界、身体事实、经历痕迹、不可变项、允许变化和禁止由外貌推断的内容。缺失项只有会改变主方向时才回问，其余保持未知。

### 4.2 外貌、衣饰与造型

- 外貌从年龄、身体、生活痕迹、观察距离和第一印象修正形成，不以脸型证明德性。
- 衣饰从时代或混合时代原则、地域、气候、行动、身体、资源、身份和礼制反推领襟、肩袖、腰部、下装、鞋履、携物与发饰结构。
- 东方人物按形、势、衣、神、境组织；去掉颜色、纹饰和说明文字后，人物轮廓、重心、衣装结构与行动关系仍须成立。

### 4.3 生成与修订

先生成一张中性背景、结构可读的四分之三全身图。图像角色未确认时默认是审美基准候选，不称为身份锚图。

修订按最早失败层选择动作：

| 失败范围 | 动作 |
| --- | --- |
| 年龄、脸、骨架、主轮廓、主要衣装结构或全身姿态错误 | 以已通过项为约束重新生成 |
| 局部饰物、衣缘、单处纹样、手部或小范围生成瑕疵 | 工具支持时优先局部编辑 |
| 工具不支持所需编辑 | 带最小差异契约重新生成一次 |
| 一张人物图的一次定向修订总预算用完后仍漂移或失败 | 报告工具限制并停止，不降低设计标准 |

### 4.4 逐属性采用矩阵

每张图片至少记录：`图片 ID 或路径 / 属性 / 图片角色 / 结论 / 可见证据 / 后续效力`。结论只用 `采用 / 保留候选 / 拒绝 / 无法验证`。作者采用整体方向时，未逐项采用的脸、身、发、衣和饰物保持候选。

## 5. 最小资产落点

- 增强 `fiction-visual-designer/references/character-visual-design.md`：加入图片角色与逐属性采用矩阵。
- 新增 `fiction-visual-designer/references/character-rendering.md`：承载生成、编辑 / 重绘路由、迭代预算和停止条件。
- 增强 `fiction-visual-designer/assets/visual-design-sheet-template.md`：增加可裁剪的人物图片角色、采用矩阵和成图差异字段。
- 更新 `fiction-visual-designer/SKILL.md`、`agents/openai.yaml` 与 `README.md` 的人物成图路由，不改变职责 Owner。
- 扩展现有行为 fixture；不新增脚本、模型依赖、供应商配置或人物专属模板。

## 6. 验证与准入

静态验证包括 frontmatter、reference 路由、fixture schema、候选 source hash、统一 dry-run 和 `git diff --check`。

真实能力改善仍须使用同一 runner/model 对同一人物任务进行 baseline/candidate 重复生成与独立盲评。至少检查图片角色分型、逐属性采用、衣装结构、无依据新增、最小修订和停止条件。当前真实成图和只读行为检查只构成失败基线与 smoke 证据，`FVD-001` 在重复生成和盲评完成前保持开放。

## 7. 非目标

- 不新增人物正典、历史服制事实、固定中国风模板或供应商提示词库。
- 不把审美基准自动升级为身份锚图。
- 不自动下载模型、调用云服务、读取凭据、同步、提交或发布。
- 不用 SVG、CSS、网页线框或文字说明冒充人物审美成图。
