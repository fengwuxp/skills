# 文档交付契约

## 使用时机

创建、重写、合并或最终收口正式文档前读取。信息不足时只补一个当前主 blocker，不一次索要全部细节。

## 最小契约

```text
文档类型：报告 / 制度 / 手册 / 研究说明 / 总结 / 创作设定集 / 其他
文种与效力：信息 / 建议 / 决策 / 强制 / 对外承诺
目标读者与读者关系：谁阅读、谁评审、谁使用；上行 / 平行 / 下行 / 外部；创作项目为作者侧 / 编辑侧 / 读者侧
阅读后动作：知情 / 判断 / 批准 / 执行 / 留档 / 阅读
范围：包含什么；明确不包含什么
事实源：文件、数据、会议记录、链接、领域证据卡
文档状态：草案 / 评审版 / 最终版
输出载体：Markdown / DOCX / PDF / PPTX / 表格
语体与版式依据：行文强度、编号、引用、目标模板或平台要求
Owner：内容确认、专业确认、最终批准分别由谁负责
验收：结构、事实、引用、修订、渲染和签批要求
```

## 文档类型最小骨架

| 类型 | 必需内容 |
| --- | --- |
| 报告 | 背景与目标、读者、来源、事实、分析、结论、行动、风险、验证 |
| 制度 | 目的、范围、定义、角色、规则、流程、例外、记录、复审 |
| 手册 | 读者、前置条件、步骤、预期结果、验证、故障处理、限制 |
| 研究说明 | 问题、范围、来源、事实、推断、不同观点、结论、局限 |
| 会议纪要 / 决议 | 会议范围、参会责任、事实、分歧、决议、行动、owner、期限和待确认项 |
| 总结 / 复盘 | 目标与结果、事实、偏差、机制、得失、行动、验证与复审 |
| 对外方案 / 白皮书 | 对象与问题、价值、依据、方案、边界、案例、风险与下一步 |
| 创作项目文档 | 作者侧正典档案、人物档案、时间线、伏笔/承诺台账、编辑梗概或读者附录所需的权威范围、状态、剧透等级、引用、作者决策和待确认项 |

未知内容保留“待确认 + owner + 影响”，不得用常见做法或模型记忆补成事实。

创作项目先确认作者侧 / 编辑侧 / 读者侧、阅读进度、剧透等级和正典状态。正典与价值 Owner 是作者，`novelist` 是故事语义主能力；本 Skill 只维护文档结构和版本关系。旧稿、参考素材和创作候选不得因被整理进文档而升级为正式设定。

从 `novelist` 接收故事事实时，必须同时取得授权范围、逐项设定状态与确认证据 / 权威指针；缺失、越界或冲突的条目保持待确认，不写入正典。

创作文档用“已确认 / 建议骨架 / 待确认 / 参考素材”标记状态，并区分作者本真 / 人物所知 / 读者所知。编辑用完整梗概可以完整剧透；材料不足时只整理已确认故事线和缺口，不补造主冲突、转折或结局。读者侧材料只呈现当前阅读进度应知内容。
