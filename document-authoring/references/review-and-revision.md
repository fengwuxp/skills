# 评审与修订

## 使用时机

用户要求评审、审校、改写、合并、红线修订或整理最终版时读取。

| 模式 | 产出 | 不做 |
| --- | --- | --- |
| 评审 | 按严重度列问题、证据、影响、建议和 owner | 不默认重写全文 |
| 审校 | 修正错别字、病句、术语、引用和格式 | 不改变领域结论 |
| 改写 | 在目标、范围和事实不变时重组结构与表达 | 不补造缺失事实 |
| 合并 | 选择权威版本，消除重复和冲突，保留差异说明 | 不把冲突静默覆盖 |
| 最终版 | 只保留有效结论、依据、风险、待确认和批准状态 | 不保留 AI 推理和讨论流水 |

修订前确认允许修改的层级：措辞、结构、事实、结论或载体。事实和结论的修改必须回到对应 owner；无法判断时保留原文并标记冲突。

## 保真去模板化

用户要求“去 AI 味”“说人话”或“写得自然”时，先把请求转换成受控修订，不把风格目标解释为改事实、改流程或消除不确定性。

1. **冻结不得漂移项**：逐项保护数字与修饰对象、日期与范围、责任主体、动作与顺序、条件与例外、效力词、完成态、强度、观点归属、引文、命令、参数、字段、路径、日志和已声明的不确定性。制度中的“必须 / 不得 / 应当 / 可以”、复盘中的“观察 / 推断 / 待验证”属于语义，不是可随手删除的语气词；未获效力修改授权时，制度效力词原样保留，不换成“要 / 不能 / 可”等口语近义词。
2. **按授权范围修改**：只改措辞或表达时，不删除承载独有语义的句子，不做改变语义关系的并句或重排；可删除不承载独有语义的套话、结构自述和重复收尾。允许局部结构调整时，也只处理不承载独有事实、判断、责任、条件或行动的病灶。要求“更顺”“更有力量”不构成修改流程、效力或证据强度的授权。
3. **按功能判断形式**：套话、空总结和无信息口号可以删除；短段正文已经直接呈现内容时，删除不承担定位作用的开场结构预告和末尾重复收尾，不用“本文依次说明 / 下面介绍 / 以上为”等近义句换壳。长文导读、章节导航、决策请求或承上启下确有定位功能时保留。没有证据或独立信息支撑的空泛评价，不换成较轻近义词继续保留，删除后让相邻的可核实事实、判断或行动直接承重，也不为显得具体而补造数据。重复、排比、正式用语或抽象句若承担操作顺序、记忆提示、法定效力、证据限定或文种语体则保留，不用禁词表、句长随机化或整篇洗稿代替判断。用户限定只改正文、不动结构时，`先核版本，先核环境，先核回滚点` 这类安全步骤重复默认原样保留，不压成“依次核对”而隐藏其强调功能。
4. **保真回读**：对照原文逐项检查主体—动作、数量—对象、条件—结果、观点—归属是否仍配对，谓词方向、完成态、效力和不确定性是否改变，并清除本轮改写新引入的同义复沓、错搭或病句。不可追溯的“业内人士 / 有关方面 / 消息称”等归因不换成另一个模糊主体；没有可核验的公开文件或具名来源时，删除经核对仍无证据支撑的断言，或明确当前缺少哪类可核验来源并保留原有不确定性，不扩大为没有任何来源支持，不补造来源，也不把建议升级为事实或决定。只获风格修改授权时，输入与输出中的“必须 / 不得 / 应当 / 可以”词项及出现次数必须一致，并逐项核对约束对象；任一原词被删、换词、少词或改绑对象，先恢复原样再交付。发现其他漂移也恢复原义；原文证据不足时保留待确认，不补一个更像结论的说法。

检测器分数只能作为复读线索，不能证明作者身份、作弊或 AI 参与比例，也不能成为牺牲事实、效力和可追溯性的准出标准。

## 文种与语体复核

- 文种与效力是否匹配目标读者的阅读后动作；开头、章节和证据顺序是否服务该动作，而非统一套用结论先行。
- 读者关系、责任主体和“必须 / 不得 / 应 / 可以 / 建议”等效力词是否清楚，术语、编号、日期、数字和单位是否一致。
- 作者侧、编辑侧和读者侧是否分开；正典状态、作者本真 / 人物所知 / 读者所知、阅读进度与剧透等级是否匹配。
- 结构与载体调整不得改变领域语义；发现事实冲突、剧透越界或材料不足时停止补写并交回对应 owner。
