# Markdown 到语雀发布契约

## 适用范围

用于把仓库或本地权威 Markdown 更新到明确的语雀知识库和 docRef。正文事实仍由来源所属产品、工程或文档 Owner 持有，本契约只控制派生载体和发布证据。

## 发布输入

| 输入 | 要求 |
| --- | --- |
| 本地源 | 绝对路径、可读取文件、文档版本、SHA-256 |
| 语雀目标 | 知识库、稳定 docRef、新建或更新意图 |
| 图片 | 正文必需图与可选图分开；每张图有本地路径和插入位置 |
| 链接 | 已知语雀文档映射；未映射本地链接的处理方式 |
| 授权 | 内容传输、覆盖、新建、删除和权限动作分别确认 |
| 停止条件 | 草稿冲突、源摘要变化、目标不明或关键渲染失败 |

## 临时投影

投影脚本必须保持正文语义和 Mermaid 原文，只允许以下派生处理：

1. 在首个一级标题后加入本地权威、`SourceVersion` 和 `SourceSHA256`。
2. 把本地图片语法替换为普通文本占位，并在 manifest 的 `images` 记录 alt 与路径；按源文件目录无法解析的图片同时进入 `missing_images`，发布前必须清零。外部 HTTP(S) 和 `data:` 图片保持原样；占位不得使用引用格式，避免图片被插入引用块。
3. 已映射的本地 Markdown 链接替换为稳定语雀文档 URL；未映射链接降为可读文本并进入 manifest；外部 HTTP(S)、邮件和页内链接保持不变。
4. 统计 Mermaid 代码块，禁止把流程同时转换成另一张 SVG。

投影和 manifest 只放在显式临时输出目录。发布期间本地源摘要变化时废弃当前投影并重新生成，不能拼接新旧版本。

`missing_images` 非空表示发布输入不完整，不得用占位、文件名或上传提示冒充图片已就绪；先补齐源图片或由文档 Owner 明确调整正文。

## 更新既有文档

1. 从稳定 docRef 打开阅读页，记录发布版本和来源标记。
2. 进入编辑器，确认加载内容与阅读版一致；存在未发布人工草稿时停止。
3. 全选正文并粘贴投影；语雀识别 Markdown 时选择样式转换。
4. 核对标题层级、表格、大纲、代码块和 Mermaid 卡片，再处理图片。
5. 从编辑器可见的图片插入能力触发文件选择器，上传 manifest 中的必需图片；删除占位并确认图片仍在原章节。
6. 等待顶部明确显示已保存，再执行更新；返回阅读页后重新回读。

## 失败与恢复

| 现象 | 处理 | 禁止 |
| --- | --- | --- |
| 阅读版与草稿不同 | 停止，记录两个版本和摘要，交文档 Owner 决定保留、回写或丢弃 | 直接覆盖或把两版拼接 |
| Markdown 未转换 | 保留草稿，执行样式转换并重新核对结构 | 把井号、表格和围栏作为普通文本发布 |
| 文件选择器未触发 | 重新定位编辑器可见的图片插入能力；仍失败则记录未上传图片并停止相应发布 | 反复点击隐藏 input 或用上传提示冒充成功 |
| 已保存但更新提示“正在保存，请稍候”或 `busy` | 等待保存状态；长期不解除时重载同一 docRef，核对草稿来源版本、SHA-256 和核心章节，更新按钮恢复后继续 | 重复粘贴、切换目标、从旧阅读版覆盖 |
| SVG 存在但不可见 | 在阅读页检查实际载入、自然尺寸和显示尺寸；失败则保留正文并记录图片残余 | 只看文件名、节点或上传成功提示 |
| Mermaid 不渲染 | 保留可复制代码文本并记录失败 | 补传等价流程 SVG 形成双权威 |
| 长文档 DOM 检查超时 | 改为目标章节、目标卡片和代表性视口的分段检查 | 继续全页扫描并把超时当页面失败 |
| 旧章节链接失效 | 从最新目录重新定位；对外只保留文档 docRef | 持久化新 anchor 作为跨版本契约 |

## 发布后证据

- 版本证据：阅读页显示的来源版本和 SHA-256 与本地一致。
- 结构证据：标题、目录、代表性表格和代码块可读。
- 图形证据：Mermaid 节点、箭头和标签可见；必需图片实际加载且尺寸非零。
- 目录证据：目标分组、同名文档和非预期资源目录已检查。
- 边界说明：浏览器静态回读不证明业务运行、接口、权限、移动端、生产准出或持续自动同步。

## 当前环境观察

2026-09-07 的实际语雀编辑器曾出现 Markdown 转换提示、隐藏文件输入无法稳定触发、已保存草稿短时 `busy`、整篇重导后旧章节 anchor 失效。它们只作为恢复分支和复核条件，不是语雀永久契约；编辑器、团队空间或浏览器能力变化后应重新验证。
