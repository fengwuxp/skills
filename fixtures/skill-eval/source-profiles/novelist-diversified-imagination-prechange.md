### 幻想入口路由

用户明确要求只发散、不选择、不解释、不落地时，除区分用户原话、外部事实、文学虚构和授权边界外，直接进入 `references/worldbuilding-and-research.md` 的“天马行空”，不先用下方察实、正名、审时和权衡步骤筛选候选；本轮止于可继续生长的文学虚构候选。用户显式要求会商或头脑风暴时，先发散，收敛前至少做一次去同构与反方复核；普通构思不强制多轮。用户要求选择、成形、写入故事或检验可用性时，再进入完整工作流和“幻想归来”。历史幻想项目中的普通历史推演、制度设计或人物选择不因题材名称自动进入幻想归来；只有实际调用作者已选的不可替代幻想核、非常规则或神异机制时才进入，未调用时按历史融合、故事设计或人物选择推演处理。

4. **发散创见**：同时接住积厚而发的材料积累与灵感天成的突现幻想；先保留不可替代的原始核，与后续加工分开。多轮讨论中增量收集承重创作素材，区分作者原话、小说家公开建议、作者确认与未决项，不把谈话顺序当成故事时序；材料只说讨论或分析发生过却未给出具体依据时，记录“依据未提供”，不能补写看似合理的旧讨论。探索期允许候选互相矛盾、暂时无用、不可落地或没有解释，不因求真过早扼杀想象，也不因想象跳过事实和作者确认。

幻想创作保留天马行空与幻想归来两个可往返方向。用户明确要求只发散、不选择、不落地时，本轮止于文学虚构候选，不把幻想归来反向变成探索门禁。只有作者要求选择、成形、写入故事或检验可用性时，才进入幻想归来：保护不可替代的幻想核，不因“真实可信”被改写成科学或常识解释；再让它在故事、人物、世界、历史与神话中归来，通过选择、生活、遗痕、异文和后果成为读者可感的叙事现实。若成形后变得常规、工整或可预测，可以退回天马行空重新发散。候选之间可以矛盾；进入当前创作单元后仍须服从已确认正典、三层真实和后果自洽。完整百科不得先于人物选择与当场故事；“成真”只指经作者确认进入小说正典并在叙事中成立，不指成为现实史实。

## 四层材料

| 层级 | 含义 | 写作规则 |
| --- | --- | --- |
| 事实 | 已核验的自然、历史、制度或文本材料 | 标记来源、时代和适用范围 |
| 传统说法 | 文献记载、地方传说、传统训释或后世整理 | 说明版本、流变和争议 |
| 合理推演 | 基于事实与约束形成的创作假设 | 允许反证，不写成真实历史 |
| 文学虚构 | 为主题、人物和情节创造的设定 | 保持内部一致，不伪称有史料依据 |

需要当前外部事实时读取一手或官方材料；正文不可得时停止下事实结论。古籍字词、异文和训诂交给 `hanzi-philology`，其证据只限定可借用范围，不替作者创作。

## 天马行空与幻想归来

幻想创作按当前任务在两向之间往返，不机械执行一条单向流水线：`辨向 -> 蓄材 -> 远游 -> 存核 -> 归人 -> 验生 -> 承续`。辨向先确认本轮止于发散，还是要选择、成形、写入或检验；蓄材接住生活感受、事实材料、传统说法、语言积累与突现灵感，保留各自证据身份；远游只负责打开可能；存核保护不可替代的奇异点；归人让被选中的幻想进入人物与世界；验生用场景、选择和后果检验；承续只在作者确认或明确自决授权后更新正典。纯发散在远游或存核处停止，成形失去奇异性时可以退回远游。

幻想归来要求当前任务实际调用作者已选的不可替代幻想核、非常规则或神异机制，并让它改变人物、生活、选择或后果。历史幻想项目中的普通虚构历史、制度设计、政治冲突和人物选择，不因题材名称或世界中另有神异就自动进入幻想归来；未调用幻想核时，分别按历史融合、故事设计或人物选择推演处理。作品立意、政治判准和会商工作名也不能自称幻想核或既有世界规则。

### 天马行空

探索期允许候选互相矛盾、暂时无用、不可实现或没有解释。用户明确要求只发散、不选择、不落地时，不强迫共享原因、统一世界观、人物主线、现实约束、代价、反制或回收，也暂不读取下方五层归来；本轮止于可继续生长的文学虚构候选，不替作者筛选或升级正典。候选不能只是替换名词、颜色或背景皮肤，应在主体、关系、因果、时空、感知、规则或叙事声音中至少形成一种真正不同的可能；错位、反转、移时、换尺度、换主体和规则变形只是可选手段，不作为机械配额。候选之间可以矛盾；被作者选择并进入当前创作单元后，仍须服从已确认正典、三层真实和后果自洽。

用户显式要求会商或头脑风暴时，首轮先发散，收敛前至少做一次去同构与反方复核；不把第一份裁决包冒充头脑风暴结论，并检查候选是否只是换载体、换名称或共享同一因果，让反方指出被忽略的主体、代价和替代解释。该复核只在显式会商、头脑风暴或候选明显同构时启用，普通构思不强制多轮，也不在发散轮提前用可行性筛掉奇异方向。

只有候选需要跨轮保留、比较或准备进入幻想归来时，才记录最小幻想核；一次性纯发散不强制填卡：

```text
原始表达：
不可替代的奇异点：
暂不解释的未知：
哪种解释会毁掉它：
```

### 幻想归来（成真）

只有作者要求选择、成形、写入故事或检验可用性时，才从候选中选择幻想核进入归来；进入前先回读原始表达、不可替代的奇异点、暂不解释的未知和禁配解释，不为便于说明把幻想改写成幻觉、仪器、科学现象、常见血统或万能规则。若成形后变得常规、工整或可预测，可以退回天马行空重新发散。

选核时先写一句**归来目的**：它要改变哪一个人物的什么选择，或哪项普通生活与后续条件；同时写清它不能替代的事实、权利或责任判断。说不清目的，或只能增加氛围、象征和设定名词时，不进入幻想归来。作者确认时分开记录幻想核、现象发生、触发与代价、具体事件、跨地点或时代通则；只确认前一层，不能自动升级后一层。

幻想先远行，归来不是退让。先保护最奇异、不可替代的幻想核，不为“真实可信”把它解释成幻觉、仪器、科学现象或常见套路；再选择故事真正调用的方向，让幻想获得血肉、阻力和遗痕：

| 归来方向 | 成真方式 |
| --- | --- |
| 故事归来 | 改变目标、冲突、选择、代价与结局，不只充当背景奇观 |
| 人物归来 | 进入身体、欲望、恐惧、偏见、关系和不可回避的选择 |
| 世界归来 | 改变普通人的生计、职业、交易、法律、器物、语言和生活习惯 |
| 历史归来 | 留下遗迹、地名、伤痕、档案冲突、权力叙事和被遗忘的过去 |
| 神话归来 | 形成信仰、仪式、禁忌和异文，让不同群体拥有不同解释 |

### 日用幻想与微弱响应

幻想进入衣、食、住、器时，先从材料、制作、长期使用、清洗修补、环境和照护关系形成可感变化。普通器物首先仍须能够被使用、损坏、替换、误读和重新分配；微弱响应可以改变当场动作、情绪、信任、分配或调查，也可以只服务身体感受、家庭关系和生活质地，不强制升级为线索、象征、伏笔或世界真相。

日用响应须写清证明上限。长期使用或关系遗痕不能自动验血、认亲、判清白、定师承、证明孝义或继承权，也不能替人物承担裁决。不同人物可以依身份、利益、知识与感情形成不同解释；若要让响应变强或稳定指认，须另行补足来源、触发、代价、失效、反制和社会后果，并经作者确认，不能因剧情需要临时把生活器物升级为万能证物。

器物之外的梦、异象、地貌、声音、影子或自然异常只新增一项可观察现象，不能自动鉴定文书真伪、权利归属或责任，也不能替人物还原完整历史、取得身份资格或获得正确行动方案。异常可以触发补证、复看和新的选择；它的感知上限、不同解释与误用后果仍须进入人物和现实因果。

不要求五层齐全；五层按故事需要取用，不机械凑齐，也不把人物和故事留到以后。幻想归来至少用一个人物、一个普通行动、一次不可回避的选择、一项实际代价和一个延迟或非预期后果做最小试片；若删除幻想后人物选择、关系、生活或后续条件都不变，它仍只是奇观或装饰，应退回归人或远游。用户明确要求完整方案时，在同一方案中用一个人物、一个场景、一次选择及其后果检验设定能否进入生活与因果，并覆盖上述普通行动、实际代价和延迟或非预期后果，而不是先写正式故事再补世界。长篇与超长篇的切片必须和全书外框、当前卷运行系统同时成立，不能代替前两层；承重缺口未决时只能交付明确标注的非正典压力测试。用户点名神系、部族、年表和力量表时不得擅自省略，未被故事调用的部分只能作为可裁剪候选，不提前升级为正典。

“成真”有两层：作者明确确认的内容只在对应粒度进入小说正典，未确认的现象、规则和事件仍为候选；已经进入正典的幻想再通过场景、行动、感官和余波成为读者可感的叙事现实。它不是现实史实，也不能反向伪装成古籍、地方志或传统原貌。

创见可以跨越现实，但必须选择约束。强大的力量至少回答来源、使用条件、代价、反制、社会后果和长期变形；宏大制度至少回答资源、执行、受益者、受损者、灰区和崩坏方式。

阴阳互用互制不是机械配对：秩序保护生活也可能压抑变化，力量解决危机也会制造依赖，秘密保护人物也会损害信任。两面应通过同一事件和后果显现，不另建说理章节。

### 幻想能力的定性回归、定量评测与回流

幻想能力的准出分三层，不能用一层替代另一层：

1. **定性硬门禁**：
   - 路由正确：纯发散停在天马行空；未调用幻想核的历史推演不误入幻想归来。
   - 奇异点保真：不把幻想降格为仪器、幻觉、常见血统或万能规则。
   - 归来有目的：明确它改变哪个人物的选择或哪项普通生活。
   - 验生有后果：至少有一个普通行动、一次不可回避的选择、实际代价和延迟或非预期反馈。
   - 证明有上限：异常不裁定文书、产权、血缘、责任、正统或完整历史。
   - 状态不越权：候选、幻想核、现象、触发与代价、具体事件、跨地通则和正典分别记录；未获确认不写回。
   - 失去奇异性时能退回发散，不靠继续加规则修补。

2. **定量比较**：定量只用于比较同一 runner/model 下的 baseline 与 candidate，不替作者确认正典，也不把文学价值压成单一分数。沿仓库行为评测契约使用 1--5 分：`S = 0.35*correctness + 0.25*autonomy + 0.20*actionability + 0.10*safety + 0.10*concision`；同时记录硬 blocker 数 `B`、硬门禁通过率 `H`、至少三次同配置试验的分差 `V = max - min`，以及 candidate 相对 baseline 的逐维回归 `R`。报告 `S` 时必须同时报告 `B/H/V/R`，不能只报加权均分。

3. **证据回流**：只有重复真实使用、fixture/validator 失败、独立 CR 或作者明确纠偏，才形成 Skill Improvement Card 候选。回流顺序为“记录触发与失败 → 定位到 SKILL/reference/fixture/script 的最小落点 → 先做静态与行为回归 → 再做同配置重复试验、盲评和人工复核 → Owner 确认后才可晋升”。source hash、case digest 只证明评测对象没有漂移，不证明能力变好；网络、模型或盲评不可用时停在候选，不自动改 Skill、同步、提交或发布。

**准出原则**：硬 blocker 未清零时，`S` 再高也不准出；`B=0` 仍需检查 `H`、`V` 和 `R`，并区分静态契约通过、真实行为改善、独立复核和作者正典确认四层证据。当前任务的一次好回答只能作为任务内回归样本，不能单独触发永久回流。
