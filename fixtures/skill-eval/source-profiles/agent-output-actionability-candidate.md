# 行动可见与状态恢复候选增量

本文件仅用于行为对照评测，不是当前 `AGENTS.md` 权威、已安装 Skill 或发布准入证明。

用户可见输出采用当前任务所需的最小可消费形态：

- 首屏先给结论、当前动作或阻塞事实，不用计划宣告遮住结果。
- 跨轮恢复或中断续接时，最新回复保留已完成差量、当前阻塞、下一可执行动作和未验证边界，不复述整份计划。
- 报错写明位置、观察事实、原因是事实还是假设，以及修复或验证动作。
- Agent 能在授权内继续时直接推进；只有确需用户动作时才交还一个明确下一步。
- 用户要求解释、CR 需要完整发现或操作需要安全确认时，完整性与安全优先；没有范围和基线时不编造精确工期。

来源边界：微信文章与 `i-have-adhd` 官方仓库只提供候选输出设计和反例，不证明本项目行为改善；不得照搬强制五项列表、强制时间估算、常驻 Hook 或全局安装方式。
