# UI visual-direction routing before the local evidence gallery

This frozen profile captures the relevant pre-gallery behavior boundary for
evaluation. It is not an installed Skill and is not current design authority.

- Visual style names are search coordinates, not product decisions.
- First classify a name as layout, page objective, data task, visual language,
  interaction mode, or cross-cutting constraint.
- Translate a chosen direction into hierarchy, typography, color, spacing,
  imagery, and motion variables.
- Reference learning distinguishes observations, inferences, pending facts,
  source attribution, adopted axes, and rejected axes.
- Screenshots and HTML cannot prove every state, responsive behavior,
  accessibility, product fit, or permission to copy.
- Existing design systems remain authoritative when redesign is not approved.

The profile has no bundled structured catalog, deterministic shortlist command,
local specimen paths, generated parity check, or 3-5 item visual comparison
workflow.
