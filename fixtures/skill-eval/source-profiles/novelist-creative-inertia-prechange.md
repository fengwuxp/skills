用户明确要求只发散、不选择、不解释、不落地时，除区分用户原话、外部事实、文学虚构和授权边界外，直接进入 `references/worldbuilding-and-research.md` 的“天马行空”，不先用察实、正名、审时和权衡步骤筛选候选；本轮止于可继续生长的文学虚构候选。用户显式要求会商或头脑风暴时，先发散，收敛前至少做一次去同构与反方复核；普通构思不强制多轮。

### 发散创见

同时接住积厚而发的材料积累与灵感天成的突现幻想；先保留不可替代的原始核，与后续加工分开。探索期允许候选互相矛盾、暂时无用、不可落地或没有解释，不因求真过早扼杀想象，也不因想象跳过事实和作者确认。

### 天马行空

探索期允许候选互相矛盾、暂时无用、不可实现或没有解释。用户明确要求只发散、不选择、不落地时，不强迫共享原因、统一世界观、人物主线、现实约束、代价、反制或回收，也暂不读取下方五层归来。候选不能只是替换名词、颜色或背景皮肤，应在主体、关系、因果、时空、感知、规则或叙事声音中至少形成一种真正不同的可能；错位、反转、移时、换尺度、换主体和规则变形只是可选手段，不作为机械配额。

用户显式要求会商或头脑风暴时，首轮先发散，收敛前至少做一次去同构与反方复核；不把第一份裁决包冒充头脑风暴结论，并检查候选是否只是换载体、换名称或共享同一因果，让反方指出被忽略的主体、代价和替代解释。该复核只在显式会商、头脑风暴或候选明显同构时启用，普通构思不强制多轮，也不在发散轮提前用可行性筛掉奇异方向。

### 长时段去同构与剧情转化

长时段大纲继续扩写前，暂时隐去人物和朝代名称，检查相邻阶段是否可以任意互换，是否反复沿用 `发现前弊 -> 推出纠偏 -> 纠偏异化 -> 后继者再纠偏`。修正不是把结果逐项反转，也不是为了多样而机械分配变化轴。修正后再隐去人名、制度名和异兽名复查一次；若各阶段仍是 `危机 -> 英雄牺牲 -> 新制度 -> 新隐患`，只是换了变化轴和名词，去同构尚未完成。

### 人物刻画

人物决策模型不是创伤清单。`错误信念或旧伤 -> 保护策略 -> 认知盲区 -> 脆弱触发 -> 压力下独有的选择 -> 代价`只是一条追问路径，不是唯一公式；某一环不适用就删去，不为填模板制造创伤。人物行动可以由情、理、欲、关系、身体、处境与偶然共同作用。

人物底色、过往与当场处境分层处理：先确认不依赖单一事件仍稳定存在的欲望、价值边界、亲疏方式和责任习惯，再判断过往经历怎样把它偏转成保护策略、敏感点、误判或债务，最后让当前时间、地点、身体、知情、关系与具体刺激共同决定本次选择。

先写具体的人，不先写好人、坏人、伟光正、纯恶或“人人自私”的结论。动机可由关系、利益、恐惧、责任、偏见、爱、虚荣、控制欲、疲惫和处境共同作用。

人物弧光不是性格标签翻面，而是同一核心矛盾在更大压力下反复受试。群像先保证欲望、声音、行动方式和承担后果各有区别，再用共同事件让人物互相照见；不靠外貌、口头禅或身份名称制造表面差异。
