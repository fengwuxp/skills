# 创作惯性、想象力与人物去同构

## 使用时机

作者指出想象力匮乏、模板化、脸谱化、又像前案，或同一项目正连续设计一批承重人物、事件、势力与神异时读取。普通一次性构思或作者明确要求镜像时不启用识骨与负空间；已经选定分支时不重开发散，但仍可按需只读“场景贴合预检”。正典确实要求重复的救援、道路、记录、责任或其它母题继续承接。

## 识骨与负空间

定向回看最近相关设计，不扫描全库。先分开作者明确要求的正典、题材约束和有意母题回声，与 Agent 近轮反复生成的创作残留；再隐去专名、朝代、器物和奇观外壳，把各案压缩为：

```text
发动者及其欲望或压力 -> 主要动作 -> 资格、关系或冲突怎样改变 -> 不可逆选择 -> 代价与收束
```

多案删名后仍可互换，只算一个因果发动机。伤者换灾民、舟路换山道、账册换石刻、仪式换面具、庭院换梦境，都不能单独构成新设计。

下一轮只冻结硬正典、人物不可丢失的关系条件和作者明确保留的回声；对创作残留建立一次性负空间，让其暂时降权。负空间不是永久禁词表、题材配额或全项目新规则。按当前问题改变少量高杠杆轴即可：发动主体、私人欲望、社会场域、幻想规则、时间形状、情绪温度、不可逆选择或代价类型，不机械填满维度。

## 生成与校准

首轮先从图景、动作、声音、身体感受、荒诞关系、私欲、虚荣、玩心、审美、误会、竞争与偶然中打开可能。事实边界和作者硬约束始终生效；证明上限、受益受损、公共承责、普通生活验收与经世镜片只校准已经出现的候选，不替首轮供应统一题材、机构和道德弧。作者要求选择、成形、写入或检验时，再恢复完整正典、人物、世界、后果和责任校准。

## 场景贴合预检

想象或幻想开始前，先判断本轮要停在纯发散，还是要进入当前故事的成形与行动。对后者，从当前权威和输入中只抽取本层真正可用的少量条件：视角与在场者、地点与时段、当下所求、已知或误知、身体与资源限制、正在发生的其它行动，以及不能改动的正典。缺一项就标为未知或准入缺口，不用百科补齐。

成形时把候选放回一个实际场景，问它是否改变当场的注意、动作、选择、关系、信息、资源或风险；再写出触发、范围、代价、失败或误用的最小边界。删去候选后场景仍完全同样，候选就留在素材或发散层；不能为了证明幻想有用，强行把它升级成线索、证物、制度或主线谜底。纯发散可以只保留与场景的潜在接口，不提前承担这些后果。

贴合不是把每个幻想压成同一现实题材。候选与场景不合时，优先裁剪、延后、改变呈现位置或保留多解；只有作者选择并要求落地后，才让它进入人物和后果。检查过程中始终保留人物有限知情、消息与移动时效，以及未出场行动者的独立目标。

硬正典或作者选核没有明确规定时，机缘只改变机会与选择空间，不能替人物完成核心选择。形式名位可以依已确认的荒诞规则、程序、血统、神器、祖训或仪式偶然到手，但实际承责、关系变化与后续资格仍须由人物的欲望、判断和行动继续完成。高概念外壳若共享同一资格来源与人物选择，只算一案。

日用神异可以只改变游戏、审美、身体、亲密、劳动节奏、梦或无目的的生活经验，不必统一成为证物、认亲、复核或治理装置；进入承重因果后再核证明上限与后果。

## 人物生命余量

连续人物先删名比较心理发动机、常用动作、关系表达、压力选择、代价类型和声音。若多人都可压缩为 `旧伤 -> 少说多做 -> 独担或保护过度 -> 受损 -> 学会交还或共同承责`，不能靠换创伤、身份或口头禅扩人；保留共同命题，重生其中一人的欲望、判断、行动或关系后果。

重要人物可以拥有不证明品德、不解释创伤、也不承担伏笔的生命余量：享乐、虚荣、厌烦、审美、玩心、羞耻、透明的小谎、无用的手艺或单纯想赢。按需给一个没有灾难、救援或重大职责的生活切片；阶段人物和简单人物已经成立时不强加癖好、阴暗面或隐藏秘密。

做人物不可替换反查：换成同阵营另一人后，注意对象、欲望、判断、可接受代价、行动链和关系后果是否仍原样成立；删去姓名与口头禅后，能否从句法、社交距离、所见所避和当场所求认出他。输入没有提供足够人物事实时，标为准入缺口，不为证明差异擅造前史。

关键候选仍可互换时，从本人、亲近者、竞争者或利益受损者、普通旁观者中，按当前差异选择最少必要且彼此有实质冲突的临时站位，分别推演其先注意什么、误解什么、想得到什么、会做什么。站位不投票决定作者本真，也不创建持久人格或第二人物 Owner；各方若只复述同一作者命题，退回人物欲望与关系重新生成。

## 最小交付

识骨、负空间和人物反查默认在内部完成。作者要求诊断依据、比较分支或解释为何重做时，才用最短自然语言说明保留的正典回声、实际重复的骨架和本轮差异；不规定句数、字段、配额或固定前置格式。纯发散只需保持候选状态，选核后恢复完整校准；只交付正文时不展示方法。
