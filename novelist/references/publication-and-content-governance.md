# 公开传播与内容治理

## 使用时机

仅在作品准备投稿、公开连载、出版、签约、商业改编，或用户明确要求核验文化管理、平台规则、`清朗`、`净网`、AI 标识时读取。私人构思和未公开母稿不默认进入发布准入审查。

本文件是小说家的发布适配方法，不是法律意见、平台审核结果或永久禁题清单。时效规则必须在使用当日重新核验官方原文。

## 创作与发布双轨

- **创作母稿**：承载作者正典、文学选择和探索空间。发布适配不得原地覆盖；即使作者要求替换，也先保留可恢复的母稿版本，再生成独立适配稿。
- **发布适配稿**：面向一个已确认法域、平台、受众和发布形态的独立版本，保留与母稿的差异、依据、待确认项和回退路径。
- 私人稿可以按用户要求标记风险候选，但不套用不存在的“所有平台统一规则”，不承诺“绝对安全”。
- 只有进入公开传播准备，才核验当期规则并形成发布准入建议；建议不能替代作者、编辑、平台、法务或主管机关裁决。

## 四层权威

按下列顺序核验，不得混成一张禁词表：

1. **现行法律法规与部门规章**：确认发布机关、施行日期、适用法域、对象与行为。区分现行有效、发布但尚未施行、已废止和仅征求意见。
2. **主管机关专项行动与执法案例**：记录机关、时间、行动周期、整治对象和行为语境。`清朗` 是网信部门专项治理系列，`净网` 通常是公安机关打击网络违法犯罪的行动口径；二者不能互相替代，也不自动形成永久禁题。
3. **目标平台当期规则**：只核验实际投稿平台的用户协议、社区规范、内容发布、版权授权、签约、类别篇幅、AI 使用与标识规则。不得把起点规则用于番茄，也不得用平台公告替代法律。
4. **责任人确认**：作者决定文学取舍；编辑和平台确认内容、签约与发布要求；版权、合规或高风险问题交法务及相应专业方确认。

## 发布准入信息

开始核验前确认：

```text
发布状态：私人稿 / 内部评审 / 投稿 / 公开连载 / 出版 / 商业改编
目标法域：
目标平台与规则版本：
目标读者 / 年龄：
作品形态：长篇 / 短篇 / 有声 / 影视或其他改编
AI 参与及平台标识要求：
版权、授权、真实人物与现实事件素材：
核验日期与官方来源：
需确认的作者 / 编辑 / 平台 / 专业方：
```

目标平台或发布形态未定时，到“风险候选清单”停止，不作平台准入结论。

## 核验与适配

1. 从主管机关和目标平台官方页面读取现行原文；记录标题、发布机关、发布日期、施行日期、核验日期和适用范围。不得使用模型记忆补当前规则。
2. 分别检查内容合法性与传播语境、未成年人保护、著作权及人格隐私、真实事件与虚构标识、AI 生成合成内容标识、平台签约和授权条件。没有材料信号的专题不机械展开。
3. 区分“描写某题材”与“美化、教唆、提供可执行方法、冒充现实事实或面向特定受众传播”。不得仅凭题材关键词判定违规。
4. 对专项行动和执法案例只吸收其已证实的对象、行为和风险机制，不外推为全平台、永久、所有小说均适用的禁令。
5. 在发布适配稿中以最小改动处理：优先调整虚构标识、现实主体混淆、宣传包装、受众分级、AI 标识和必要语境；只有权威规则、平台要求或责任人裁决支持时才删除正文。

## 停止条件

- 官方原文、施行状态、目标法域或目标平台无法确认：标记未核验并停止，不给“可发布”结论。
- 涉及现实人物、未成年人权益、重大公共事件、版权归属、独家授权、商业合同或法律责任：转交相应专业方确认。
- 作者不同意发布适配改动：保留母稿与候选建议，不代替作者定稿。
