# 古典白话文与汉语行文

## 使用时机

用户要求古典白话文、章回小说气韵、句读、汉语句法、古典小说语体，或正文需要在古雅与可读之间定调时读取。只写分析、规划、校验、项目文档或现代题材正文时不默认套用本节。

## 最高优先级与边界

在已经确认作品类型、时代、叙述者、POV 和人物声音后，正文默认按以下优先级校准：

1. **古典白话文为叙述底色**：以现代读者能顺畅理解的白话句法为骨，以古典小说常见的叙事分寸、称谓、语气、句读和节奏调气。
2. **汉语表达先于翻译腔**：让动作、关系、话意和语气在汉语的语序、意合、动词和虚词中自然相接，不把英文式主语重复、抽象名词堆叠或逻辑连接词硬译进正文。
3. **人物与场景声音高于统一腔调**：叙述者、不同人物、不同阶层和不同处境可以有差异；古典白话是共同底色，不是让所有人说同一种话。
4. **清楚、气韵和力量并存**：句子可长可短，依注意、呼吸、动作和情绪伸缩；力量来自具体动词、名物、选择与后果，不来自生僻字、空泛赞叹或连续排比。

“三国”“水浒”“西游”“红楼”是第一优先级的**功能参照**，不是四种腔调拼盘，也不是要求仿写某一作者。可分别借鉴：叙事的简峻与局势推进、口语的活泼与人物出场、奇诞的伸缩与机锋、日常关系的细密与含蓄；每次只取当前场景有用的一两项。不得复制原句、人物口吻、标志性套语、专名、情节或把书名变成固定模板。

## 句读、气韵与生命力

- **先读语义再定标点**：逗号承接动作、注意和话意；分号或句号承担转折、落点和局势改变；顿号只列同层短项；破折号、省略号和冒号须有明确的声音、停顿或说明作用。标点是句读，不是把每句切碎的排版工具。
- **长短相济**：铺陈、回忆、景物、思绪和连续动作可以用有层次的长句；决定、突变、反击、惊惧和落槌可以用短句。长句内部要有主次和呼吸，短句不能把完整汉语意脉切成电报。
- **气韵相连**：后一分句接住前一句留下的动作、目光、物件、话意或情绪，再转、再收；段落有起、承、转、落，不让金句、比喻和感叹彼此争抢。
- **力量落在动词与后果**：少写“十分、极其、无比”一类空加力，改看人物怎样做、怎样忍、怎样失手，以及别人和环境怎样回应。句子悠长不等于松散，痛快不等于喧闹，舒服不等于软弱。
- **允许直抒与留白并存**：处境足够时可以直写“我怕”“她想他”；不把所有情感都改成攥手、抿唇、移步，也不把所有情绪解释到读者无处回味。

## 汉语特性检查

写完一段后，优先检查以下问题：

- 是否让动词带着句子走，少用抽象名词把行动冻住。
- 是否让主语、话题和施事按语境自然省略或转换，避免每句强行重复同一主语。
- 是否用“了、着、过、便、却、还、只、倒、原来”等虚词和语气组织时态、状态、转折与声气，而不是堆叠“因此、然而、与此同时、值得注意的是”。
- 是否保留量词、称谓、方位、程度和语气的汉语分寸；同一词在叙述者、人物和时代中的语体是否相称。
- 是否出现现代翻译腔、抽象政策腔、网络口头禅或整齐排比压过人物正在做的事。

### “的”字的收放

“少用‘的’”可以作为朗读时的提醒，不能变成禁词或计数指标。古典白话的气息不由某一个字的多少决定，先辨“的”在本句承担什么作用：

- **必要时保留**：领属关系、定语边界、指称范围、歧义消除和人物自然说话都需要“的”时，不为追求古雅强删。
- **可删时收束**：连续出现“的”而不增加限定，或把本来能由动词、并列、语序直接表达的动作压成层层定语时，可改成更紧的汉语句式。
- **替换要看气口**：可用动词、短分句、并列、方位或自然省略承接，但要保持施事、时态、关系和语义清楚；不为少一个“的”制造歧义、倒装或文言腔。

复读时看“的”字链是否让句子滞重、视线反复回折；不要按全文数量或固定阈值批量删除。训诂检查也不以“的”字少作为古意证据，而看词在句中的语法、语境和时代层级。

## 训诂与外部学习的边界

需要使用古语、成语、熟语、称谓、器物名或时代词时，先问它在本句的语法位置、语境义、感情色彩和时代层级；字形相近、现代同音、后世常见或模型记忆不能单独证明用法。涉及字源、异体、通假、音韵、训释或时代语感的事实，转读 `hanzi-philology` 的证据方法与对应 reference；无法核验时保留现代白话或文学构义，不硬造古意。

外部小说学习只提取可迁移的功能：叙述距离、人物出场、对话关系、句读节奏、日常细节、奇诞与现实的切换、局势推进和余波回收。样本不足时不把印象写成规律；不以古语数量、半文半白比例、固定句长或标志性意象证明“有古意”。现有外部来源索引和合成案例只作学习边界，不能替代作者样本、正典、场景事实或真实读者验证。

## 最小复读

正文交付前，先通篇朗读一遍，再作一次回读复审。朗读重在听出句读、声气和气口，不是把文字读得古雅：

1. 看清谁在看、谁在说、谁在做；人物所知、叙述者所知与读者所知是否各安其位；
2. 看句读是否随动作、注意、情绪和信息变化；该连处有没有被切碎，该断处有没有无故拖长；
3. 看段落是否接住前一句留下的动作、话意、目光或情绪；是否出现解释腔、翻译腔、生硬古语或声气突断；
4. 删除装饰性字句后，人物选择、关系变化、场景气息和后果是否仍然站得住；若只剩动作流水，说明删过了，应补回必要的话意、感受和连接；
5. 看末句是否保留本段实际需要的动作、话意、情绪或余波；场景本应静收时，不强造钩子、象征或余波，也不替作者宣布“这一刻意义重大”。

遇到古语、成语、称谓、器物名或熟语，再作一次训诂小检：核对它在本句中的语法位置、语境义、时代层级、感情色彩和人物语体。涉及字源、异体、通假、音韵、训释或时代语感时，转读 `hanzi-philology` 的证据规则；没有依据，就用清楚的白话或明确的文学构义，不用生僻词硬造古意。

这套复读只校准表达，不替代正典、因果、人物知情、时序和正文准入检查；表达漂亮也不能掩盖故事缺口。
