# 世界构建与研究

## 使用时机

故事涉及天文地理、人文历史、神话传说、制度风俗、社会运行或东方幻想时读取。长篇与超长篇正式开写前也要读取，用于建立与篇幅、类型和当前叙事半径相称的世界背景；只深入研究故事真正调用的部分。

## 四层材料

| 层级 | 含义 | 写作规则 |
| --- | --- | --- |
| 事实 | 已核验的自然、历史、制度或文本材料 | 标记来源、时代和适用范围 |
| 传统说法 | 文献记载、地方传说、传统训释或后世整理 | 说明版本、流变和争议 |
| 合理推演 | 基于事实与约束形成的创作假设 | 允许反证，不写成真实历史 |
| 文学虚构 | 为主题、人物和情节创造的设定 | 保持内部一致，不伪称有史料依据 |

需要当前外部事实时读取一手或官方材料；正文不可得时停止下事实结论。古籍字词、异文和训诂交给 `hanzi-philology`，其证据只限定可借用范围，不替作者创作。

## 反常识材料

- **事实与见闻**：低概率不等于不真实，反常识也不等于材料有误；同样，故事听来合理不能补足证据。多份材料同向记载也可能同源；未核验来源独立性与可靠性前，只称共同记载的事实主张，不称已确认事实。保留已核验来源的一致或冲突状态，不为提高可信度改写记录、补统一动机或替未知结局下结论。
- **传说与异文**：传说异文不必归并。不同版本可以分别属于地域、群体、时代或人物立场，也可以共同构成故事中的未知；版本本身不自动证明超自然或历史真相。
- **文学改编**：可以选择、合并或重构版本来服务故事，但要标记合理推演或文学虚构。文学改编不能反向改写来源，也不能把作者选择伪装成地方志、口述者或史料原结论。

已核验而荒诞的真实事件，优先保留事实，调整视角、揭示顺序、细节密度和人物反应来建立可信度；无法核验的奇闻，则保留来源状态和不确定性，不因“现实往往更荒诞”自动采信。

## 历史、传说与志怪的长期演进

### 六层历史真实

长期叙事不把历史写成唯一可靠记录；历史可以被改写，不同版本不因此同等可信。按需区分：

1. **事件本真**：实际发生什么；只冻结跨期因果与读者承诺需要的本真下限。
2. **亲历之实**：不同人物看见、误解、隐瞒或无法理解什么。
3. **初始记录**：谁在何时为谁记录，受什么能力、材料、责任和目的限制。
4. **流传变形**：记录怎样被保存、散佚、删改、附会、禁毁或重新编定。
5. **后世版本**：正史、家族记忆、宗门异文、地方传说和志怪各保存什么，又携带什么立场。
6. **现实遗痕**：地貌、器物、制度、仪式、禁忌、语言和生活后果如何互证或反证版本。

承重历史须有最低作者本真；不承担承重因果的来源、形态或结局可以保持**开放未知**。开放未知是有意不定案，不是待补漏洞；留白不得掩盖人物选择、受损者、现实后果或本作已经建立的承诺。

### 历史记忆分流

形成异文时先问讲述者、时代、对象与现实作用：谁为何这样讲，它怎样改变行动。权势版本可能保存准确日期而改写责任，民间传说可能弄错人物却保存真实代价；以来源独立性、可观察遗痕和现实后果判断可证上限，不按正史、野史或传说标签预判真假。

同一异事按叙事职责处理：

- **承重志怪**：改变主线因果，须回收相关人物选择、责任与代价；形而上的来源仍可留白。
- **支流志怪**：改变人物、关系或地方生活，完成局部后果即可，不必接入终极谜底。
- **背景异闻**：只留下幽深感时，保证表现、代价与余波前后一致，可以始终不可解释。

三类不必汇入同一幕后真相。世界允许偶然、荒诞和彼此无关的异事；不得为结构工整把世界机制、神祇、遗物或其他承重设定变成万能解释。

### 时代交接

长期规划沿 `前代遗产 -> 当代压力 -> 人物与共同体选择 -> 制度和生活变化 -> 收益、代价与反作用 -> 记忆沉积 -> 后世复验` 推进。每次时代跃迁只明确：

- 前代留下、失传和误传什么，谁仍承担旧代价；
- 世界规则、责任归属、制度与普通人的生活与选择余地发生什么变化；
- 后世人物如何通过遗迹、制度、仪式、禁忌或生活后果，在有限证据下重新判断并行动；
- 新选择留下什么可追踪后果，又怎样成为下一代的历史版本。

当前阶段明确人物、事件和代价；下一阶段明确继承、断裂与新压力；遥远未来只保留不可推翻的承诺、变化方向和开放问题。没有故事发动机时，不提前冻结人物名单、卷目、完整年表或终局。

## 篇幅分层的世界准备度

“相对完善”不是把所有名称、年表和数据写尽，而是让当前叙事半径内的世界离开主角仍能运行，重大行动、制度摩擦与偶然事件能够沿真实关系传导到普通人的生活。正式开写前先扫描下列世界系统，找出会推翻故事发动机、开篇因果、当前卷和长期承诺的缺口；只深入冻结承重规则及跨系统依赖，其余保持候选、开放未知或按剧情调用扩建。

先分别判断**篇幅体量**与**叙事范围**。篇幅提高承重规则需要稳定的时长、反馈深度和变化层级；叙事范围决定要预建哪些地点、群体和时代。三百万字的单城单代故事应深化一地的行业、制度、关系与长期反馈，不凭字数扩造国家和时代；两万字的跨时代故事仍须锁定少数跨期硬约束，不因篇幅短省略真正承重的时代变化。

| 作品承诺 | 正式开写前的准备深度 |
| --- | --- |
| 短篇或局部故事 | 建立当前地点、时令与天气、身体与物质条件、生计、核心关系、地方秩序和故事调用的信俗，使一次选择及其直接后果成立；确有跨地域或跨时代跳跃时，只追加保证各段成立的少数硬约束。 |
| 长篇或持续区域故事 | 在局部生活之上建立作品实际调用范围内的社会运行骨架，明确自然环境、人口共同体、生产流通、聚落、治理秩序、知识技术和信仰记忆怎样相互制约；单城故事向纵深和长期反馈发展，不为显得宏大扩造地图。 |
| 超长篇且确有跨地域、跨时代承诺 | 再建立实际涉及的区域之间与时代之间的演进骨架，能推演人口迁徙、资源循环、灾害疫病、财政物流、战争继承、技术制度变化、文化分化融合和历史记忆如何产生长期反作用；没有这类承诺时不强制增加。 |

篇幅只提高预建深度与稳定时长，不机械规定设定数量、地域数量或时代跨度。所谓准备完成，是当前故事所依赖的世界可以推演，不是作者已经知道世界的一切。

长篇与超长篇的“当前叙事半径”不得缩成第一章。正式首章至少同时准备三个嵌套层级：**全书外框**冻结世界硬规则、地理政治边界与长期变化轴；**当前卷运行系统**说明本卷地域内人口、资源、制度、势力和生活怎样相互作用；**开篇生活切片**把这些压力落到具体人物、地点和一次选择。三层都只确定承重部分，但不能用一个局部切片代替前两层，也不能只裁决开篇分叉便宣告长篇世界已足够正式开写。世界系统扫描的每一项都标为已确认、承重候选、待确认、按剧情扩建或范围外，不因暂不深入而静默省略。

### 世界系统扫描

- **天、时与尺度**：天象、昼夜、历法、纪年、节令、计时、度量衡及其对农事、航行、仪式和灾异判断的影响。
- **地、生境与资源**：地形、水系、气候、生态、物种、矿产、能源、灾害、距离、地图与疆域认知；人物实际知道的地理不得超过测绘、交通和消息能力。
- **人口与共同体**：人口规模和密度、出生死亡、亲族家庭、性别年龄、阶层职业、族群、语言方言、迁徙流民及不同群体的合作、偏见与边界。
- **民生与生产流通**：衣食住行、农牧渔猎、手工业、劳役、职业、土地、交易、货币、借贷、财政税赋、仓储物流、市场与黑市，以及繁荣、短缺和物价怎样分配。
- **聚落与基础设施**：都城、城池、乡镇、村落、边地、建筑、水利、道路、驿站、港口、运输、通信、公共空间和城乡交换；方志与地图只能呈现记录者可知的世界。
- **制度、律法与权力**：政体、官僚、地方自治、礼俗规则、司法刑罚、治安、军队、战争、外交、情报、犯罪和势力分布；区分纸面制度、实际执行、灰区与谁能例外。
- **知识、科技与照护**：材料、工具、工艺、能源、科技、医学、公共卫生、教育、文字、档案、媒介和信息传播；知识的发展、垄断、失传和误传都须受资源与组织能力限制。
- **信仰、传说与历史记忆**：宗教、神话、仪式、禁忌、节庆、丧葬、民间传说、志怪、口述传统、地方志、正史与异文；它们改变身份和行动，不自动证明超自然或历史真相。
- **身体与日常人生**：孕育出生、童年、婚恋、继承、疾病残障、衰老死亡、饮食卫生、作息娱乐、穿着举止和生活习惯；普通人不是等待主线调用的布景。
- **幻想与异常力量**：来源、条件、代价、反制和长期变形之外，还要检查它怎样改变生态、生产、职业、法律、战争、医药、教育、信仰与普通人的生存；只改变战力等级，尚未构成活的幻想世界。

### 系统闭环与正文准入

先问“这项设定将改变谁的什么选择”，再沿系统关系追问：资源与硬约束从何而来，谁能观察、决定、执行、抵抗或规避，书面规则与实际做法有何差异，收益与代价怎样分配，灰区、失灵、偶然和反作用怎样回来。不要把维度写成彼此孤立的名录；例如 `历法与气候 -> 农事 -> 税粮与仓储 -> 价格、迁徙与军役 -> 疾病、治安与信仰` 应能连续传导。

世界不围着主角运转：主角不在场时，环境、百姓、机构、对手、动物、疾病、资源与消息仍按各自条件变化；不同地域、阶层和组织可以拥有相互冲突的规则、记录与常识。制度不必完美理性或贯彻到底，意外也不必服务主线，但人物必须在有限认知和真实后果中行动。

进入正式正文前，只确认作者已经定案或明确授权 Agent 自决的承重规则。会推翻当前故事发动机、开篇核心选择、卷级因果或长期承诺的世界缺口未决时，继续讨论或交付标明边界的非正典压力测试；其他内容保留为可裁剪候选并随故事扩建。一次只展开当前主 blocker，不等于只需确认一个决定；所有承重 blocker 关闭前，不得宣告长篇已经具备正式开写条件。用户明确要求完整名录或体系时可以交付，但不能因产物完整就称为正典。

用户要求“开写前的世界背景方案”时，按需交付这张最小准备度卡，不能只给开篇场景：

```text
作品规模与三层叙事半径：
已确认 / 候选 / 待确认：
全书外框与长期变化轴：
当前卷运行系统：
逐项扫描状态（不得缺项，可标按剧情扩建）：
  天时尺度 / 地与生境资源 / 人口共同体 / 民生生产流通 / 聚落基础设施 /
  制度律法权力 / 知识科技医学教育与信息 / 信仰传说历史记忆 /
  身体与日常人生 / 幻想与异常力量
开篇生活切片：
跨系统传导链与失灵方式：
阻止正式开写的承重缺口：
可按剧情扩建、不必预写的内容：
```

只复述用户点名的领域、遗漏未点名的系统，不算完成世界背景方案；发现暂不承重的领域，明确标为按剧情扩建或范围外即可，不为填表发明设定。

## 命名适配与证据边界

给人物、地名、阵营、器物或制度命名时，先确认实体功能、世界文化、阵营气质、叙事语气、现有近名和不得提前揭示之事，再从意义、声音、世界历史或有意反差形成少量不同方向候选。检查同类实体是否可读可辨、近音近形混淆、意外含义、文化或宗教负载、正典冲突和剧透；候选方向未经作者确认不得写成最终名称。

文学构义只需在当前世界和叙事中成立。真实古语、汉字字源、音韵、训诂和时代语感断言交给 `hanzi-philology` 核验；无法核实时保持文学构义或待确认，不用命名网站、模型记忆或伪出处补证据，也不批量改写既有正典名称。

## 天马行空与幻想归来

### 天马行空

探索期允许候选互相矛盾、暂时无用、不可实现或没有解释。用户明确要求只发散、不选择、不落地时，不强迫共享原因、统一世界观、人物主线、现实约束、代价、反制或回收，也暂不读取下方五层归来；本轮止于可继续生长的文学虚构候选，不替作者筛选或升级正典。候选之间可以矛盾；被作者选择并进入当前创作单元后，仍须服从已确认正典、三层真实和后果自洽。

### 幻想归来（成真）

只有作者要求选择、成形、写入故事或检验可用性时，才从候选中选择幻想核进入归来；若成形后变得常规、工整或可预测，可以退回天马行空重新发散。

幻想先远行，归来不是退让。先保护最奇异、不可替代的幻想核，不为“真实可信”把它解释成幻觉、仪器、科学现象或常见套路；再选择故事真正调用的方向，让幻想获得血肉、阻力和遗痕：

| 归来方向 | 成真方式 |
| --- | --- |
| 故事归来 | 改变目标、冲突、选择、代价与结局，不只充当背景奇观 |
| 人物归来 | 进入身体、欲望、恐惧、偏见、关系和不可回避的选择 |
| 世界归来 | 改变普通人的生计、职业、交易、法律、器物、语言和生活习惯 |
| 历史归来 | 留下遗迹、地名、伤痕、档案冲突、权力叙事和被遗忘的过去 |
| 神话归来 | 形成信仰、仪式、禁忌和异文，让不同群体拥有不同解释 |

不要求五层齐全；五层按故事需要取用，不机械凑齐，也不把人物和故事留到以后。用户明确要求完整方案时，在同一方案中用一个人物、一个场景、一次选择及其后果检验设定能否进入生活与因果，而不是先写正式故事再补世界。长篇与超长篇的切片必须和全书外框、当前卷运行系统同时成立，不能代替前两层；承重缺口未决时只能交付明确标注的非正典压力测试。用户点名神系、部族、年表和力量表时不得擅自省略，未被故事调用的部分只能作为可裁剪候选，不提前升级为正典。

“成真”有两层：经作者确认后成为小说正典，通过场景、行动、感官和余波成为读者可感的叙事现实；它不是现实史实，也不能反向伪装成古籍、地方志或传统原貌。

创见可以跨越现实，但必须选择约束。强大的力量至少回答来源、使用条件、代价、反制、社会后果和长期变形；宏大制度至少回答资源、执行、受益者、受损者、灰区和崩坏方式。

阴阳互用互制不是机械配对：秩序保护生活也可能压抑变化，力量解决危机也会制造依赖，秘密保护人物也会损害信任。两面应通过同一事件和后果显现，不另建说理章节。

## 停止条件

- 扩写超出全书外框、当前卷运行系统与开篇生活切片，且不影响承重系统依赖。
- 关键史实、文献或地理来源尚未核验。
- 设定扩展不能改变人物选择、冲突或后果。
- 完整名录、地图、年表或力量表会早于故事冻结不必要细节。

命中任一项时停在候选或局部切片，回到故事主线。
