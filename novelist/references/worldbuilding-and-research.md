# 世界构建与研究

## 使用时机

故事涉及天文地理、人文历史、神话传说、制度风俗、社会运行或东方幻想时读取。只研究当前故事真正调用的部分。

## 四层材料

| 层级 | 含义 | 写作规则 |
| --- | --- | --- |
| 事实 | 已核验的自然、历史、制度或文本材料 | 标记来源、时代和适用范围 |
| 传统说法 | 文献记载、地方传说、传统训释或后世整理 | 说明版本、流变和争议 |
| 合理推演 | 基于事实与约束形成的创作假设 | 允许反证，不写成真实历史 |
| 文学虚构 | 为主题、人物和情节创造的设定 | 保持内部一致，不伪称有史料依据 |

需要当前外部事实时读取一手或官方材料；正文不可得时停止下事实结论。古籍字词、异文和训诂交给 `hanzi-philology`，其证据只限定可借用范围，不替作者创作。

## 反常识材料

- **事实与见闻**：低概率不等于不真实，反常识也不等于材料有误；同样，故事听来合理不能补足证据。多份材料同向记载也可能同源；未核验来源独立性与可靠性前，只称共同记载的事实主张，不称已确认事实。保留已核验来源的一致或冲突状态，不为提高可信度改写记录、补统一动机或替未知结局下结论。
- **传说与异文**：传说异文不必归并。不同版本可以分别属于地域、群体、时代或人物立场，也可以共同构成故事中的未知；版本本身不自动证明超自然或历史真相。
- **文学改编**：可以选择、合并或重构版本来服务故事，但要标记合理推演或文学虚构。文学改编不能反向改写来源，也不能把作者选择伪装成地方志、口述者或史料原结论。

已核验而荒诞的真实事件，优先保留事实，调整视角、揭示顺序、细节密度和人物反应来建立可信度；无法核验的奇闻，则保留来源状态和不确定性，不因“现实往往更荒诞”自动采信。

## 历史、传说与志怪的长期演进

### 六层历史真实

长期叙事不把历史写成唯一可靠记录；历史可以被改写，不同版本不因此同等可信。按需区分：

1. **事件本真**：实际发生什么；只冻结跨期因果与读者承诺需要的本真下限。
2. **亲历之实**：不同人物看见、误解、隐瞒或无法理解什么。
3. **初始记录**：谁在何时为谁记录，受什么能力、材料、责任和目的限制。
4. **流传变形**：记录怎样被保存、散佚、删改、附会、禁毁或重新编定。
5. **后世版本**：正史、家族记忆、宗门异文、地方传说和志怪各保存什么，又携带什么立场。
6. **现实遗痕**：地貌、器物、制度、仪式、禁忌、语言和生活后果如何互证或反证版本。

承重历史须有最低作者本真；不承担承重因果的来源、形态或结局可以保持**开放未知**。开放未知是有意不定案，不是待补漏洞；留白不得掩盖人物选择、受损者、现实后果或本作已经建立的承诺。

### 历史记忆分流

形成异文时先问讲述者、时代、对象与现实作用：谁为何这样讲，它怎样改变行动。权势版本可能保存准确日期而改写责任，民间传说可能弄错人物却保存真实代价；以来源独立性、可观察遗痕和现实后果判断可证上限，不按正史、野史或传说标签预判真假。

同一异事按叙事职责处理：

- **承重志怪**：改变主线因果，须回收相关人物选择、责任与代价；形而上的来源仍可留白。
- **支流志怪**：改变人物、关系或地方生活，完成局部后果即可，不必接入终极谜底。
- **背景异闻**：只留下幽深感时，保证表现、代价与余波前后一致，可以始终不可解释。

三类不必汇入同一幕后真相。世界允许偶然、荒诞和彼此无关的异事；不得为结构工整把世界机制、神祇、遗物或其他承重设定变成万能解释。

### 时代交接

长期规划沿 `前代遗产 -> 当代压力 -> 人物与共同体选择 -> 制度和生活变化 -> 收益、代价与反作用 -> 记忆沉积 -> 后世复验` 推进。每次时代跃迁只明确：

- 前代留下、失传和误传什么，谁仍承担旧代价；
- 世界规则、责任归属、制度与普通人的生活与选择余地发生什么变化；
- 后世人物如何通过遗迹、制度、仪式、禁忌或生活后果，在有限证据下重新判断并行动；
- 新选择留下什么可追踪后果，又怎样成为下一代的历史版本。

当前阶段明确人物、事件和代价；下一阶段明确继承、断裂与新压力；遥远未来只保留不可推翻的承诺、变化方向和开放问题。没有故事发动机时，不提前冻结人物名单、卷目、完整年表或终局。

## 按剧情调用

先问“这项设定将改变谁的什么选择”。没有答案时只留占位。用户明确要求完整名录或体系时可以交付，但必须标记为可裁剪候选，不能因产物完整就称为正典：

- 天文历法：影响时间、节令、航行、农事、仪式或灾异。
- 地理气候：影响距离、补给、产业、疾病、战争、迁徙和地方性格。
- 人文历史：影响身份记忆、合法性、创伤、偏见、盟约和利益。
- 制度经济：影响谁有权决定、资源从何而来、规则如何执行、失败由谁承担。
- 神话信仰：影响人物如何解释世界、举行仪式、建立禁忌和面对未知，不自动证明超自然真相。

世界不只由统治者和强者组成。至少检查普通人的生计、交通、婚丧、疾病、教育、交易、信息传播及对权力的实际感受。

## 命名适配与证据边界

给人物、地名、阵营、器物或制度命名时，先确认实体功能、世界文化、阵营气质、叙事语气、现有近名和不得提前揭示之事，再从意义、声音、世界历史或有意反差形成少量不同方向候选。检查同类实体是否可读可辨、近音近形混淆、意外含义、文化或宗教负载、正典冲突和剧透；候选方向未经作者确认不得写成最终名称。

文学构义只需在当前世界和叙事中成立。真实古语、汉字字源、音韵、训诂和时代语感断言交给 `hanzi-philology` 核验；无法核实时保持文学构义或待确认，不用命名网站、模型记忆或伪出处补证据，也不批量改写既有正典名称。

## 天马行空与幻想归来

### 天马行空

探索期允许候选互相矛盾、暂时无用、不可实现或没有解释。用户明确要求只发散、不选择、不落地时，不强迫共享原因、统一世界观、人物主线、现实约束、代价、反制或回收，也暂不读取下方五层归来；本轮止于可继续生长的文学虚构候选，不替作者筛选或升级正典。候选之间可以矛盾；被作者选择并进入当前创作单元后，仍须服从已确认正典、三层真实和后果自洽。

### 幻想归来（成真）

只有作者要求选择、成形、写入故事或检验可用性时，才从候选中选择幻想核进入归来；若成形后变得常规、工整或可预测，可以退回天马行空重新发散。

幻想先远行，归来不是退让。先保护最奇异、不可替代的幻想核，不为“真实可信”把它解释成幻觉、仪器、科学现象或常见套路；再选择故事真正调用的方向，让幻想获得血肉、阻力和遗痕：

| 归来方向 | 成真方式 |
| --- | --- |
| 故事归来 | 改变目标、冲突、选择、代价与结局，不只充当背景奇观 |
| 人物归来 | 进入身体、欲望、恐惧、偏见、关系和不可回避的选择 |
| 世界归来 | 改变普通人的生计、职业、交易、法律、器物、语言和生活习惯 |
| 历史归来 | 留下遗迹、地名、伤痕、档案冲突、权力叙事和被遗忘的过去 |
| 神话归来 | 形成信仰、仪式、禁忌和异文，让不同群体拥有不同解释 |

不要求五层齐全；五层按故事需要取用，不机械凑齐，也不把人物和故事留到以后。即使用户明确要求完整方案，也先用一个人物、一个场景、一次选择及其后果交付并验证最小故事切片；切片成立后，再完成用户明确要求的完整方案。用户点名神系、部族、年表和力量表时不得擅自省略，未被故事调用的部分只能作为可裁剪候选，不提前升级为正典。

“成真”有两层：经作者确认后成为小说正典，通过场景、行动、感官和余波成为读者可感的叙事现实；它不是现实史实，也不能反向伪装成古籍、地方志或传统原貌。

创见可以跨越现实，但必须选择约束。强大的力量至少回答来源、使用条件、代价、反制、社会后果和长期变形；宏大制度至少回答资源、执行、受益者、受损者、灰区和崩坏方式。

阴阳互用互制不是机械配对：秩序保护生活也可能压抑变化，力量解决危机也会制造依赖，秘密保护人物也会损害信任。两面应通过同一事件和后果显现，不另建说理章节。

## 停止条件

- 当前卷或角色没有调用需求。
- 关键史实、文献或地理来源尚未核验。
- 设定扩展不能改变人物选择、冲突或后果。
- 完整名录、地图、年表或力量表会早于故事冻结不必要细节。

命中任一项时停在候选或局部切片，回到故事主线。
