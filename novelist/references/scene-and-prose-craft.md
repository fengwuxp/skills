# 场景与叙事表达

## 使用时机

把章纲展开为场景或正文，处理 POV、内心、动作、空间、转场、对白、打趣和项目文风校准时读取。本文只管叙事如何在页面上发生；故事功能读 `story-design-and-drafting.md`，人物依据读 `character-craft.md`，跨章状态读 `continuity-and-revision.md`。

## 场景承重与展开

先确认本场的进入状态、即时目标、阻碍和必须发生的变化。承重节点沿当前 POV 展开为`刺激 -> 相互冲突的冲动 -> 决定 -> 可见行动或克制 -> 对方或环境反作用 -> 即时代价 -> 离场状态`；展开后仍须保留人物责任、因果功能、关系变化和后续约束。没有新增选择、信息、关系、风险或后果的赶路、等待和重复证明可以概述、跳切或省略，不为满足字数、感官配额或“全都场景化”制造动作。

动作不只是位移。优先写会暴露意图、能力、犹豫、关系或代价的动作，并让器物、距离、遮挡、身体限制和他人反应改变下一步。感官细节由人物当下寻找、躲避和能够感知之物筛选；一两个能参与判断或行动的细节胜过等量罗列五感。

## POV 与内心

POV 不是摄像机位置。环境和信息先经过视角人物的欲望、知识、偏见、身体与风险过滤：他此刻寻找什么、躲避什么，就先注意什么、误读什么。关键刺激形成`感知 -> 冲动冲突 -> 决定`，再落到动作、言语或克制；不先给客观全景，再补一段心理说明，也不越权进入他人内心。

只有新 POV 能带来此前不可得的信息、有效重释、新压力、新选择或新行动时才切换；重复同一事件、替主角喝彩或提前泄露应被遮蔽的内心，不足以构成切换理由。群像或全知叙事也要明确当前叙述位置与信息权限。

人物沉浸推演是作者侧的隐藏过程。进入正文时不展示推演表、标签或完整心理因果说明，只留下当前叙事距离允许读者获得的、可感的身体、注意、动作、言语、克制或片段心理；人物不能清楚总结自己尚未意识到的机制。正文完成后再退出人物视角，检查行动能否回到其有限认知与处境，并让外部反作用而非作者解释证明选择成立。

## 转场与承接

转场先继承上一场未尽的决定、关系、风险和事实状态，再判断下一场需要读者立即定位什么。按需选取时间、空间、共同事件、物件、动作、情绪或信息中的最小触点；有效硬切可以直接进入下一场第一拍，不为平滑补齐赶路和解释。

换时间或 POV 后，用新视角可知的信息与新行动承接同一压力。允许有意失向、蒙太奇和悬疑切换，但不能造成无意的时空、POV 或因果断裂。章末已经交付关系、决定、风险或情绪余力时，下一章第一拍须兑现、反拨或转义，不复述、不无因降温。

## 对白与打趣

对白开场前明确各方目标、筹码、位差、隐瞒和不能直说之事；每句应在试探、施压、遮掩、交换或决断，而不是轮流说明设定。人物声音来自身份、关系、风险与当场策略，不靠口头禅区分。对白结束后，权力、信息、情绪或决定至少一项必须改变，并产生下一动作；否则压缩或并入行动。

人物声纹用匿名复读校验：遮住人物姓名，比较信息选择、用词、句法、停顿、礼貌策略、回避方式和动作配合；不靠口头禅、方言或固定句长制造差异。修订后再次遮名复读，仍同声时回到人物当场的目标、风险、关系和隐瞒，不追加人物标签冒充正文效果。

打趣只有在压力和关系中承担功能时才使用。每轮回应须接住并否认、升级、误读或重释前句，让幽默暴露恐惧、传递信息或改变策略；危险和代价仍须可感。庄重、哀悼、恐怖或创伤场景不自动添加笑点，也不规定固定笑点次数和喜剧角色模板。

## 文风校准

只使用当前任务中明确属于作者或已获授权、且适用范围清楚的样本；不读取朋友未授权稿，不以趋近在世或著名作家的表面风格为目标，也不建立跨项目持久偏好。先按叙述者、POV、人物声音、场景功能和作品阶段选择可比样本；不足或互相冲突时，降级为项目既有的中性语体并说明限制。

提取叙事距离、信息释放、句法倾向、意象密度和人物声音等功能规律，保护正典、因果与清晰度；不用词频、口头禅、固定句长或标志性意象复制冒充作者文风。

## 正文交付

用户要求可直接续接的正文时，作品载体只放必要标题、分隔和正文，不混入分析、状态标签、备选方案、TODO、占位符、验收清单或结尾自评。承重事实不足或权威冲突时，不编造正文，在作品载体之外简要指出缺口并停止。
