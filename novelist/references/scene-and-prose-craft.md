# 场景与叙事表达

## 使用时机

把章纲展开为场景或正文，处理 POV、内心、动作、空间、打斗与斗法、导演调度、社会或战争场面、转场、对白、打趣和项目文风校准时读取。本文只管叙事如何在页面上发生；故事功能读 `story-design-and-drafting.md`，人物依据读 `character-craft.md`，世界规则与制度事实读 `worldbuilding-and-research.md`，跨章状态读 `continuity-and-revision.md`。

## 场景承重与展开

先确认本场的进入状态、即时目标、阻碍和必须发生的变化。承重节点沿当前 POV 展开为`刺激 -> 相互冲突的冲动 -> 决定 -> 可见行动或克制 -> 对方或环境反作用 -> 即时代价 -> 离场状态`；展开后仍须保留人物责任、因果功能、关系变化和后续约束。没有新增选择、信息、关系、风险或后果的赶路、等待和重复证明可以概述、跳切或省略，不为满足字数、感官配额或“全都场景化”制造动作。

动作不只是位移。优先写会暴露意图、能力、犹豫、关系或代价的动作，并让器物、距离、遮挡、身体限制和他人反应改变下一步。感官细节由人物当下寻找、躲避和能够感知之物筛选；一两个能参与判断或行动的细节胜过等量罗列五感。

## 作者侧三镜：导演、编辑与观众

三镜只用于设计和复核，不是三个正文 POV。**导演镜片**安排人物走位、视线、距离、遮挡、物件、声场、明暗、显隐与尺度，决定读者注意何处、何时看见什么；调度必须服务冲突、关系和场景变化，不把小说写成分镜脚本。**编辑镜片**检查进入与离场状态、信息重复、场内节拍、切入切出点、时空因果和相邻场承接，删除没有改变局面的拍子。**观众镜片**依次检查读者此刻知道或误解什么、感受什么、期待什么，以及是否迷失、过载、麻木或被提前泄底。

三镜先共享同一场景契约：当前 POV、即时任务、进入与离场变化、应遮蔽的信息、目标读者与作品类型承诺。随后由导演镜把欲望、身份、权力、通行资格、危险和可选行动排进空间与显隐；编辑镜依因果变化、信息增量、张弛和相邻承接取舍，不因只求快而误删承载关系和判断的生活质感；观众镜检查目标读者凭现有证据能否理解空间与因果、积累情绪、形成期待并信任后续揭示，不规定读者必须感受什么。需要读者确认死亡、背叛或规则生效等结果已经发生时，正文须给出 POV 可见且能排除拘押、放逐、试探等主要竞争解释的结果证据，不能只用身份移除、沉默或气氛暗示代替。三镜冲突时，依次服从`世界事实与视角边界 -> 人物选择、责任与代价 -> 场景任务与因果变化 -> 阅读清晰度与节奏 -> 视听效果`，不让任一镜片为自身效果改写更高层事实。

三镜完成后回到当前叙述契约：正文只能留下叙述者或 POV 可感、可知且会注意的动作、声音、物件、空间和片段心理。读者专属事实不得以人物“没有看见 / 不知道”的否定句、未授权触感或近义暗示进入人物 POV；只有当前权威已确认人物能感知该迹象时才可写。机位、剪辑意图、观众应有何感受及他人未外显的内心留在作者侧。

内部准入、三镜复核、状态扫描和规则名不外显为交付过程。用户未要求完整方案时，只交付结论与当前任务真正承重的最小结构；同一事实只写一次，事件卡能一行写清就不在卡后复述，用户要求纯正文时只交付正文。

## POV 与内心

POV 不是摄像机位置。环境和信息先经过视角人物的欲望、知识、偏见、身体与风险过滤：他此刻寻找什么、躲避什么，就先注意什么、误读什么。关键刺激形成`感知 -> 冲动冲突 -> 决定`，再落到动作、言语或克制；不先给客观全景，再补一段心理说明，也不越权进入他人内心。

只有新 POV 能带来此前不可得的信息、有效重释、新压力、新选择或新行动时才切换；重复同一事件、替主角喝彩或提前泄露应被遮蔽的内心，不足以构成切换理由。群像或全知叙事也要明确当前叙述位置与信息权限。

人物沉浸推演是作者侧的隐藏过程。进入正文时不展示推演表、标签或完整心理因果说明，只留下当前叙事距离允许读者获得的、可感的身体、注意、动作、言语、克制或片段心理；人物不能清楚总结自己尚未意识到的机制。正文完成后再退出人物视角，检查行动能否回到其有限认知与处境，并让外部反作用而非作者解释证明选择成立。

## 打斗、斗法与战争

打斗不是可独立抽换的动作模块。开写前先从当前故事、卷章承诺、权威设定和连续性状态中，只提取会改变本场为何战、怎样战或战后走向的承重项：剧情任务，参战者的故事定位、关系、阶段欲望与成长轨迹，已确认世界与力量规则，当前功法、武器、法宝、伤势和资源状态，以及天气、地形、建筑、生态、平民与组织秩序。题面给出的身份或职业若是承重项，其观察方式、专业能力、伦理边界或可调用资源必须实际改变战术和选择，不能只出现在背景介绍或战后余波。缺失且会改变上述判断的事实，不在打斗中临时补成正典。

所有打斗再定`争夺目标与剧情分叉 -> 失败代价 -> 场域拓扑与距离 -> 身体、功法与装备条件 -> 信息差 -> 行动与反作用 -> 局势改变 -> 即时代价与余波`。每一拍必须改变位置、能力、信息、关系、资源或下一步可选行动，不能双方轮流报招后恢复原状；胜负由前文条件、判断和取舍推出，受伤、耗竭、误伤、暴露和环境损伤进入后续因果。

- **凡人斗殴**：让体重、重心、抓握、距离、地面、疼痛、恐惧、疲劳和失误决定动作。普通人不会稳定执行长连招，挨打也不会只扣除抽象体力。
- **武侠高手**：用观察、抢位、节奏、虚实、借势、克制和承担代价显出技艺；招式名只在人物、传承或战术上有用时出现，不用“更快、更强、残影更多”代替判断。
- **功法、武器与法宝**：功法塑造感知、习惯、优势、盲区和可成长方向；武器以长度、重量、材质、握持、空间、归属和损坏状态改变战法；法宝必须沿已确认的发动条件、次数、代价、反制与所有权使用。突破、换招或器物显威须由此前经历、训练、理解或牺牲推出，不临场发放新能力，也不让装备替人物完成核心选择。
- **玄幻、奇幻、仙侠、修士、魔法与斗气**：作者侧先明确力量的可感线索、来源或媒介、发动条件、作用边界、代价、反制和环境后果；正文按 POV 只揭示当场可知部分。强弱差可以存在，但等级不能跳过战术、选择和代价自动结算。
- **妖、鬼、神、灵兽与魔等非人存在**：先确认其身体或无身体、感知、欲望、智能、契约、辖域与存在方式怎样改变空间、信息和战法；异类不是换了名称的人类，也不因非人而免除行为后果。
- **群战与战争**：不能写成放大的单挑。让目标、地形、时限、侦察、情报、指挥、通信、编制、补给、士气、军纪、敌我反制和平民共同作用；命令在传递和执行中可能因距离、时延、误解、利益、恐惧或现场变化而延误、失真或被改作，条件未发生时不为证明系统复杂而强造偏差。在全局态势、局部队伍和个体身体之间有目的地缩放。胜负离场若实际已有死亡，不得只写“伤亡入册”，还要让阵亡者、遗体处置或埋葬及相应责任进入场面与后文。异常力量也必须进入侦察、运输、医疗、反制和战后秩序，不能只负责齐射特效。

战斗离场只清算实际变化项：主线证据与时限、人物选择与关系、伤势和能力认知、功法进展、武器与法宝状态、资源损失，以及地貌、建筑、生态、生产、平民生活、组织和制度反应；未变化状态原样继承。外部环境既限制战斗，也必须继承战斗实际造成的破坏、残留力量与责任。只更新战力等级或宣布胜负，不算完成场景变化。

灾害、战争、疫病或群体场面还要让实际涉及的百姓、机构、动物、疾病和资源按各自位置、知情、能力与利益继续变化，写清不对称影响；离场按本场所及分别核对伤亡、疾病、迁徙、粮草、物价、关系与秩序，不用“各方调整”或“民生受损”概括，也不把未受影响项机械写满。

动作句先保证谁对谁做了什么、空间和结果是否清楚，再用句段速度、视野收放和感官焦点塑造节奏。关键一击可以短，蓄势、混乱和判断也可以长；不以短句数量、招式密度或破坏尺度机械制造激烈。

## 社会场面、礼制与尺度

市井、家庭、朝堂、仪式和地方风俗都从人物当场任务进入，再让物质条件、组织秩序、权力关系、感官焦点和场后变化共同显形。器物、食物、钱粮、道路、职业、座次、服色、通行与发言资格只有参与行动、判断或后果时才写；不先给静态全景或百科说明，再让人物走进布景。

社会场面的运行链是`人物任务 -> 身份、名分、资源或制度约束 -> 交涉、执行或规避 -> 群体分化反应 -> 秩序反馈 -> 下一步选择`。尺度可在个人、家庭或小队、乡里或市井、组织与国家之间换挡，但每次必须由消息、文书、道路、价格、名册、仓储、队列、伤亡、传言或仪式见证等具体载体连接，并改变信息、资源、行动窗口或责任；宏大不是突然拉远讲解，而是变化能够跨层传导，再以生活后果返回人物。

纸面规则、实际执行与公众理解可能不同；场面应让名义身份与真实权力、时机与延误、受益者与承担者、执行偏差与反馈通过行动显形。群众不是单一合唱，按角色、所知、利害、风险承受力和行动阈值分化为服从、求助、规避、互助、套利、传信、记录或追责者，其反应继续改变现场和后续秩序。

- **市井与风土人情**：通过劳动、交易、价格、交通、方言语用、邻里互助与冲突呈现地方生活；风俗要有人实行、变通、拒绝或借用。
- **家庭与温馨场面**：温情来自共同劳作、照料、习惯、克制、旧账和未说之事。亲密不等于没有边界、分歧和代价，也不靠连续柔光、笑声与形容词证明。
- **朝堂与礼制**：让身份、席位、先后、称谓、物件、发言权、禁忌、例外及纸面规范与实际执行的差异进入博弈。礼既能维持秩序，也能遮蔽、施压、保护或被重新解释；还应实际改变谁先行动、谁能见证、何事入册、谁获例外、谁受惩处或谁的身份由此变化。
- **宏大、悲壮与大国风貌**：在个人、群体和制度尺度之间往返，以消息、道路、仓储、名册、调度、税粮、救治、仪式和执行偏差等可追踪链条，同时呈现组织能力、地域与阶层差异、传导损耗、成本和后续责任。宏大不靠建筑、人数和赞颂词堆叠；悲壮必须落到不可免费取消的死亡、伤残、离散、饥饿、误判、收殓、抚恤和责任。

同一场面不必装满以上维度，只保留会改变人物选择或读者理解的承重细节。用户只要求设计场景、但未授权正文定稿或设定自决时，输出第一行标明“候选场景骨架”，该状态覆盖段内全部新增细节；输入未给出的数量、动机、执行者、查验结果或揭示动作只作可替换候选，不用场景完成度把它们写成当前事实。需要新增制度、礼俗、战争结构或风土事实时，先回到 `worldbuilding-and-research.md` 区分已确认、候选与待确认，不由场面描写临时补成正典。

## 转场与承接

转场先继承上一场未尽的决定、关系、风险和事实状态，再判断下一场需要读者立即定位什么。按需选取时间、空间、共同事件、物件、动作、情绪或信息中的最小触点；有效硬切可以直接进入下一场第一拍，不为平滑补齐赶路和解释。

换时间或 POV 后，用新视角可知的信息与新行动承接同一压力。允许有意失向、蒙太奇和悬疑切换，但不能造成无意的时空、POV 或因果断裂。章末已经交付关系、决定、风险或情绪余力时，下一章第一拍须兑现、反拨或转义，不复述、不无因降温。

## 对白与打趣

对白开场前明确各方目标、筹码、位差、隐瞒和不能直说之事；每句应在试探、施压、遮掩、交换或决断，而不是轮流说明设定。人物声音来自身份、关系、风险与当场策略，不靠口头禅区分。对白结束后，权力、信息、情绪或决定至少一项必须改变，并产生下一动作；否则压缩或并入行动。

人物声纹用匿名复读校验：遮住人物姓名，比较信息选择、用词、句法、停顿、礼貌策略、回避方式和动作配合；不靠口头禅、方言或固定句长制造差异。修订后再次遮名复读，仍同声时回到人物当场的目标、风险、关系和隐瞒，不追加人物标签冒充正文效果。

打趣只有在压力和关系中承担功能时才使用。每轮回应须接住并否认、升级、误读或重释前句，让幽默暴露恐惧、传递信息或改变策略；危险和代价仍须可感。庄重、哀悼、恐怖或创伤场景不自动添加笑点，也不规定固定笑点次数和喜剧角色模板；笑意过后用人物继续处置的物件、责任、动作或沉默承接，不在正文末句替读者解释“笑没有消解死亡或代价”。

## 文风校准

只使用当前任务中明确属于作者或已获授权、且适用范围清楚的样本；不读取朋友未授权稿，不以趋近在世或著名作家的表面风格为目标，也不建立跨项目持久偏好。先按叙述者、POV、人物声音、场景功能和作品阶段选择可比样本；不足或互相冲突时，降级为项目既有的中性语体并说明限制。

提取叙事距离、信息释放、句法倾向、意象密度和人物声音等功能规律，保护正典、因果与清晰度；不用词频、口头禅、固定句长或标志性意象复制冒充作者文风。

## 正文交付

用户要求可直接续接的正文时，作品载体只放必要标题、分隔和正文，不混入分析、状态标签、备选方案、TODO、占位符、验收清单或结尾自评。场内动作、语气、节拍、空间和感官可按授权临场决定，但不得借表现细节新增场前、场外、人物过往或因果凭据；交付前按 `story-design-and-drafting.md` 做正典增量扫描，删除输入未给出的旧动作、旧对白、回忆和物件细节。扫描不限于显式回忆：凡用“一路”“此前”“又”“仍旧”“早已”等词把当前身体、情绪或物件状态归因于开场前经历，都须能回指已确认权威；不能把“他一路攥得太久，指节发僵”当作表现细节，应改成场内当下可见的“他攥紧账角”。承重事实不足或权威冲突时，不编造正文，在作品载体之外简要指出缺口并停止。
