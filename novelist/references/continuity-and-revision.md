# 连续、承诺与重写

## 使用时机

项目存在新旧稿、多个设定文件、长篇续写、人物知情差异、时间地理约束或大范围重写时读取；需要核对三层真实、戏剧许可、伏笔与承诺闭环、真情可读与去 AI 味、审查与试写时也读取。

## 权威与状态

先建立最小权威表：

```text
当前正文：
设定权威：
人物与关系权威：
时间线 / 地理权威：
旧稿与参考素材：
允许写回的文件：
作者确认方式：
```

同一事实只保留一个权威来源。其它文件只能引用或摘要。发现两个权威候选冲突时停止批量写回，先请作者裁决；作者已经明确授权本轮在限定范围内自决时，按授权处理冲突并留下变更记录。

项目已有状态定义时，先读取各状态的语义、Owner、晋升条件和效力；故事正典状态、来源证据状态和工作进度状态分轴记录，不把“待核”等证据标签等同于“待确认”等作者决策状态。项目未定义时，才使用默认四态：已确认、建议骨架、待确认、参考素材。正文已出现不等于作者已确认；旧稿出现更不等于当前正典。

跨轮恢复先从项目入口重建权威拓扑，不强制新建状态文件或统一目录：先确认当前目标与创作单元、各类事实的唯一权威、项目状态语义、作者授权范围与允许写回位置，再读取最近已验证的正文或章节、活跃读者承诺、未决冲突和下一动作。恢复简报只保留当前创作单元、权威指针、最近成立的变化、活跃承诺、冲突、作者授权范围、允许写回位置和下一动作；缺少续写授权时可以分析、对账和提出候选，不得直接续写或回写权威。已获续写授权但缺少允许写回位置时，可以在对话中交付正文，不得写入文件或权威。决策台账、会话摘要和恢复简报除非被项目明确指定，否则不能替代事实权威。它们与权威原文冲突时，以当前权威原文为准并标记摘要失效。

### 讨论增量与冲突收口

承续草稿的协作记录只保存当前会话与作者明确提供、授权读取的项目材料；不得扫描未提供或未授权的历史对话、记忆目录或私有材料。没有允许写回位置时，只在对话中交付最小承续包，由作者决定是否归档，不自行创建第二份项目正典。

作者修订已经确认的承重事实时，先确认旧值、新值、确认证据、生效范围和唯一权威，再沿时间线、人物关系、人物知情、伏笔与承诺、卷卡、章卡和正文检查真实依赖。当前草稿只保留一个生效值；依赖旧值的断言必须删除、改写或明确失效，仍依赖旧值的草稿标记为失效或阻断正文准入，不能只更新会话摘要或新建一份并列草稿。

详细协作记录保留问题由来、作者公开意图、小说家公开判断维度与依据、作者确认、取舍理由和影响闭环；已裁决方向只用中性功能名、来源或版本指针、退役原因和影响处理结果表示，不完整复述会与当前结论冲突的旧命题。未决冲突只记录问题、判断维度、影响、裁决所需证据和停止线，不向当前草稿填入互斥值；需要回看原方案时读取其原始材料，不让历史过程反向获得当前效力。

续写当前章前，先按项目范围、权威、状态和 currentness 过滤材料，再只选本章实际调用的人物当前状态、前章离场结果、规则约束与活跃读者承诺；旧摘要、已取代内容和相邻项目材料不能因名称相同或语义相关进入当前事实。权威冲突或适用范围无法裁决时停止续写并指出缺口，不强制创建上下文包、统一目录、RAG 或全项目扫描。

## 三层信息

- **作者本真**：作品世界实际发生了什么。
- **人物所知**：每个人在当前时间点知道、误解、隐瞒或相信什么。
- **读者所知**：正文已经展示、暗示或故意遮蔽什么。

悬念来自三层信息的有意差异，漏洞来自无意混写。每次揭示都记录来源、接收者、理解变化和后续行动。

### 跨章信息差压力测试

多章规划按`信息起点 -> 事件或证据 -> 接收者 -> 理解或误解 -> 人物行动 -> 读者所得 -> 下一章约束`核对同一秘密的传播、隐瞒、误读和重释。作者本真不得倒灌给人物；当前 POV 已经知道且会影响选择的关键信息不得被叙述强行藏掉。每次揭示须改变判断、关系、风险或行动，并有来源且能重释旧事实；没有产生变化的信息降级为气氛或背景。

### 线索、推测与揭示

线索收集先按当前权威区分已确认观察、候选线索、生活质感、退役旧稿与权威冲突，再记录来源、发生与可见时点、谁能接触、可靠性和当场功能。只有能够改变推测、人物行动或读者期待的痕迹才升级为线索；旧稿矛盾先作为权威污染处理，普通衣饰、器物、意象和异常不因以后可能有用就强升为伏笔。

作者 / Agent 层区分已确认事实、候选解释与未知，推测不能自动晋升正典；人物层只用当时获得的证据、经验、偏见和利益形成判断与行动阈值；读者层只用正文已经展示、暗示或公平遮蔽的内容形成合理解释。重要推测沿`观察 -> 当前解释 -> 可成立的其他解释 -> 行动阈值 -> 新证据或反馈 -> 支持、削弱、推翻或暂缓`更新，并说明什么后续信号会改变判断；不使用伪精确概率，也不让错误推测只为拖延揭晓而拒绝更新。误判须有真实来源并促成行动、关系或代价，更新后的判断继续约束下一场。

## 旧稿提炼

旧稿只提炼可迁移单元：冲突、人物功能、场景记忆点、伏笔、情绪承诺和因果候选。名称、关系、设定、结局和价值判断必须重新经过当前权威与作者确认。

不要对旧稿做全局替换后再修冲突。先列迁移候选，逐项判断保留、改造、拆分或舍弃，再进入新稿章卡。

## 连续性检查

| 维度 | 检查问题 |
| --- | --- |
| 人物 | 欲望、能力、伤势、关系、知情和称谓是否随事件变化 |
| 时间 / 时序 | 年龄、时距、昼夜、季节、伤愈和消息传播是否可成立；事件发生序与正文呈现序是否被无意混写 |
| 地理 | 距离、路线、交通、气候和补给是否支持行动 |
| 规则 | 能力条件、代价、制度权限和禁忌是否前后一致 |
| 因果 | 关键结果是否来自人物选择与既有条件，是否留下余波 |
| 多线 | 各线局部时钟、知情和状态是否连续，跨线消息、移动、资源与会合是否有真实接口 |
| 揭示 | 读者是否过早知道、重复知道或无证据跳到结论 |
| 终局 | 作者已确认的最终归宿、既定结局或硬承诺是否被中途情节悖逆 |

复杂结构先分别回放事件发生轴、叙事呈现轴和因果与状态链。倒叙、插叙、回忆或不可靠记忆不是时间错误；只有定位不清、前置条件倒置、知情越界、返回当下后不产生作用，或借非线性叙事掩盖状态断裂时才修。并行多线分别核对局部时间与离场状态，再检查跨线传播和会合的最早可能时点；人物移动、消息传播、命令执行和自然变化分别计时，不得用人物路程代替消息耗时。任一承重接口的路线、载体或耗时未知时，只能判定现方案是否已不成立，最早抵达或会合时点保持未知，不补成伪精确日期。不同线不必同步抵达，不得用强行顺叙或同时高潮掩平真实差异。规划方法见 `story-design-and-drafting.md` 的“剧情演进、叙事时序与多线并行”。

项目采用递增逻辑锚时，再按 `story-design-and-drafting.md` 的“递增逻辑锚与并发场景组”复核：同一作品内事件只有一个稳定`EV`号，讨论或设计先后不得改写`T`锚；并存时间轴各自声明命名空间，跨轴关系没有对齐证据时不得比较；同线局部序号递增，范围锚不伪装成精确时点，未落位事件保留上下界和`blocker:placement`而不伪造`T`锚；同一全局窗口只证明同窗，`overlap`与`exact-sync`须有对应事件和时间证据，且均不自动证明触发、参与或承受机制；一次启动下不同分支可以经过各自历时先后完成，不据此新增二次触发；跨线依赖必须有消息、移动、资源、环境或会合接口；`00`汇合只等待真正参与的分支，未出场支线继续按离场状态和自身时钟演进；`P`锚可以重排呈现，但不能让人物提前知情或结果先于前置。已确认事件只允许修改显式开放字段；作者纠正已经生效但权威载体尚未清理时标为待回写或冲突，并阻断受影响正文准入。

承重时序或机制被纠正后，旧值清理不能只搜索专名和时间数字。沿事实权威、卷章规划、摘要、人物档、伏笔或准备材料与准入门检查“感应、召来、触发、卷走、再遇”等会暗示主体、机制、因果或必然性的动词，确保当前有效载体都回指同一裁决。历史 Decision Log 或审计行可以保留旧说法，但必须显式标记已废止并指向当前权威，不再参与现行事实裁决；清理未完成时保持`pending-writeback / conflict`并阻断依赖旧机制的正文，不用新解释覆盖残留冲突。

逻辑锚回写再分开复核三件事：`Canon Status`只回答事件是否成立，`Record Status`只回答权威与当前有效引用是否已经对齐，`blocker:`只回答目标章纲、正文或其它交付阶段能否准入。作者确认高层事件后可以标`confirmed`，但任一受影响载体仍保留旧值、权威指错文件或写回只完成一部分时，记录继续保持`pending-writeback / conflict`；只有逐项回读真实文件、清除旧值并复核引用后才转`aligned`。即使已经`confirmed + aligned`，能力、地理、自然时距、伤势或场内动作仍会改变目标正文时也必须保留对应`blocker`，普通结构校验通过不能替代正文准入。

### 剧情承继复核

新剧情按 `story-design-and-drafting.md` 的“剧情承继与时序锚定”判断顺承、递进、回释、显式修订或无据漂移；本文只负责复核，不另建一套分类。逐节点从当前权威回放上游承诺、进入状态、发生锚点、人物可知条件、结果与下游接口，出现下列任一情况即停止把该节点写入当前大纲或正文：

- 准备进入当前章纲或正文的作品内事件缺少所属线、相对或绝对时点、必要历时、前序节点或前置条件，导致其在事件发生轴上不可定位；纯呈现节点没有指向所呈现事件的发生锚点，或把卷章位置冒充发生时点。尚未落位的已确认事件只能留在事件卡或未落位清单，以已知上下界和`blocker:placement`阻断准入，不能留成无锚空白或伪造精确位置。
- 已采用逻辑锚的事件出现重复`EV`号、重复发生锚、同线局部序号倒退、依赖事件晚于当前事件、跨线依赖无真实接口，或把`same-window`、`overlap`、`exact-sync`和严格先后未知混为一类。
- 把同一局部`T`值跨时间轴直接比较，把未落位或条件式事件写成已确认卷章，因同时发生而补出触发关系，或因分支完成有时间差而补出第二次机制启动。
- `Authority`指向关系、人物或摘要等受影响载体，而不是保存事件主要行动事实的现行领域权威；或只因事件已确认便在多文件写回完成前提前标`aligned`。
- 把`T`锚数字差换算成自然历时，未区分动作完成与结果状态继续存在，让从开始时即生效的持续支线先完全结束才允许主线发生，或用点事件与范围事件伪造`exact-sync`；现行脚本不能证明持续状态等语义时保持人工 CR 和相应`blocker`。
- 与硬边界或现行工作大纲相反，却未先通过效力门：硬边界没有作者显式修订，或现行设计没有作者修订 / 覆盖该节点的自决授权；既有支点、当场因果和伏笔只能证明候选可能成立，不能代替修改授权。
- 已通过效力门的修订，或不改写旧事实的回释，没有从既有支点和当场触发走到人物选择、代价、结果与反馈；“伏笔”“隐藏身份”或“以后解释”不构成承续桥梁。
- 人物提前获得信息，人物移动、消息传播、命令执行、自然变化或跨线会合早于最早可能时点，或把叙事呈现位置误当作发生时点。
- 新节点让既有伤势、关系、资源、责任或代价无因复位，或回释后把人物当时真实作出的选择抹成从未发生。
- 作者已明确修订，或小说家在已覆盖当前节点的自决授权内明确变更，但旧值仍在时间线、人物关系、知情、伏笔或下游章纲中生效；清理完成前将受影响草稿标记失效并阻断正文准入。

终局只约束作者已确认的结果与承诺一致性，不能把作者所知倒灌给人物，也不能让人物为了抵达结局而虚假行动。中途人物仍须按当时的目标、有限认知、关系与替代方案真诚选择；最终归宿应由这些选择、代价和认知变化抵达，不靠宿命预告、无因失败或外力拖回终点。

### 人物场景状态转移

连续场景按`目标、情绪、关系、身体、知情和声音`核对人物进入状态、当场触发与离场状态。只记录真实变化及其依据，并把未消解的伤势、承诺、决裂、隐瞒和声音变化列为下一场必须继承的约束；没有可见触发或代价时不得无因复位。异常反应可以成立，但须能回到人物当时的有限认知、身体、处境或关系压力，不扩成逐句机械打表。

### 章节状态增量

章节按项目既有确认机制成立后，只向现有权威记录本章实际改变的人物、关系、身体、知情、资源、伏笔或世界状态，并附来源章节及后续影响；不复制未变化状态，不维护第二份全量正典。候选、章纲和未确认草稿不得自动晋升；项目没有状态权威时只交付增量清单，交由作者决定是否写回。

## 三层真实与戏剧许可

- **世界真实**：世界规则与后果必须自洽；已经成立的限制不能只在主角需要时失效。
- **事件真实**：低概率、偶然和反常可以发生。巧合可以制造或加剧困境，不能反复替主角解决困境、抹去代价或取消选择。反常事件不必成为谜底、主因果或世界真相，也可以只改变体验、关系或生活秩序；不强迫不同异常共享原因，不因异常规模大就缩小、删除或并入主因果。
- **心理真实**：人物可以不理性，但冲动、误判和失控须能回到其情感、偏见、有限认知、身体状态或处境。可回望，不等于事前可预测，也不强求事后唯一解释。心理支点不等于外部证据链：人物可以不相信消息来源，却因无法承受消息为真而行动，这种不敢赌为假本身就可以成立。若现有心理支点已经成立，不新增外部证据，只校验人物能否实施行动以及行动后的现实后果；不要为了“修逻辑”把人物改成证据充分的最优行动者。探索中选中的分支在当前草稿或版本内须保持连续，不能因结果不理想而暗中重抽，也不自动晋升正典；作者明确修订或切换分支时，按版本与正典规则更新受影响内容。

审查人物违背常态的承重选择时，不用“已有心理支点”一句带过；调用 `story-design-and-drafting.md` 的“失常选择闭环”，逐项写出题面已知与缺口。最小审查输出先分`已知`与`缺口`，再给条件式候选修复；缺少辨识、能力或权限依据时，不得直接写成识破、制服或扣押等成功动作。缺少承重条件时列为待确认或候选，不能直接判定人物选择成立，也不能擅自补成事实。

转折应当意外而可回望：不要求读者事前猜到，也不要求立即解释；回看时能从人物、时势或既有规则找到支点即可。公平反转核对`可见规则、合理假设、已埋异常和隐藏支点 -> 旧事实重释 -> 人物代价与余波`，不临时新增规则，也不藏掉当前 POV 已知的关键事实。荒诞、魔幻现实、黑色幽默等类型可以保留未知，不强行补成科学说明、完整魔法体系或调查主因果；发生后的伤害、利益、关系变化和余波仍按真实世界的重量处理。

处理真实事件、见闻和传说时，把事实真实性与叙事可信度分开：事实主张能支持到何种结论，由证据状态、来源独立性与可靠性决定；故事是否可信由视角、场景、人物反应和后果承载。即使一件事低概率、动机不统一或结局不明，也不改写事实来迎合常识；可以调整揭示顺序和叙述距离，不能替真实人物补统一动机，也不能把传说异文硬收成历史结论。具体来源分层读取 `worldbuilding-and-research.md`。

## 伏笔与承诺闭环

草蛇灰线不是把每个物件都变成谜底。先按承诺强度区分：

- **硬伏笔**：直接支撑主因果、身份、规则或结局；未发布改稿可删除、转义或明确退役，已交付读者后必须在正文回收、转义，或正式修订已发布文本。
- **可呼应意象**：用于情绪和主题回响，可以复现，不承担证明责任。
- **生活质感**：只让人物和环境可信，不制造未来承诺。
- **误导线索**：当场须有真实来源和局部解释，不能靠作者隐瞒关键事实欺骗读者。

伏笔规划只在作者侧保持清晰，不按章节给伏笔配额，不要求每个候选细节参与谜底；弱线索可以直接淘汰。伏笔不要求读者事前唯一锁定答案，不把“无法唯一证明”当成缺陷，也不为此新增身份锚点；只要求揭晓后回看成立且不依赖临时新规则。硬伏笔的设计链条为：首次出现服务当场戏 -> 自然强化 -> 语境变化或误读 -> 回收窗口 -> 由行动、选择或后果揭示 -> 余波进入后续。回收要改变人物行动、关系或世界理解，不用解释会逐条点名。

正典状态与伏笔生命周期分轴：真相是否已确认，不等于某条线索已经放置或必须保留。复杂伏笔从揭晓向前倒推读者必须有机会接触的规则、异常与支点，再从首次出现向后检查每次出现是否先服务当场人物、冲突或环境；强化应增加新关系或新重量，不机械重复。项目未定义生命周期时，作者侧只按候选、已放置、已强化、已转义、已回收或已退役追踪承重项，不建立第二份全量正典。

结尾闭合不等于回答所有问题。主角核心选择、主因果、关键关系变化、公平揭晓和本作依赖的世界规则必须闭合；人物未来、主题解释、更大世界与不影响本作成立的次要谜团可以开放。删除测试前先判断读者承诺：当类型承诺、结构位置，或反复聚焦并留下可追踪支点，使读者合理期待本作回答时，即使不影响主因果也必须回收、转义或明确改变承诺。一次出现且没有追踪支点的开放项只算留白或意象，不称悬念；悬念应当有迹可循，并明确面向未来而非伪装成本作答案。

再用删除测试划界：暂时拿掉待解释项，若读者仍能理解事情为何发生、人物为何选择、代价与关系如何落定，且没有遗留上述读者承诺，它属于开放空间；若上述理解因此断裂，或承诺仍在，它就是未偿叙事债务。

留白是在当前故事已经成立后不说尽事实或意义，给读者参与想象的空间；悬念是留下有迹可循、面向未来的问题。二者都不能替代本作必须给出的答案，也不能靠“续作再解释”延后核心责任。未发布改稿改变方向时，删除、转义或退役孤立线索；已交付读者的硬承诺按上一条处理，不留“以后也许能用”的债务。

## 真情、可读与去 AI 味

正文优先用具体生活、身体反应、言外之意、矛盾动机、不完美选择、物件和环境变化承载情绪与信息。少替人物总结感受，允许沉默、迟钝、误解和没有即时闭环的段落。

可读与传播来自场景推进、信息差、关系变化及可记忆的动作或意象。能被记住的句子应从人物声音和冲突中长出，不刻意制造金句和口号。删改时重点检查：过度解释、人物同声、主题直说、万能反转、每段都完整闭环和连续“不是……而是……”；以及凑字副词（可用精准动词替代）、万能形容词（无具体指向的泛泛赞美）、客观点评腔（上帝视角的“需要注意的是”式句式）、套路连接词（过度书面的转折与并列）、用滥的比喻、无递进的排比和紧张场景里的大段心理分析。这些只用于定位病灶，不是禁词表；判断它们是否应改，要看人物声音、场景功能和读者效果，保留有意的祭文排比、人物口癖、直接情绪与必要停顿。

## 审查与试写

- **读者优先复读**：第一遍暂不看提纲、作者意图和技法清单，以目标读者身份连续阅读，只记录注意力、期待、情绪与停顿从哪里变化；再回到最早且影响后续的断点，用场景目标、信息节奏、人物选择或语言密度诊断，修改后重新沉浸复读。
- **小说家视角**：人物是否主动，因果是否连续，意象与语言是否服务主题，转折是否有铺垫和余波。
- **连载读者视角**：开篇是否兑现类型承诺，本章是否有进展，疑问是否可追踪，章尾是否推动继续阅读。
- **删改判断**：一段文字既不改变人物理解、情绪、行动、关系、信息或风险，也不承担节奏、氛围、人物声音、视角质感、幽默或意象功能时，再删或并入动作。

先试写最小批次再扩展。连续长篇通常先验证 1-3 章；失败时回到最近的卷纲或章卡，不在错误方向上继续堆字数。

## 重写顺序

先修权威冲突，再修卷级因果，再修章级行动，最后修句子。局部文风优化不能补救主角无目标、关系无变化、线索无回收或卷末无新状态。

每次只重写能独立验证的最小批次。验收不通过时回退到最近的故事契约，不用后续新设定掩盖前段缺陷。
