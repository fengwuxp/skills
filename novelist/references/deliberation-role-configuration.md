# 小说场景化角色合议

本文拥有小说创作中角色、站位和视角的专业场景包，单一小说任务直接使用本文。由 `wise-agent` 主持时，主持方另从 `../../wise-agent/references/deliberation-role-configuration.md` 提供通用角色语义与选择契约；使用本文本身不等于启动 `wise-agent`。`novelist` 始终是统一创作主体，人类作者是正典与方向的最终 `decision_owner`，临时工作位不是平级作者、持久人格或第二正典来源。

## 使用时机

- 作者显式要求角色讨论、多视角碰撞、会商、辩论或头脑风暴。
- 历史、世界、神话、人物、文明、剧情或正文设计存在会改变承重因果、人物选择、正典、读者承诺或写作方向的真实冲突。
- 同一创作对象需要先发散异案，再从不同责任面收敛为可写候选。

## 不适用场景

- 普通构思、续写、润色或局部修订没有真实分歧；由小说家直接完成。
- 作者只要求正文；角色检查在内部完成，不展示讨论过程或拼接多份角色稿。
- 只有纯史实考证、训诂或非虚构研究，没有小说创作目标；转给相应证据任务。
- 权威稿、允许改变范围或当前创作单元未明确，继续讨论会把候选写成正典。

## 读取后必须产出

- `task_phase`、`domain_object`、当前创作单元、权威与允许改变范围。
- 按当前分叉裁剪的创作工作位、站位、检查视角、依据和退出条件。
- 当前主冲突、候选差异、推荐、作者裁决点、正典状态与写作停止线。

## 需要继续读取的 reference

- 剧情发动机、时序、角色视图和正文准入读 `story-design-and-drafting.md`。
- 历史、世界、神话、文明发展与幻想边界读 `worldbuilding-and-research.md`。
- 人物选择、关系和有限认知读 `character-craft.md`；场景调度、POV 与正文声腔读 `scene-and-prose-craft.md`。
- 既有稿件、正典状态、人物知情和跨稿修订读 `continuity-and-revision.md`。

## 一、先按创作阶段选角色

| 阶段 | 优先工作位 | 不做什么 |
| --- | --- | --- |
| `divergence` 天马行空 | 原始幻想核守护、异质方案生成、去同构挑战 | 不用统一世界观、因果闭环或历史合理性提前筛优 |
| `convergence` 收敛成形 | 作者/正典、故事发动机、人物选择、世界后果、读者承诺 | 不把推荐或多数意见升级为正典 |
| `planning` 剧情规划 | 正典、时序、人物知情、因果可达、影响回写、读者呈现 | 不让结构美感覆盖真实依赖 |
| `drafting` 正文编写 | 单一叙述执行、当前 POV，导演/编辑/观众只作检查镜片 | 不让多个角色分别写段落后拼接 |
| `review` 修订评审 | 连续性、人物真实性、读者承诺、语言声腔、下游影响 | 不在未授权时改正典或重开已确认分叉 |

`divergence` 阶段只守事实标签、作者原始意图、授权和正典边界，允许候选互相矛盾、暂时没有解释或不可落地。只有作者要求选择、成形、写入或检验可用性时，才进入 `convergence`，再增加人物、因果、世界和读者视角。不能让收敛角色反向扼杀探索，也不能让探索候选绕过正典门进入正文。

## 二、按创作对象增加专业工作位

工作位是候选池，每次只选择能改变当前分叉的部分。历史、世界和神话可以同时出现，但不能因此机械跑满全部角色。

| 对象 | 候选工作位与站位 | 主要视角 |
| --- | --- | --- |
| 历史设计 | 史实证据、时代条件、当世生活、历史记忆 | 已核事实、合理推演、制度遗产、地貌器物、利益债务、记录目的和后世异文 |
| 世界设计 | 世界规则、资源环境、社会运行、日常生活 | 来源、限制、反制、反馈、地域差异、群体与普通人如何生活 |
| 神话设计 | 神话原核、信仰共同体、仪式传播、异文记忆、力量代价 | 谁相信、为何传播、怎样实践、版本如何变化、神异怎样限制并改变现实 |
| 人物设计 | 人物欲望、有限认知、关系对手、行动能力、社会镜像 | 欲望、恐惧、误知、身份、身体、资源、关系压力、选择和代价 |
| 文明发展 | 物质基础、制度责任、技术军事、交换生态、普通人生活、邻接群体 | 资源、人口、生产、合法性、战争、贸易、环境、迁徙、代际反馈和多因演化 |
| 剧情设计 | 故事发动机、因果时序、人物选择、读者承诺 | 谁必须行动、为何是现在、阻力、不可逆结果、事件发生序、正文呈现序和下游状态 |
| 故事编写 | 当前 POV、叙述执行、导演、编辑、观众 | 可见可知、空间调度、进入离场、信息节拍、阅读清晰度、期待、余味和统一声腔 |

### 历史、世界、神话与文明

- 史实证据位只说明当前材料能支持什么，不替作者决定文学改编；无法核验的内容标为推演、传说或虚构。
- 当世生活位检查历史是否通过制度、地貌、身体、器物、风俗、利益和债务进入人物选择，不接受只有帝王年表和背景说明。
- 世界规则位检查力量的来源、条件、代价、反制、社会后果和长期变形，不用完整百科替代当前故事。
- 神话工作位保留讲述者、信仰者、地域、时代、仪式和异文；神话不能替人物选择、历史责任或证据裁决，也不要求所有版本统一为幕后真相。
- 文明工作位至少检查物质条件、责任与权力、交换或冲突以及普通人的生活后果；不把单一制度、血缘、技术、神力或英雄解释整个兴衰。

### 人物与剧情

- 人物自身只能提供受身份、知情、偏见、身体、资源和关系限制的剧中视角，不是作者权威。
- 关系对手位必须拥有自己的目标、选择和时钟，不只作为主角的阻力或镜子。
- 行动能力位检查人物此时是否真的能到达、知道、持有、承受和实施选择；合理动机不能代替现实可行性。
- 剧情角色围绕最小故事发动机工作：谁必须行动、为何是现在、主要阻力和不可逆结果。偶然可以改变选择空间，不能替人物完成核心选择。
- 读者承诺位检查读者凭当前呈现能够知道、误解、期待和公平重解什么，不规定读者必须产生唯一感受。

### 正文编写

进入 `drafting` 前，承重分叉必须已由作者确认或落在明确自决授权内。正文由一个叙述执行位按照当前 POV、人称、叙事距离、人物声音、场景任务和作品语体统一落笔。

- 导演镜片处理走位、视线、距离、遮挡、声场、明暗和显隐。
- 编辑镜片处理进入与离场状态、因果节拍、信息重复、切入切出和相邻承接。
- 观众镜片处理读者所得、期待、迷失、过载、麻木和是否被提前泄底。

三镜与人物视角只返回检查意见，不分别生成正文供拼接。复核意见回到当前叙述契约，由同一叙述执行位改写；工作位名称、方法卡、作者侧事实和他人未外显的内心不得泄入当前 POV。

## 三、裁决顺序

收敛、规划、起草和评审阶段的冲突依次服从：

`作者正典与授权 -> 人物真实选择与可行动性 -> 因果、时距和信息边界 -> 读者清晰度与既有承诺 -> 场景效果与结构美感`

- 作者是唯一正典 `decision_owner`；小说家可以在明确自决授权范围内裁剪候选，但不得从讨论热度或角色共识推定授权。
- 历史证据、人物视角、读者视角和技法视角各有证明上限，不能互相代签。
- `hypothesis` 工作位可以制造反方、陌生化或压力测试，但不能修改正典、决定人物本质或充当 Checker。
- 已确认分叉不因新角色加入自动重开；只有新证据、正典冲突、下游不可达或作者显式修订才重开受影响项。

## 四、输出与停止

若由 `wise-agent` 主持，使用通用 `Discussion Role Matrix`。普通小说任务可压缩为：

```text
创作阶段 / 创作对象 / 当前单元:
权威与允许改变范围:
工作位 / 保护对象 / 检查视角 / 依据:
当前冲突 / 候选差异 / 推荐与影响:
作者裁决点 / 正典状态 / 写作停止线:
```

- 发散阶段止于互不相同的文学虚构候选；不选择、不写回、不补完整解释。
- 收敛阶段只把作者确认或授权自决的内容写入当前有效设计，其他内容保持候选或待确认。
- 正文阶段不输出角色会议纪要、推理过程或多份拼接稿；只交付统一正文及用户要求的最小边界说明。
- 没有真实分歧、角色不能改变当前创作问题或讨论不再产生新候选、反证和影响时，结束角色讨论。
- 缺少权威稿、作者授权、人物可行动条件或承重因果时停止写回；可以交付明确标注的非正典压力测试，但不得宣称正文准入。
