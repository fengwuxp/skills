# 网文 / 连载专项：定位与持续力诊断

## 使用时机

仅当作品或任务明确进入**网文 / 连载 / 追更 / 盐选 / 平台短篇**语境，需要判断一个点子值不值得写、开头为什么留不住人、为什么开得起来却写不下去，或需按连载节奏诊断章节时读取。它是 `story-design-and-drafting.md` 的补充，不是替代：通用的小说语义仍归后者，本文只补充连载语境下的分层定位与持续力检查。

## 分层定位：先分清卡在哪一层

不要把“这个点子能不能写”直接压成一句润色。先判断它断在哪一层，每层只补缺口：

1. **题材与消费点**：读者到底来吃什么，主卖线是什么。表现是题材混、读者预期说不清。
2. **卖点与异常局面**：最抓人的局面能不能一句成交，是否只像背景介绍。表现是 hook 空泛、卖点埋在长介绍后。
3. **主角处境与第一麻烦**：主角是否有眼前压力、不行动的具体损失、第一波冲突。表现是主角特别却没人逼他动。
4. **故事发动机**：能不能持续产出新的选择、新的代价、新的局面，而不是一次性反转。表现是十章后没路、点子像短梗。
5. **长度与第一阶段**：体量是否配得上阶段数，卷一的最小目标和卷末不可逆变化是否成立。表现是短点子硬拉长篇、想写长却没有卷目标。

同一个章节也可能多层同时有问题，先修更靠前、更致命的缺口，不把下游问题（对白、转场、句面）提前处理。

## 连载三层递进检查

开篇、单章和连载中期分别抓不同问题，不做固定字数或黄金三章模板：

- **开篇**：第一拍抓手只负责让人进入局面；作品承诺和故事发动机才回答为什么继续读。让异常尽快落到主角当前处境、行动或选择，并留下可追踪的后续期待，不以固定字数、死亡、外挂或章尾 cliffhanger 判定有效。
- **单章**：本章目标是否清楚，冲突是否升级，新信息是否落地，章末是否收在本章已生成的变化上。章末余力优先来自关系、决定、风险或情绪，不只靠突发声响或陌生人出现；下一章第一拍承接或反打上一章余力，不复述、不无因降温。
- **连载中期**：支线是否服务卷目标，设定是否膨胀，兑现点是否拖欠。连续高压只要每次都改变约束、选择、关系或后果就可以成立；连续同质、代价长期未清或读者承诺被拖欠时才需要改写。

## 逐章完稿自查（按风险裁剪）

完稿后先查结构，再查句面。以下按“先事实、后人物、后表达”排序，检查深度随任务、篇幅和风险裁剪，不设“任意几项不稳就禁止交稿”的固定门禁：

1. 因果：大事有前提，决定有触发，后果改变关系、资源、风险或路线。
2. 人物：目标、情绪、关系、身体与声音跨章接得上，不无故翻面。
3. 信息：谁知道、谁误会、谁隐瞒，前后一致。
4. 转场：时间、空间、POV 与上一场余力是否被带到下一场，读者不迷路。
5. 章末：收在变化上，下一章第一拍接得住。
6. 句面：先排除结构硬伤，再处理空泛总结、人物同声、套话氛围与平均节奏，只改病灶，保护有功能的留白、排比、人物声音。

## 必须避免的固定配方

以下诊断启发只在对应网文取向中可能有用，不能升格为所有小说的普遍规则：

- 固定开篇字数（如 300 / 500 / 3000 / 6000 字）、黄金三章任务、禁止慢热或天气开头。
- 每 2-3 章一次变化、每章必有钩子、固定缓冲比或动静比。
- 每章强制六项审查、任意两项不稳即禁止交稿。
- 每场景固定感官数、对白句数、单章字数或情绪强弱交替配额。
