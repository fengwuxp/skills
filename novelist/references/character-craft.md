# 人物刻画与弧光

## 使用时机

设计人物、人物弧光、重要配角或对手时读取。人物从故事定位、选择和关系变化中长出，不用静态人物卡、天命或外形清单替代场景；场景 POV、内心与对白读 `scene-and-prose-craft.md`。

## 人物刻画：从故事定位到关系网

人物刻画先问“这个人使故事发生什么变化”，再补资料。人物方案不得把功能留给读者推断，至少显式交付两句：`故事定位：此人改变……；删除后……不再成立`；`关系变化：A 与 B 由……，因某次选择或代价变为……`。答不出时先调整故事定位和关系设计；进入正文后则用场景表现，不强制保留标签。维度不是必填人物卡，只有进入人物选择、关系、场景或后果的内容才写进当前创作单元；不用静态人物卡和形容词清单替代场景表现。

| 维度 | 刻画原则 |
| --- | --- |
| 故事定位 | 明确其对主线、主角、关系、主题或世界变化承担什么作用；删除此人后故事没有变化时，合并、改造或删去 |
| 性格 | 不停在勇敢、冷漠等标签，写清欲望、恐惧、价值边界、矛盾倾向，以及压力下反复出现或被打破的选择 |
| 天命 | 区分世界事实、预言或宗族解释、他人期待和人物自我信念；它们只能构成约束、诱惑或误读，不能取消人物主动性，人物如何回应才形成命运 |
| 长相 | 选择会影响他人判断、自我感受、行动能力或关系的特征，通过具体视角与场景显现，不作无差别身体参数清单 |
| 衣着 | 承载时代、地域、身份、职业、资源、礼制、身体经历或关系变化；让穿、脱、改、借、藏和破损进入行动，不列与剧情无关的衣柜 |
| 行事风格 | 落到人物观察什么、忽略什么、怎样说话、决策、冲突、示弱、承担后果；常态与失常的差异用于表现压力和变化 |
| 人生经历 | 只保留已经进入当前能力、偏见、习惯、伤痕、债务、秘密和关系的因果痕迹，不用完整年表代替当下人物 |
| 朋友圈 / 关系网 | 标明亲疏、信任、利益、权力、亏欠、爱憎与共同经历，以及不同人所见的不同侧面；至少写出一组关系在人物选择前后的具体变化 |

### 外号、称谓与社会镜像

外号不是作者替人物另取一个酷名，而是具体关系或群体对可见行为、身体特征、经历、职业、地域、器物或传闻的口头压缩。先区分本名或正式名分、人物实际行为、众口之名与自我认同；自取名号、官封称号和榜文赞称不因出现就自动成为外号，只有被具体群体接纳并实际使用时，才进入众口之名。外号即使错认人物动机，也须真实暴露命名者所见、所受、所求或权力位置，不能充当人物本质、道德判词或案件证据。

设计沿`可见事实或传闻 -> 首次命名者与当场关系 -> 便于复述的口头压缩 -> 群体传播、遗漏与变形 -> 人物和旁人反馈 -> 含义强化、反转、分化或退场`推进。明确谁当面或背后使用、谁拒绝使用，以及同一称呼在不同群体中是否异义；不要求天下人共享一个外号，也不从多个称呼中选出唯一真实本质。即使用户以俗语或交付格式要求三选一，也不得把某个群体的反复观察升级为核心外号或人物本质；当前任务确需选择一个称呼时，只能说明它最适合哪一叙事任务、阶段或视角，并保留其他群体称呼同时成立。人物可以接受、拒绝、利用或试图摆脱众口之名，旧外号也可以在人物改变后继续流传。

只有进入人物、关系、场景或社会秩序的承重外号才追踪传播和变化；只服务地方口吻与生活质感的称呼可以当场使用，不强建生命周期。承重外号至少改变识别、亲疏、信任、威慑、交易、通行、追捕、权力或下一步选择之一；若找不到具体谁会在何种关系与场景中叫出口、怎样传开以及使用后改变什么，就保留为作者候选或删除。涉及形音义、训诂和时代用字证据时，再协同 `hanzi-philology`。

人物决策模型不是创伤清单。`错误信念或旧伤 -> 保护策略 -> 认知盲区 -> 脆弱触发 -> 压力下独有的选择 -> 代价`只是一条追问路径，不是唯一公式；某一环不适用就删去，不为填模板制造创伤。人物行动可以由情、理、欲、关系、身体、处境与偶然共同作用，人物自述也可能只是局部原因或事后自辩；心理真实要求回看时有支点，不收束成唯一动机，也不要求事前可预测。需要建档时按人物重要度裁剪 `../assets/character-dynamic-profile-template.md`，不用档案替代场景。

人物底色、过往与当场处境分层处理：先确认不依赖单一事件仍稳定存在的欲望、价值边界、亲疏方式和责任习惯，再判断过往经历怎样把它偏转成保护策略、敏感点、误判或债务，最后让当前时间、地点、身体、知情、关系与具体刺激共同决定本次选择。不得从预定剧情倒推一种万能创伤或性格解释，也不得因底色稳定把人物写成每次都作同一反应；同一底色面对不同关系、知情和代价，可以表现为实行、克制、变通、自我背叛或事后补责。人物违背常态时，须有当场可感的信息、时限、关系压力、身体或资源条件与既有惯性相撞，不能只用“一时冲动”“仇恨失控”替代选择支点。

先写具体的人，不先写好人、坏人、伟光正、纯恶或“人人自私”的结论。一次恶行不证明此前善行全是假，一次善行也不抵消既有伤害；可敬、可憎与应受追责的事实可以同时成立。动机可由关系、利益、恐惧、责任、偏见、爱、虚荣、控制欲、疲惫和处境共同作用，不要求等量齐备，也不用“人性复杂”把责任稀释成善恶皆无。

人物底色从反复怎样选择、让谁承担代价、造成什么后果、是否负责，以及不同关系人所见的侧面中显出。正面人物不靠舍己仪式洗净控制、偏见和伤害；对手的亲情、信誉或善举可以真实存在，不必回收为阴谋，也不能替他赎清旧债。让行动与余波供读者判断，不用旁白标签替故事宣判。

人物弧光不是性格标签翻面，而是同一核心矛盾在更大压力下反复受试，最终通过不可逆选择改变他与自己、他人或世界的关系。群像先保证欲望、声音、行动方式和承担后果各有区别，再用共同事件让人物互相照见；不靠外貌、口头禅或身份名称制造表面差异。

重要对手每次失利或取得关键情报后，按目标、已知与未知、误判、损失、新情报和剩余资源、时限及关系压力更新威胁判断、行动路线、资源投入或退出条件；不得无因复刻失败方案。重复可以是有目标、有代价的试探或诱饵；对手仍受有限认知、偏见和情绪约束，不写成全知且永远最优。

## 人物沉浸推演

人物沉浸推演用于角色反应、关键对白或选择尚未成形时，从人物内部生成候选，不是建立持久人格或让模型假装成为真实人物。

- **入境**：冻结当前时间点、人物可知与误解、身体、情绪、关系、目标、恐惧、资源、能力、时限及被当场刺激唤起的经历；人物不应知道的作者本真、其他 POV 内心和未来结果留在边界外。
- **内演**：从人物会注意、忽略或误读什么开始，经过身体反应、联想、情绪与相互冲突的冲动，形成他自己的判断或误判，再落到可实施的行动、言语、克制或逃避。深度理解不等于替人物辩护，也不把性格标签、作者价值观或最优决策冒充人物选择。
- **出境**：退出人物视角，复核知情、能力、身体、时代语感、世界规则、关系和正典边界，并记录反作用、代价与离场状态。推演可以给少量真正不同的反应；作者选择前仍是候选，不写回正文、人物档案或正典。

## 人物选择沙盘

只有人物反应、对白或关系转折存在多个可行走向，且直接定稿容易被作者预设牵引时，才做人物选择沙盘。先冻结已确认事实、人物进入状态、各自知情、能力、关系、处境和场景触发，未知保持未知；再形成少量真正不同的候选行动链，每条只写可观察行动或克制、场景变化、代价和离场状态。人物可以冲动、误判、失控或自我背叛，但须能回到当时的心理或处境支点，不用“符合人设”把反常选择修平。

沙盘结果在作者选择前只作候选，不写回正文、人物档案、伏笔台账或正典，也不替作者决定或证明唯一正确反应。作者可以修改输入、回退当前分支或叫停；路线已经清楚，或连续推演不再产生新的选择与后果时停止。

若多个候选本来都有心理与处境支点，且不触碰承重正典，可按场景用高、中、低或粗略权重做作者侧小扰动。权重只表达人物此刻的倾向，不作为统计概率、人物规则或掷骰机制，也不能借随机性改变人物知情、能力或世界规则。选中并写入当前草稿分支后，后续场景须承接该选择及其后果，不得仅因效果不理想而暗中重抽；写入草稿不自动晋升正典，作者明确修订或切换分支时，按版本与正典规则更新受影响内容。

## 经世叙事校准

把 `huaxia-practical-wisdom` 的镜片转成叙事问题，不在正文讲方法：

| 镜片 | 叙事追问 |
| --- | --- |
| 察实 | 人物实际知道什么，误以为什么；作者事实与传闻是否分开 |
| 正名 | 身份、名分、权力、责任和真实行为是否相称 |
| 审时 | 旧秩序哪里松动，新力量何时进入；行动为何发生在此刻 |
| 权衡 | 每种选择由谁获益、由谁付代价；反面力量如何制约 |
| 行验 | 选择怎样变成可见行动，环境和他人怎样反馈 |
| 化 | 后果怎样改变人物、关系、制度和下一阶段问题 |

人物不是镜片的例题。先写欲望、恐惧、偏见、关系与有限认知，再让镜片检查行为是否名实相符。

## 立意、直笔与曲笔

心怀天下先从具体人物的处境、名分、责任和损益成立，博古通今体现为选材准确并知道何处须核验。直笔让人物凭身份、证据、行动与代价承担立场；曲笔用借喻、反讽、用典、明褒暗贬形成名实对照。二者都须改变现场关系、风险或后续行动，不替读者宣布唯一结论。典故须核验出处、时代与语境，不为展示学养堆砌典故；确有字词证据问题时协同 `hanzi-philology`。
