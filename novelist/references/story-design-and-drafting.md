# 故事设计与结构

## 使用时机

构思故事、设计总纲 / 卷纲 / 章纲、与作者讨论关键分叉、判断正文准入、处理开篇承诺、支线或评审叙事结构时读取。场景和正文读 `scene-and-prose-craft.md`；本文不规定固定三幕、字数或网文模板，结构必须服务作品类型和读者承诺。

## 故事发动机

先用一句话回答：谁想得到什么，为什么现在必须行动，什么力量阻止他，他愿付出什么，行动后会失去或改变什么。

主角不能只承接设定和旁人安排。即使被卷入事件，也要尽快形成自己的判断、选择和代价。配角至少承担阻力、镜像、关系、信息或后果中的一项，不因名单完整而出场。

重要配角须有自己的问题，其帮助、拒绝或离场会改变主线；对手须有目标、资源、情报和计划，并在主角视野外行动，受挫后按损失、新情报和剩余资源调整。普通功能角色不强制建立完整副线。实质冲突要求双方目标当前不兼容且各有具体退让成本；不能只用“职责如此”“剧情需要”或单方降智代替动机。

## 生活因果与意外

把故事背景当作所有人都在生活的真实世界。因果负责约束、反馈与结算，不负责证明每件事都由主线需要安排：天气、疾病、误差、延误、资源损坏、陌生人和机构的自行其是都可以在没有预告时改变选择空间；低概率不等于无现实成因，与主线无关也不等于逻辑漏洞。不要为显得严密把意外强编成反派计划、伏笔回收或单一幕后真相，也不要强行把高潮拉回原方案。

意外可以打乱计划，不能直接交付胜利、洗掉承诺或取消人物选择。用户已经锁定核心取舍时，意外可以改变选择空间，不能把这项取舍拆成互不承重的连续小选择来回避代价。发生后让各方按位置、知识、能力、利益和惯性独立应对，由后续选择与代价生成结果；主角不在场时，普通人、对手、机构、环境和资源仍继续变化。伤亡、疾病、迁徙、物价、关系与秩序余波按真实重量进入后文；生活细节可以只属于当下，不必全部变成伏笔。

“意外、插曲、变化、交叉”本身不规定危险级别。群像、庆典、市井、家庭或并行线第一次相交时，先分别写清各线的欲望、截止时间、资源和下一站，再选择能使这些时钟发生关系的最小共同事件；题面与类型承诺没有要求高危时，优先从交易、错认、名次、失约、座位、表演、时间冲突或物件错置等日常变化中生成行动，不默认升级为火灾、坍塌、洪水、伤者救援、调查或官署追责。共同事件只负责让独立行动互相改变条件，不要求所有人同时做好事、同时承责或证明同一主题。

作者或正典已经锁定灾害、战争、伤者或紧急救援时，完整承接其真实危险与后果，不为去同构降级或替换。紧迫行动可以暂时压过享乐、虚荣、审美等私人欲望，但各线原有目标、关系和下一站仍须在离场后继续生效；去同构只改变实际判断、分工、不可兼得与后果，不能另加低风险插曲回避已确认危机。

## 开篇抓手与长期承诺

区分第一拍抓手与作品长期承诺。异常、日常失衡、关系压力、声音或意象都可以成为抓手，但须经过人物职责、有限知识和当场选择改变局面，并让读者知道接下来值得追踪什么。慢热、气氛型、序章或实验叙事可以延迟显性冲突，首章仍须建立人物处境、阅读问题或关系压力，不能只有世界观说明和空泛神秘。

不以固定字数、死亡、追杀、外挂或章尾 cliffhanger 判定开篇有效。廉价震惊若不连接故事发动机、人物责任和可持续后果，只消耗注意力，不形成承诺。

## 想象的两种来路

- **积厚而发**：长期阅读、一手材料、生活观察、历史与专业知识、人物和语言积累，只有能改变人物、关系、场景、因果或叙事声音的部分才进入作品；不堆知识，也不拼贴来源。
- **灵感天成**：突现的意象、声音、人物、冲突或句子先原样保留不可替代的幻想核，与后续加工分开，不急于合理化、筛优或统一世界观。

只有作者要求选择、成形、写入作品或检验可用性时，两种来路才进入“幻想归来”，再接受人物选择、故事因果、世界规则、三层真实、正典状态和读者效果检验。验证服务于成形，不能反向改写或扼杀探索期的原始核。

## 博采与熔铸

广读古典小说、现代小说、网文、短篇、散文及其他叙事传统，先从具体作品提炼可迁移能力，不按门类高下取舍，也不凭标签代替细读：古典小说可取叙述分寸、人情世态与章法照应，现代小说可取个体幽微、视角复杂与复义，网文可取目标推进、期待管理与连载反馈，短篇可取聚焦、留白与不可逆选择，散文可取意象、节奏与感官质地。这些能力并非各门类独有，具体作品若与概括不符，以作品实证为准。

熔铸时按当前作品的类型承诺、人物、场景和读者体验取舍，不设固定比例，不要求各门类等量出现，也不让段落逐一显露技法来源。保持同一叙述主体和统一声腔，让所取技法共同服务人物选择、故事因果与后果；可以分析具体作者如何成事，但不复刻其表面句法、口癖或标志性意象。自成一派不是预设风格标签或短期速成，而是长期阅读、生活与材料积累、持续创作、删改和读者反馈中反复取舍后形成的稳定审美判断与叙事声音，不以自称宗师代替作品验证。


## 故事架构：执简驭繁

按内容、类型、篇幅、作者要表达的故事与要展示的世界确定规划分辨率。先知其要者：不可替代的故事核、主角为何现在行动、类型承诺、核心关系、主要变化轴与必须兑现的结局责任；其余人物、支线、制度、历史和世界信息只有在改变这些要点时才进入架构。执简不是删掉复杂，而是用最少稳定主干统摄可生长的复杂。

篇幅体量与叙事范围分开判断。篇幅不是单纯字数，更关乎主干需要承重多久、因果反馈需要推演多深、多少人物与关系变化需要持续追踪；地域和时代跨度由故事实际承诺的叙事范围决定：

| 规模 | 规划原则 |
| --- | --- |
| 短篇 | 聚焦一次不可逆选择、一个核心关系或一种处境变化；控制视角、人物与解释范围，让局部行动和后果折射未展开的世界；确有跨地域或跨时代承诺时仍保留必要跨度 |
| 长篇 | 以主线统摄卷或阶段目标、关系弧、必要支线与世界揭示；每卷或阶段都形成不可逆新状态，支线必须改变主线、人物或结局条件 |
| 超长篇 | 保持稳定故事核、长期读者承诺与跨阶段因果；只有作品实际承诺主角群、时代、制度或世界范围演进时才预建相应跨度；每个阶段重建可独立成立的故事发动机，定期回收、转义或退役旧线，不提前锁死全部章节 |

类型决定主要承诺和组织压力：悬疑重公平线索与揭晓，成长重能力、关系与认知的阶段变化，情感重关系选择与不可替代性，史诗或制度叙事重多方力量、资源、责任和时代反馈。组合类型先定主承诺，再让次类型服务主线，不为每个类型各造一套平行故事。

重要支线须有行动者、局部目标、阻碍、阶段结果与代价，能在主角不在场时继续行动；同时保留两向主线接口：主线变化会迫使支线转向，支线也会改变主线证据、人物关系、资源或结局条件。只有单向陪衬、沿途展示或永不交换因果时，合并、降级或删除。短意象、生活纹理和一次性呼应可以只承担氛围或主题回响，不强迫建立完整支线发动机。

扩写前问新增人物、支线、制度、历史或地域改变了哪一项上层状态；没有改变就不加。压缩时保护故事核、关键选择、因果支点与结局责任，先删重复证明、同功能角色和只供参观的世界信息。不得把同一模板按字数机械拉长，也不得因篇幅巨大先做完整百科、逐章锁死远期剧情或靠重复升级维持长度。

## 剧情演进、叙事时序与多线并行

先确定当前单元以什么为主推进，不把两种组织方式混成流水账：

- **剧情推进**：沿`目标 -> 行动 -> 阻力 -> 选择 -> 结果 -> 新局势`前进，后一单元必须承接前一结果并改变下一步可选行动。
- **时间推进**：沿人物生命、制度演变、旅行、战争、灾害或季节等承重时段前进；每次跃迁须说明前一阶段的行动、关系、能力、债务或公共后果怎样沉积到下一阶段，不逐年填满空白。

两者都用“**双轴一链**”控制：**事件发生轴**记录作者本真中的先后、历时和前置条件；**叙事呈现轴**记录正文何时让读者看见、误解、回忆或重新理解；**因果与状态链**记录人物、关系、知情、资源、风险、身体和世界状态怎样变化。事件发生序是连续性底盘，呈现序可以重排；重排不得让结果早于必要前提、人物提前获得信息或既有代价无因复位。

### 递增逻辑锚与并发场景组

具体事件已经进入设计稿、章纲、复杂时序或修订影响时，可用递增逻辑锚把“双轴一链”落实为可引用坐标；轻量总纲、普通正文场景和不承重的交叉剪辑片段不强制建表。逻辑锚只帮助定位和校验，不替代世界年月、自然历时、权威裁决、人物选择或场景创作。

交付先按任务分两级，不能用简短回答代替正式锚表，也不为单点纠错机械铺满表格：

- **校正结论**：用户要求审查、判断、解释或最小处理一个时序问题时，至少交付当前有效事实与被否定提议、稳定`Event ID`及`Authority / Canon Status / Record Status / Open Fields`、受影响的`T / P`关系、下游移动与自然时距及状态接口、待回写范围和正文停止线。只写“不要移动”“不是同时”或一条正确因果仍不算完整校正。
- **完整锚表**：用户要求建立、统一、生成或写回时间线，任务涉及两条以上并行线、持续状态、跨轴对齐，或修改事件发生位置时，先声明`Time Axis`，再让每个受影响事件逐行使用下文全部必需列；涉及动作、移动、消息、等待、伤愈或状态持续时另加`Natural Duration`，未知也明确写`unknown`或对应`blocker`，不得省列。并行线还须逐线附最小状态卡：POV、地点、行动者、目标、知情、资源、必要历时、选择和离场状态。正式交付固定为三块：事件主表、逐线状态矩阵、四行验收结论（结构、记录、语义、阶段）；已经在表或矩阵中的 Authority、状态、接口和开放字段不在表外逐行复述，只有被否定方案、异常例外和当前唯一`blocker`另作说明。表中存在范围锚、`overlap`、持续状态或未知自然时距时，在语义行显式保留人工 CR；现行脚本不能证明持续接口和自然时距，证据不足项继续标`blocker:natural-time`，不得因结构变绿而删除。

两级交付共同遵守人物卡范围：只为承担承重剧情的人物与经历引用稳定锚，背景人物和不承重经历不机械补表；条件事件未获确认时继续保持未落位。

采用该协议时按以下最小闭环推进，不能从排表直接跳到正文：

1. **定界选载体**：先明确当前创作单元、目标阶段、已有权威与`Time Axis`；现有卷纲、事件稿或准备稿能够承载时直接复用，不为校验另建第二正典。
2. **盘点影响范围**：先列受影响事件及其上下游、跨线接口、人物卡或关系文件引用、正文呈现点和未落位事件；清单与随后事件卡逐项对应，未落位项保留上下界和`blocker:placement`。
3. **先定身份与效力**：先确定稳定`Event ID`、`Authority`、`Canon Status`、`Record Status`和开放字段，再分配发生与呈现位置；排入表格不产生确认效力。
4. **分别落位与接线**：用`T`记录作品内发生，用`P`记录正文呈现；每条线维护自己的局部时钟，完成依赖写`Depends On`，持续影响写`overlap + Interface + State Delta`，自然历时另记。
5. **按变更事务回写**：移动、拆分、合并或退役承重事件时，先将受影响记录标为`pending-writeback / conflict`，再检查下游时序、移动、知情、持有物、伤势、关系、伏笔和旧因果动词；逐项回读并清除旧值后才能恢复`aligned`。
6. **分层验收后收口**：依次报告结构校验、影响范围完整、自然时距与人物知情等语义连续、当前目标阶段准入；`--require-ready`只验证表内活跃行的确认、对齐和显式`blocker:`，不能替代范围与语义复核。完成后只向领域权威写事实，人物卡等下游载体只引用稳定锚并记录本域状态增量。

#### 按需角色视图与两轮复核

角色视图是从当前事件核与领域权威生成的临时检查投影，不是平级作者、持久台账或新的事实来源；只交付当前冲突、状态差异、`blocker`和回写范围，用完即止。按任务触发下列视图，不机械跑满：

| 视图 | 触发 | 只检查 |
| --- | --- | --- |
| 正典守门 | 任何承重事件、候选晋升或既有事实修改 | Authority、作者授权、Canon / Record / Open Fields |
| 时序连续性 | 先后、时距、移动、并发、持续影响或跨轴关系 | T、自然历时、Depends On、Interface和离场状态 |
| 人物 | 选择、知情、关系、身体、能力或资源改变 | 当时目标、已知与误知、可行动范围、选择、代价和人物侧增量 |
| 影响回写 | 修改已确认内容或需要写回多个载体 | 上下游事件、人物卡、关系、伏笔、准备稿和旧值清除 |
| 读者呈现 | POV、回忆、揭示、悬念或交叉剪辑 | P、读者所得、人物知情隔离、定位和揭示后的当下作用 |
| 场景写作 | 章卡、场景或正文准备 | 地点拓扑、距离、参与者、能力、动作时限、进入与离场状态及场景 blocker |

复核分两轮：**事实完整性轮**从正典守门开始；普通“继续”且当前单元无冲突时，只按 `continuity-and-revision.md` 的“既有裁决复用预检”做轻量承接检查；出现明确复用信号、状态冲突或承重事实变更时再展开对账，区分已确认功能、载体残留和真正开放字段，然后按需加入时序、人物和影响回写。事实冲突、授权缺失、记录未对齐或会改变当前目标的语义`blocker`未关闭时停止。**写作准入轮**只在前轮足以支撑当前目标后开启，按需加入读者呈现和场景写作；后轮可以调整`P`锚、调度与表现，不能反向改写前轮的`T`锚、人物知情、责任或权威。多数任务默认使用二至四种视图，这不是硬上限；复杂任务应分轮扩展，而不是为凑数量漏掉承重视图或一次生成六张表。

#### 下一阻塞点收窄

事实状态判定后，不把全部`Open Fields`并列抛给作者。先选会改变下游分支、决定下一场能否进入或决定人物选择能否实施的最早未决条件，按真实依赖排序，不按事件发生先后或字段类别套固定优先级：地点、时距、跨线会合若决定行动是否可行，先关闭该接口；高层步骤已经确认且只剩动作细节、又没有可行性矛盾时，不得让该细节抢在会改变下游路线的人物选择之前；读者呈现和招式、措辞、调度等表现细节最后处理。只把第一项标为当前唯一`blocker`并推进裁决，其余只说明依赖关系；前项关闭后再重算，不沿用旧排序。`唯一 blocker`只限制本轮向作者关闭的问题，不缩减连续性复核；权威冲突、载体对齐或场景准入仍须列出移动、持有、知情、伤势、自然时距和真实跨线接口等依赖，缺失项保留为后续`blocker`或停止线，但不在本轮并行追问。开放项若只影响表现且不阻断当前目标，不得为了排期升级成`blocker`。

关闭当前`blocker`只移除它的阻断效力，不等于事件再无开放字段。姓名、人数、材质、逐字措辞等仍未确定但不阻断当前目标时，去掉`blocker:`前缀后继续作为普通`Open Fields` token 保留；只有确实没有任何设计开放项时才写`-`。同步回读卷纲、准备稿或准入清单中的开放项，避免锚表清空而自然语言仍列缺口。`--require-ready`只拒绝带`blocker:`前缀的字段，不应把普通开放 token 当成未准入。

整表进入目标阶段时仍使用`--require-ready`。只复核少量已关闭事件时，可同时传`--ready-events EV-120,EV-121`：脚本继续校验全表结构，只对显式选中事件检查`confirmed + aligned + 无 blocker`；其`Depends On`上游只须保持`confirmed + aligned`，不会继承上游自身场景 blocker，也不会因`overlap`或`same-window`扩张局部门禁。事件表存在`Natural Duration`列时，选中事件不得留空或写`-`；`unknown`仍可保留。该局部结果只证明所选记录的声明状态，不证明依赖场景细节、自然时距语义、持续状态或正文整体已经准入。

#### 目标阶段语义准入与因果可达

准备从事件轴进入章卡、正文或阶段收口时，结构校验以后必须再过一次目标阶段语义准入。以下任一信号出现即触发：两条以上剧情线发生作用、人物或物件跨地点移动、消息或命令多级接力、等待窗口、伤愈、持续状态、世界内汇合，或相关`Natural Duration`仍为`unknown`。纯格式校验、只调`P`锚的呈现编辑，以及不会改变当前选择与结果的场内微节拍不触发。

先声明本轮目标范围，再从目标结果反向切出必要事件和跨线接口。未知值若取不同结果会改变先后、到场、知情、人物可行动范围、选择或结果，就升为当前范围的语义`blocker`；姓名、材质和逐字措辞等不改变可行性的字段继续作为普通`Open Fields`。局部范围只继承真实依赖，不因全卷后段或无关支线仍有未知而机械阻断。

时间关系与作用关系分开记录。`same-window`、`overlap`、`exact-sync`和`Depends On`都不自动表示导致；需要审查的作用边使用以下最小类型，不扩成第二套事件表：

- `precedes-only`：只有先后，没有作用；
- `requires`：下游须等上游完成，但上游不是充分原因；
- `enables`：上游改变行动条件或可选范围；
- `triggers`：上游作用直接启动下游变化；
- `informs`：消息、证据或观察改变受体知情与判断；
- `constrains`：持续中的环境、资源、伤势或制度状态限制下游；
- `handoff`：责任、物件、权限或资源经真实承载者转移；
- `feedback`：结果反过来改变后续人物、制度或世界状态。

复杂边只生成临时因果边卡：

```text
来源事件 / 源状态：
边类型：
载体或机制：
受体 / 观察者：
最早起效与必要时滞：
可观察结果 / 证明上限：
反事实：移除本边后，哪些结果仍会发生：
```

涉及普通移动、消息、命令、环境变化、等待或持续状态时，按需展开独立时钟预算：产生或出发、传播或移动、接收、理解、执行、反馈；分别给最低时距、可判定上界或依赖条件，区分可并行步骤、必须串行步骤、动作完成和结果继续存在。没有证据时保留自然时间包络，不用`T`数字差、临时捷径、即时传讯或伪精确日期填空。

世界内汇合若会驱动人物决定，还须说明：

```text
Join Predicate：哪些分支状态必须满足
Observer：谁需要知道条件已满足
Observable Signal：通过什么普通信号得知
Earliest Signal Time：最早何时可收到并理解
Timeout / Fallback：未收到信号时怎样停止、等待或改判
```

作者侧知道分支完成不等于角色侧可行动。若只是正文把几条线剪到一起、并不驱动人物选择，标为叙事汇流即可，不强造角色可见信号。

收口固定分别给出四项 verdict，不用一个`PASS`覆盖：

```text
结构：锚、依赖、并发和路径是否可解析
记录：权威、状态、引用和旧值是否已对齐
语义：自然时距、因果可达、人物知情与持续状态是否成立
阶段：当前目标范围能否进入章卡、正文或下一阶段
```

结构或记录通过而语义未闭合时，阶段必须为`CONDITIONAL / BLOCK`；只推进最早的语义`blocker`。这一判断是从现行权威生成的临时检查投影，不建立永久因果图、第二时间线或新的正典 Owner。

角色意见冲突依次服从：现行权威与授权，人物真实选择与可行动性，因果、时距和信息边界，读者清晰度与既有承诺，最后才是场景效果和结构美感。方向期作品在人物命题与故事发动机成立前只使用正典守门及必要的人物视图，不为完成复核提前生成事件核、时间轴、卷目或场景；人物命题已经确认而故事发动机仍开放时，当前唯一`blocker`是用“谁必须行动、为何是现在、主要阻力、不可逆结果”关闭最小故事发动机，具体身份、时代和地域只作为比较发动机的候选变量，不先各自锁定。规划期再按具体事件启用事实完整性轮，章卡和正文期才进入写作准入轮。

- **稳定事件号**：`EV-042`只标识同一个作品内事件。讨论顺序、设计顺序、发生位置或正文位置改变时不另造事件号；移动既有事件须沿真实依赖检查下游。
- **发生锚**：`T120.02.030`依次表示全局时间窗、稳定剧情线编号和该线内部顺序。各段以数字递增，初建时宜留出间隔；若只知道较粗窗口，可写`T120~140.02.030`，不得用伪造日期换取精确外观。
- **自然历时**：`T`锚及其数字差只用于逻辑定位，不换算成日、时辰、年月或路程。动作历时、相隔时距和结果状态持续多久仍写在事件卡的`必要历时`；普通事件可不增加表列，但完整锚表涉及移动、消息、命令、等待、伤愈、持续状态或跨线汇合时，`Natural Duration`为条件性必需列，未知也写`unknown`或对应`blocker`。不能用`T620~670`代替“三小时”或“一夜”；一个动作完成后造成的封路、伤势或制度状态可能继续存在，须分别记录动作历时与结果状态持续时间。
- **时间轴命名空间**：王朝史、分卷剧情、梦境或其它无法直接共用零点与尺度的时间轴并存时，每张表先声明稳定`Time Axis`，同一轴内再比较`T`锚；不同轴可以各有`T000`，跨轴先后或同步必须另写对齐事件和证据。现行校验脚本一次只校验一张已声明单轴的表，不把多个轴塞进同一`T Anchor`字段。
- **落位状态**：事件存在已经确认但卷章或发生窗口尚未确定时，保留稳定事件身份，并在最小事件卡或项目已有未落位清单中写`Placement: unplaced`、已知上下界、依赖和`blocker:placement`，不要为进入逻辑锚表编造`T`值。若连事件是否发生也未确认，只能保留条件式候选；不能从“寻找”“预备”或“可能前往”推出“必然再遇”“必然到达”，也不能给它写`confirmed`发生锚。
- **线路角色**：`00`只用于共同事件或汇合节点，角色为`global`；`01`至`99`是稳定线路编号，当前单元中的`main`或`side`另行记录，不把主次永久编码进编号。支线后来承担主叙事时只改角色，不重编号。
- **正文呈现锚**：`P070`记录正文展示位置；一个事件分段交叉呈现时可列多个`P`锚。倒叙、回忆、延迟揭示和交叉剪辑只调整`P`，不因正文后写、后讨论或后设计而移动`T`。
- **权威与状态**：`Authority`指向保存事件主要行动事实的领域权威，而不是受影响最显眼的文件；关系文件只维护关系状态增量，人物档只维护个人选择和长期后果。本地 Markdown 的裸路径默认相对显式项目根，`./`、`../`开头的路径及 Markdown 链接目标相对当前时间线文件目录；语法唯一决定基准，不按文件是否存在回退猜测，绝对路径或解析后越出项目根的路径无效。指针带标题锚时必须仍能回到现行 ATX 标题，标题改名而引用未同步视为记录未对齐。`Canon Status`区分事件是否成立，`Record Status`区分当前有效载体是否已对齐，`Open Fields`保存仍可设计的动作或细节；会阻断当前目标阶段的开放项加`blocker:`前缀。事件可以同时是`confirmed + aligned + blocker:scene-detail`，表示高层事实与记录已经稳定，但目标正文仍未准入。项目已有状态语义时以项目权威为准；只有项目明确采用本表时才使用这些规范化值。
- **载体选择**：只有一张局部逻辑锚表且现有卷纲、事件权威或准备稿能够承载时，直接嵌入现有载体并回指领域权威；只有多个稳定消费者或表格已经压过原文件职责时才拆出派生时间线。不得为运行脚本新建第二正典。

同一全局窗口下的多路剧情组成**并发场景组**。每条线仍须分别维护 POV、地点、行动者、目标、知情、资源、必要历时、选择和离场状态；离开正文视野不等于停止世界时间。时间关系只用当前证据能支持的一种：

- `same-window`：同一粗时间段，不证明同时开始或同时结束；
- `overlap:EV-nnn`：两个事件的自然历时确有重叠；
- `exact-sync:EV-nnn`：同一世界时刻，须有共同钟声、天象、爆发、阵法响应或其它可核对证据；
- `unknown-order`：只知道落在同一窗口，严格先后保持未知。

时间关系不自动取得因果效力：同窗或精准同步只说明时点关系，不能据此把到场者写成触发者、参与者或机制承受者。一次机关、异象或其它机制启动可以让不同分支经过各自历时后先后完成；分别锚定各分支的完成时点和离场状态，不得仅因到达有时间差就补成回震、二次触发或第二次启动。

跨线影响必须写真实`Interface`，接口只来自消息、人物移动、资源转移、共同环境变化或会合。`Depends On`只表示前置事件已经完成才允许当前事件发生；若持续中的支线从开始时就约束主线，用`overlap`、`Interface`和`State Delta`明示进行中的环境或资源状态，当前事件只依赖“已经起效”时可另拆一个起效点，不把整段持续事件伪写成完成依赖。起效点与对应持续范围用`overlap`及状态增量说明“从此开始”，不得写成`exact-sync`；现行协议的`exact-sync`只用于两个共享同一世界时刻的单点事件。汇合节点使用`00`线，只依赖真正参与汇合的分支末端；无关支线可以继续，不为同步高潮被强行收束。没有独立行动者、目标、选择和状态增量的内容只是交叉剪辑片段，不升格为独立支线场景。

项目明确采用该协议且事件已经落位时，时间线 Markdown 表使用以下必需列；字段未知写明候选、开放项或阻断，不留空白。普通事件可按需增加`Natural Duration`；命中上述移动、消息、命令、等待、伤愈、持续状态或跨线汇合条件时，该列为条件性必需。现行脚本只校验其非空，不裁决时距语义、持续约束或`Authority`职责：

```text
| Event ID | Authority | Canon Status | Record Status | Open Fields | T Anchor | Line Role | Time Relation | Depends On | Interface | State Delta | P Anchor |
```

例如同一时间窗内，主线战局、追踪者接近和另一地后果线可分别锚为`T080.01.010`、`T080.02.010`、`T080.03.010`；追踪者抵达写成`T090.00.010`，只依赖战局形成窗口与追踪完成，不依赖尚未同它相交的第三线。正文可用多个`P`锚交叉呈现，但不得反向制造人物知情或跨线因果。

### 剧情承继与时序锚定

设计新剧情先辨当前效力：已确认正文、正典事实和作者锁定的约束是硬边界；现行工作大纲或卡片中的规划性安排是当前设计约束，作者可以显式修订，但修改前后须清理依赖；提要候选、试写和灵感不自动约束后文。文件名不替代内容状态，同一卡片中的已确认事实仍按硬边界处理。

反向设计依次过两道门，不能互相替代：**效力门**判断谁有权改变当前约束，硬边界只由作者显式修订，现行设计约束可由作者显式修订，或由小说家在明确覆盖该节点的自决授权内修订；人物因果再充分、当场压力再强、伏笔再完整，也只证明候选可能成立，不赋予修改权。未过效力门时，反向方案只作待确认候选，当前大纲继续沿原约束承续，受影响下游保持阻断。**承续门**判断取得效力的修订或不改写旧事实的回释能否在故事内成立，须能从既有支点和当场触发走到人物选择、代价、结果与反馈；未过承续门时不得把断裂包装成连贯剧情。

每个进入设计稿、总纲、卷纲或章纲的剧情节点先标明是**作品内事件**还是**纯呈现节点**。作品内事件必须在事件发生轴上锚定，至少写清**所属线或局部时钟、绝对时点 / 相对时点 / 可判定窗口、必要历时、前序节点或前置条件**；再记录进入状态、行动或选择、结果与状态增量、下游接口。纯呈现节点不虚构独立发生时点，须指向所呈现事件的发生锚点，并记录卷章位置、读者所得及其对当前阅读的作用；若人物在作品内讲述、读取或回忆并因此改变状态，这次讲述、读取或回忆本身另作事件锚定。时点未知时用相对窗口、范围或 `blocker` 锚定，并说明依赖什么才能收窄；不留无锚空白，也不伪造年月日。倒叙、插叙和回忆只改变呈现位置，不免除其内部事件的发生锚点。

新节点沿`上游承诺与前置状态 -> 当场触发 -> 行动与阻力 -> 人物选择 -> 结果 -> 状态增量 -> 下游接口`承继，并按与当前设计的关系归类：

- **顺承**：直接继承上游结果，在已有目标和约束内推进。
- **递进**：扩大既有冲突、代价或选择难度，但不改写其来处。
- **回释**：既有可见规则、异常、行动或关系支点在后来获得新含义；旧行动、人物当时的有限认知、真实选择和已经支付的代价继续成立。
- **显式修订**：按效力门由作者改变硬边界或现行设计，或由小说家在已覆盖当前节点的自决授权内改变现行设计并记录依据；新值取得效力后仍须通过承续门，并逐项声明时间、人物移动、消息传播、人物知情、关系、资源、伏笔和下游章纲是已更新、待更新还是不受影响，旧依赖在清理前失效或阻断正文准入。
- **无据漂移**：未获修订效力便把反向候选写成当前剧情，或虽已取得修订效力却没有既有支点、足够的当场触发和完整的选择后果链；不得写入当前大纲或正文。

“这是伏笔”不是桥，更不是授权。反向推进若按回释准入，至少要能指出此前读者有机会接触的支点、新旧行为之间的真实连接、人物此时可知或误知的触发、改变选择所需付出的代价，以及反作用怎样进入后文；不要求线索事前唯一锁定答案，也不能临时补一个隐藏身份、万能证物或新规则抹平断裂。未过效力门时先按原设计顺承，反向方案只作待确认候选；已过效力门却无法桥接时标记承续 `blocker`，不把两条互斥剧情继续并列。

### 角色本位的局势演化

剧情不从预定转折倒推人物动作。先从当前权威继承人物底色、被当场唤起的过往因果痕迹、关系债务、知情与误解、身体资源和上一单元离场状态；再区分已确认事实、创作候选与待确认项，不让恢复摘要、旧稿或本轮新设的涉案者、凭据和真相自动成为事实。规划输出若使用输入未确认的具体身份、凭据、制度动作、因果机制或真相，先用一句总括标明这些内容仍是候选，不为每项重复贴标签；总括须覆盖本轮全部未确认内容，不能只标一类而让其余细节事实化。只有作者确认或落入明确自决授权后才能写入卡片与权威。人物依据读 `character-craft.md`，跨轮权威与状态依据读 `continuity-and-revision.md`。

作者侧沿`继承状态 -> 感知或误读 -> 相互冲突的冲动 -> 有限选择 -> 他人、制度与环境反作用 -> 即时、延迟或非预期后果 -> 新局势`推演。把当前时间、地点、身体、资源、时限、通行或发言资格、可用物件以及其他行动者正在进行的事务压入选择；不会改变选择或读者理解的背景留在作者侧。人物不要求永远理性或最优，动机也不必唯一；其他行动者即使不在主角视野内，仍按自己的目标、知情、关系和能力行动。

输出前做两项承重检查：

- **承重者闭环**：落笔前列出题面明确出现且会影响主线的行动者，逐个确认其此刻目标、知情、能力与可见影响；未出场者也说明正在做什么、为何不能介入或消息怎样抵达。机构接口若只有规则功能，说明规则由什么条件触发、怎样执行并改变选择，不为填表强造角色目标。
- **失常选择闭环**：人物若作出违背常态的关键选择，显式核对其当时所知或误读、辨识把握、身体与能力、正在承担的责任、可求助者、不可兼得的时限及环境阻碍；输入未提供的承重条件列为待确认或候选，不能跳过或补成事实。作者侧必须存在足以压过惯性的当场支点，并说明替代动作为何不能免除其亲自承担；正文是否让读者当场看见完整自我辩解，服从 POV、叙事距离与揭示时点，可以只留下可回望的动作、克制或片段心理。不得只说人物已有矛盾、冲动或创伤，也不能只补一个促使其折返的信号。

规律表现为约束、趋势、反馈与代价，不是替人物决定结局的宿命；偶发事件可以改变机会、顺序和信息窗口，不能替人物完成核心选择、免费送来答案或抹掉已确认取舍。反向检查人物选择能否回到其底色、过往、有限认知和当场压力，正向检查即时与长尾后果是否真实限制下一步；只有前者没有后者，剧情会停成人物切片，只有后者没有前者，人物就成了作者搬运结果的工具。

只处理全书 / 卷的核心问题、阶段状态变化、高潮取舍和后续承诺，尚未下钻具体事件节点的轻量总纲或卷提要，不强制事件卡。大纲一旦列出具体剧情事件，每个事件须先按上述类型具备发生锚点或呈现指针；设计稿、章纲、复杂时序复核和修订影响再维护以下承重项，不强制所有正文场景填满表格：

```text
事件 / 场景：
节点性质：作品内事件 / 纯呈现
当前效力 / 承继类型：
稳定事件号：
权威指针 / 正典状态 / 记录状态 / 开放字段：
时间轴 / 落位状态 / 发生锚 / 线路角色 / 时间关系：
必要历时：
因果边 / 可达接口（按需）：
人物、消息、命令、环境、等待或持续时钟（按需）：
前序节点 / 前置条件：
进入状态、人物底色与被唤起的过往：
各方目标、知情 / 误解与关系压力：
行动 / 选择、场景约束与偶发扰动：
结果 / 状态增量：
下游接口、跨线传递或回忆进出锚点：

```

设计稿、章纲、复杂时序复核或修订影响表先列受影响节点清单，再为**每个受影响的作品内事件**逐项使用这张最小事件卡，二者数量与名称须对得上；清单包括被修订事件、依赖它的上游与下游事件、人物移动、消息传播、仍须兑现的硬结果，以及获准后才可能生效的条件式修订候选。字段没有材料也要明确写未知、待收窄窗口或 `blocker`，不能合并省略，不能用一条总体因果链、章节顺序或“随后发生”替代逐节点锚定。每项一行即可，不在卡外重复叙述。

消息、命令和线索先区分产生、载体、传播、接收与理解接口，下游人物的决定只能锚在自己最早可能收到并理解之后，不能用另一人物已经知情代替。物件或证据跨卷留存时，把保存条件、人物抵达、取得资格和读取后的行动反馈列为下游接口。处理纯呈现时，先给材料已提供的作品内事件逐项建卡，再建指向它们的呈现卡，不能只写呈现卡。身份或真相揭示若在作品内确有讲述、读取、对质或行动，必须分别交付一张发生事件卡和一张正文呈现卡；时点未知可用卷内窗口，但两者不能合并。若材料只说读者从另一条线提前知道，而没有提供作品内信息事件，就把它记为指向既有事实的纯呈现及读者所得，不补造传讯、目击或讲述。卷章位置不得兼任发生时点与呈现位置。交付前最后对账：受影响节点清单与事件卡一一对应；显式修订已逐项声明人物移动和消息传播的处理状态；凡写到“揭示、对质、读取、讲述”，均同时存在作品内事件卡与正文呈现卡。任一项缺失即保持 `blocker`，不以总体说明代替。

复杂主线按 `SKILL.md` 协同 `huaxia-practical-wisdom`，只消费能缩小误差的叙事校准：提案的名称和实际效力是否相称，人物与事件是否处在能成立的时位，新节点继承了什么、舍弃了什么，不可兼得时谁作选择、谁受益、谁付代价，行动反馈怎样形成下一阶段的新条件。经典名词和校准卡不进入正文，也不替作者确认正典。

并行或多线剧情为每条线保留自己的局部时钟、地点、行动者、目标、知情、资源与状态链，再用共同事件、消息传播、人物移动、资源转移、环境变化或会合节点对齐全局。切线不自动表示时间跳跃；只按读者定位需要给出最小时间、空间或共同事件锚点，并让未出场的行动者继续按自身利益和条件行动。规划每个切口时同时记清本线经过多久，以及其他线在这段时间继续、等待、受阻还是已经结束什么行动，不用一句“与此同时”抹平局部时钟。跨线影响必须经过真实接口：消息有传递与理解时间，路程有距离与阻碍，命令有执行偏差，资源转移会使原持有者失去选择。不同线可以错过、先后抵达或只在后果上相交，不为制造同步高潮让所有人同时知道、同时行动或同时会合。

### 线索驱动的多线协作

多线围绕同一事件、秘密或读者承诺演进时，每条线除局部状态外只增加当前推测及其行动依据，不复制一张全知答案表。跨线线索沿`线索产生者 -> 载体 -> 传播时间与失真 -> 接收者 -> 理解或误解 -> 行动 -> 跨线反馈`传递；没有真实载体的相似意象、巧合或主题呼应不能自动成为证据，也不能让人物共享作者本真。

同一线索可以在不同位置、利益和时势下形成不同推测，一条线也可以只承载代价、阻碍或后果，不要求所有线都参与解谜、共享结论或同步会合。每次切线检查新获得、失去或误解的信息怎样改变选择，并让行动反馈支持、削弱或推翻原推测；若一条所谓支线没有独立行动者、目标、选择和状态变化，只负责递送答案，则并入场景或跨线接口。

倒叙、插叙、回忆、梦境和不可靠记忆先标明它们在事件发生轴与叙事呈现轴上的不同位置，再检查进入刺激、时间或空间定位、返回当下的锚点及其当前作用。它们可以延迟真相、重释旧事或显露人物偏见，不因非顺叙被判错；但结束后须改变当下判断、关系、风险、行动或读者理解。人物记忆可以残缺或错误，作者本真、人物确信与读者所得仍须分层；若删去整段不影响当前单元，只保留必要片段或移出。

## 节奏与呼吸

规划一批章节时联合检查句段的信息与感知速度、场景加压与恢复、章节进展或揭示、跨章张力变化及卷级承诺消耗。连续高压只要每次改变约束、选择、关系或后果就可以成立；连续章节功能同质、代价长期未清或读者承诺被拖欠时，再插入或改写清算、关系、线索、世界侧面或情感沉淀。缓冲不是停滞，也必须改变后续处境；不规定每几章一次缓冲、峰值后几章降压，也不把短句、长句或节拍标签直接等同于快慢。

## 层级契约

- **全书**：核心命题、主角长线变化、主要力量及不可逆终点。
- **卷**：卷首状态、阶段目标、主要阻力、不可逆转折、卷末新状态和后续接口。
- **幕/阶段**：目标、升级、选择、代价和阶段反馈。
- **章**：进入状态、行动目标、冲突、异常升级、信息或关系变化、代价、章尾推动力。
- **场景**：视角人物、地点时间、即时目标、阻碍、动作、感官细节、转折和离场状态。

下层必须改变上层状态；没有变化的场景应合并、删去或改写。

## 分层规划与作者讨论

按当前任务需要增加分辨率，不把所有层级一次写满：

```text
总纲 -> 卷提要 -> 作者裁决 / 明确自决授权 -> 卷卡
卷卡 + 已发生正文 -> 章节提要 -> 作者裁决 / 明确自决授权 -> 章卡 -> 正文 -> 状态回写
```

提要用于讨论，允许保留少量互斥候选；卡片只固化作者已确认或明确授权 Agent 自决的当前契约。先区分已确认、候选、待确认和可临场调整，再列出会改变核心因果、高潮、结局或读者承诺的关键分叉及其依赖；除用户已经点明的显性选择，还要检查互斥机制、揭示时点、关键物件或资源功能等会改变选择含义的隐含前提。只展开当前主 blocker，给出推荐及理由；不得因一次只请作者裁决一个 blocker 而隐藏其他关键分叉，依赖当前主 blocker 的其他分叉只列候选关系，不替作者选定。已有自决授权时直接采用最合适的候选，记录采用、舍弃及对上层承诺的影响，不重复请示。表现细节、场景顺序或章节边界若不改变承重状态，留给写作现场；表现细节只包括场内可感的动作、语气、节拍、空间与感官呈现，不授权新增场前、场外、人物过往或新的因果凭据。

### 创作承续与草稿落地

多轮讨论只增量收集会改变人物、关系、事件、时间、世界规则、知情、读者承诺或后续选择的承重内容。这类作者侧材料称为**创作承续条目**，不与小说内部证据或伏笔混称“线索”；客套、重复表达、纯措辞和不承重的生活细节不强制入账。只处理当前会话与作者明确提供或授权读取的材料，不把完整会话日志、模型记忆或恢复摘要当成事实权威。

每轮沿`作者原话与项目事实 -> 保留不可替代原意 -> 小说家公开建议及依据 -> 作者确认、修订或保留未决 -> 发生轴 / 呈现轴 / 因果状态链归位 -> 影响检查 -> 草稿或权威写回 -> 下一轮承续入口`处理。只有作者明确确认，或内容落入已经授予的自决范围，才改变当前契约；沉默、未反对、试写完成和小说家偏好都不是确认。

承续草稿同时保留当前内容和协作依据，但二者效力分明；多轮材料先用一行一轮的紧凑确认表记录`议题 / 来源、作者原意或未提供、小说家公开判断维度或未提供、确认 / 修订、改变的事实 / 人物知情 / 读者承诺 / 下游行动、唯一权威位置与其它载体引用`，再落发生轴、呈现轴和因果状态链：

```text
当前有效草稿：
发生轴 / 呈现轴 / 因果与状态：
协作确认脉络：
- 议题与来源：
- 作者明确说出的原意与不可变约束：
- 小说家公开判断维度、依据、风险与取舍：
- 作者确认 / 修订：
- 当前结论与取舍理由：
- 影响、回写和后续验证：
未决边界与停止线：
事实与权威指针：
```

协作确认脉络须尽可能详细地保留对后续创作有用的公开交换：问题为何出现，作者明确说过要保护什么，小说家使用了哪些公开判断维度、依据、风险与代价，作者怎样确认或纠正，最终选择改变了哪些时间线、卷纲、章卡、人物知情和读者承诺。不得从最终采用结果反推作者未说过的创作意图；输入没有明确表达时，“作者原意”写“未明确表达”，只把可见效果放进小说家判断或当前取舍。裁决后用“旧生死方向”“旧身份方向”“旧传讯方案”等中性功能名或原讨论 / 版本指针指代退役对象，不再写出会与当前结论竞争的完整旧命题。只记录对作者可见的依据与取舍，不保存模型隐含推理轨迹，也不把逐字聊天搬进草稿。

详细不等于并列保存冲突。作者裁决后，当前有效草稿只写当前结论；协作记录和历史也不得完整复述被否定的互斥命题，不另建“已退役方案”段落继续传播，只用中性功能名简记退役原因、影响是否清除，并按需引用原讨论或版本指针。尚未裁决的互斥分叉只记录待解决的问题、判断维度、影响、裁决依据和下游停止线，不把各候选值写进当前草稿；作者明确要求比较时，才另交付彼此隔离且明确非正典的候选材料。

作者明确要求保留但暂时不承重的意象、物件、动作或生活细节，进入“保留素材”而不是被丢弃或强升为伏笔；逐项记录作者原意、来源、小说家对作者公开的判断维度、可用场域、当前禁配义和升格条件，不替它补象征、因果或回收任务。只有作者确认其承重功能，或功能落入明确自决授权范围，素材才可升为伏笔、因果、身份或人物定论。作者未要求保留且不影响人物、场景、因果或声音的偶发细节不强制入账。

发生轴只记录作品世界内实际发生的事件及相对时间；“读者在第几卷得知”“正文何时回忆或揭示”只进呈现轴，除非材料另行确认了对应的人物传讯、讲述或行动事件。详细集中在协作确认脉络；当前事实、双轴三层和下游影响各自只写本层新增约束，已写事实后续用指针承接，不在多个小节重复展开。

以华夏经世镜片校准而不堆砌经典名词：以名实区分作者设想、小说家建议、作者确认、工作草稿和正典权威的效力；以时与位把材料放到正确发生阶段、呈现位置和人物知情边界；以取舍保留采用理由、受益、代价与放弃内容的功能；以反馈检查成篇结果怎样反过来修正大纲。当前结论变化时更新真实依赖，不用新摘要遮住旧冲突。

### 卷提要与卷卡

卷不是任意篇幅切段，而是全书内部的中程叙事单元。卷提要先回答本卷为何存在：怎样承接全书终点与长期承诺，本卷自己的核心问题、阶段故事发动机、人物与关系变化、主要阻力、高潮选择和卷末交付是什么。高潮优先由人物面对不可兼得目标时的选择与代价形成；卷末须兑现本卷主要承诺，同时明确已转交、转义、退役或新建立的后续承诺，不能只靠突然中断制造下一卷需求。

作者确认后再形成卷卡：

```text
全书承接与本卷核心问题：
卷首状态与阶段目标：
人物 / 关系变化：
主要阻力与升级链：
不可逆转折：
高潮选择与代价：
卷末新状态与已兑现承诺：
后续接口与待回收承诺：
事实与权威指针：
```

卷卡不预设固定章数、三幕比例或远期逐章事件。写作改变了人物、因果或读者承诺时，先记录影响；只有作者确认或明确自决授权范围内的变化才能修订受影响的卷卡，否则保留候选差异并交作者裁决，不让成篇文字或旧卷纲成为第二正典。

### 章节提要与正文准入

章节提要先核对上一章实际离场状态和当前权威，再说明本章为何存在、必须改变哪些行动 / 关系 / 信息 / 风险 / 资源状态、候选场景链、核心选择与代价、章尾新状态及不得提前揭示的信息。进入状态只复述当前权威已经给出的事实；材料没有说明的物件归属、地点、时点、动机或因果保持待确认，不为填满章卡擅自补齐。场景先按因果和情绪关系成链，再决定合并为一章还是拆章；章节边界服务小型弧线、节奏、情绪闭合或翻页期待，不强制一章一场，也不要求每章 cliffhanger。

进入正式正文前确认：

- 当前权威上下文和上章离场状态已经核对；
- POV、时间、地点及人物 / 读者知情边界无冲突；
- 当前创作单元调用的世界硬约束及跨系统依赖已按 `worldbuilding-and-research.md` 核对；长篇与超长篇还须确认全书外框和当前卷运行系统不存在会推翻正式正文的承重缺口；
- 不得把读者专属线索改写成人物可感暗示，不得补造权威未确认的场前 / 场外事件、人物过往、对白、记忆或因果凭据；“只授权本场表现细节”不改变这条边界；
- 本章必须改变的状态、核心选择、代价和章尾可承接状态明确；
- 不存在会推翻本章核心因果、当前卷运行或全书长期承诺的待确认项。

缺少承重条件时继续讨论，不靠补猜进入正文。作者明确要求先看效果时，可以交付标明边界的非正典压力测试，不写回权威。正式正文完成后按实际结果记录状态增量，以及章卡中兑现、移动、转义或退役的内容；临场发现更有效写法时以真实成篇为候选依据。已核对且无冲突的准入项只报告结论，不逐项复述；合并重复的边界说明，只展开当前主 blocker、其他关键分叉、候选差异及其影响。只有作者确认或明确自决授权范围内的变化才能回写卡片和后续承诺；超出授权的变化只记录为候选差异并交作者裁决。

纯正文交付前做一次正典增量扫描：逐句检查所有发生在开场前或场外的动作、旧对白、回忆、物件属性、关系细节和因果凭据。输入或当前权威没有明确给出的内容一律删除，或改写为当前场内可见事实与不带新增细节的既有关系反应；例如只能写“妹妹仍在官差手中”，不能补写“她被带走时回头、没有哭、说过什么或穿着什么”。扫描只在内部执行，不把清单混进正文。


## 发布载体与叙事语体

先锁定事实、人物欲望、关系和类型承诺，再按发布载体选择视角、人称、叙事距离、人物声音、节奏、段落与信息密度；载体改变表达，不改写人物性格或新增事实。

- **纸媒文学短篇**：保护叙事呼吸、复义、生活细节和整体回响，允许段落长短随场景变化，不强制早期解释或章尾悬念。
- **移动端连载**：控制单屏信息负荷，用短段落、早期异常、清晰进展和章尾推动力支持连续阅读；不把载体适配退化成只切短句子。
- **有声叙事**：保证人物声音可辨、场景切换可听懂，重要信息不能只依赖视觉排版；不把口语化等同于降低叙事密度。

两种版本需要真正改写叙事组织，而非只换标题、断句或段落长度。制造钩子不得取消人物迟疑、生活质感、行动代价和后续余波。

## 章卡

```text
类型 / 节拍：推进 / 峰值 / 缓冲（代价·对话·线索）
本章功能：
主视角与进入状态：
事实与权威指针：
行动目标：
阻力与异常升级：
人物选择：
信息 / 关系 / 风险 / 资源变化：
代价与余波：
章尾推动力：
不得提前揭示：
```

事实与权威指针只引用本章实际调用的正文、人物、规则、时间线、活跃承诺或原始材料及其当前版本；摘要和恢复简报只作索引，不能替代事实权威。类型 / 节拍是规划时的叙事功能提示，不是不可修改的标签。临场发现新人物、事件或更有效写法时，先核对它是否改变上层状态和读者承诺；授权范围内再更新、移动、合并或退役章卡，超出授权则只记录候选差异并交作者裁决，不为服从旧表格牺牲当场故事，也不让成篇自动升级正典。章尾推动力优先留下关系、决定、风险或情绪的余力，不只靠突发声响或陌生人出现。章卡钩子记录计划中的因果功能和读者承诺，不锁死字面事件：尚未形成承诺时可以有依据地删除、移动或转义；已经形成承诺时须兑现、转义或明确改变承诺，不能被临场刺激静默替换。下一章第一拍须承接上一章留下的动作与后果：扩大、改变或迫使人物承担它，不复述、不无因降温，也不长期切走拖欠。
