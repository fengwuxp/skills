# 故事设计与正文创作

## 使用时机

构思故事、设计总纲/卷纲/章卡、续写正文或评审叙事时读取。本文不规定固定三幕、字数或网文模板；结构必须服务作品类型和读者承诺。

## 故事发动机

先用一句话回答：谁想得到什么，为什么现在必须行动，什么力量阻止他，他愿付出什么，行动后会失去或改变什么。

主角不能只承接设定和旁人安排。即使被卷入事件，也要尽快形成自己的判断、选择和代价。配角至少承担阻力、镜像、关系、信息或后果中的一项，不因名单完整而出场。

## 经世叙事校准

把 `huaxia-practical-wisdom` 的镜片转成叙事问题，不在正文讲方法：

| 镜片 | 叙事追问 |
| --- | --- |
| 察实 | 人物实际知道什么，误以为什么；作者事实与传闻是否分开 |
| 正名 | 身份、名分、权力、责任和真实行为是否相称 |
| 审时 | 旧秩序哪里松动，新力量何时进入；行动为何发生在此刻 |
| 权衡 | 每种选择由谁获益、由谁付代价；反面力量如何制约 |
| 行验 | 选择怎样变成可见行动，环境和他人怎样反馈 |
| 化 | 后果怎样改变人物、关系、制度和下一阶段问题 |

人物不是镜片的例题。先写欲望、恐惧、偏见、关系与有限认知，再让镜片检查行为是否名实相符。

## 三层真实与戏剧许可

- **世界真实**：世界规则与后果必须自洽；已经成立的限制不能只在主角需要时失效。
- **事件真实**：低概率、偶然和反常可以发生。巧合可以制造或加剧困境，不能反复替主角解决困境、抹去代价或取消选择。反常事件不必成为谜底、主因果或世界真相，也可以只改变体验、关系或生活秩序；不强迫不同异常共享原因，不因异常规模大就缩小、删除或并入主因果。
- **心理真实**：人物可以不理性，但冲动、误判和失控须能回到其情感、偏见、有限认知、身体状态或处境。心理支点不等于外部证据链：人物可以不相信消息来源，却因无法承受消息为真而行动，这种不敢赌为假本身就可以成立。若现有心理支点已经成立，不新增外部证据，只校验人物能否实施行动以及行动后的现实后果；不要为了“修逻辑”把人物改成证据充分的最优行动者。

转折应当意外而可回望：不要求读者事前猜到，也不要求立即解释；回看时能从人物、时势或既有规则找到支点即可。荒诞、魔幻现实、黑色幽默等类型可以保留未知，不强行补成科学说明、完整魔法体系或调查主因果；发生后的伤害、利益、关系变化和余波仍按真实世界的重量处理。

处理真实事件、见闻和传说时，把事实真实性与叙事可信度分开：事实主张能支持到何种结论，由证据状态、来源独立性与可靠性决定；故事是否可信由视角、场景、人物反应和后果承载。即使一件事低概率、动机不统一或结局不明，也不改写事实来迎合常识；可以调整揭示顺序和叙述距离，不能替真实人物补统一动机，也不能把传说异文硬收成历史结论。具体来源分层读取 `worldbuilding-and-research.md`。

## 层级契约

- **全书**：核心命题、主角长线变化、主要力量及不可逆终点。
- **卷**：卷首状态、阶段目标、主要阻力、不可逆转折、卷末新状态和后续接口。
- **幕/阶段**：目标、升级、选择、代价和阶段反馈。
- **章**：进入状态、行动目标、冲突、异常升级、信息或关系变化、代价、章尾推动力。
- **场景**：视角人物、地点时间、即时目标、阻碍、动作、感官细节、转折和离场状态。

下层必须改变上层状态；没有变化的场景应合并、删去或改写。

## 伏笔与承诺闭环

草蛇灰线不是把每个物件都变成谜底。先按承诺强度区分：

- **硬伏笔**：直接支撑主因果、身份、规则或结局；未发布改稿可删除、转义或明确退役，已交付读者后必须在正文回收、转义，或正式修订已发布文本。
- **可呼应意象**：用于情绪和主题回响，可以复现，不承担证明责任。
- **生活质感**：只让人物和环境可信，不制造未来承诺。
- **误导线索**：当场须有真实来源和局部解释，不能靠作者隐瞒关键事实欺骗读者。

伏笔规划只在作者侧保持清晰，不按章节给伏笔配额，不要求每个候选细节参与谜底；弱线索可以直接淘汰。伏笔不要求读者事前唯一锁定答案，不把“无法唯一证明”当成缺陷，也不为此新增身份锚点；只要求揭晓后回看成立且不依赖临时新规则。硬伏笔的设计链条为：首次出现服务当场戏 -> 自然强化 -> 语境变化或误读 -> 回收窗口 -> 由行动、选择或后果揭示 -> 余波进入后续。回收要改变人物行动、关系或世界理解，不用解释会逐条点名。

结尾闭合不等于回答所有问题。主角核心选择、主因果、关键关系变化、公平揭晓和本作依赖的世界规则必须闭合；人物未来、主题解释、更大世界与不影响本作成立的次要谜团可以开放。删除测试前先判断读者承诺：当类型承诺、结构位置，或反复聚焦并留下可追踪支点，使读者合理期待本作回答时，即使不影响主因果也必须回收、转义或明确改变承诺。一次出现且没有追踪支点的开放项只算留白或意象，不称悬念；悬念应当有迹可循，并明确面向未来而非伪装成本作答案。

再用删除测试划界：暂时拿掉待解释项，若读者仍能理解事情为何发生、人物为何选择、代价与关系如何落定，且没有遗留上述读者承诺，它属于开放空间；若上述理解因此断裂，或承诺仍在，它就是未偿叙事债务。

留白是在当前故事已经成立后不说尽事实或意义，给读者参与想象的空间；悬念是留下有迹可循、面向未来的问题。二者都不能替代本作必须给出的答案，也不能靠“续作再解释”延后核心责任。未发布改稿改变方向时，删除、转义或退役孤立线索；已交付读者的硬承诺按上一条处理，不留“以后也许能用”的债务。

## 发布载体与叙事语体

先锁定事实、人物欲望、关系和类型承诺，再按发布载体选择视角、人称、叙事距离、人物声音、节奏、段落与信息密度；载体改变表达，不改写人物性格或新增事实。

- **纸媒文学短篇**：保护叙事呼吸、复义、生活细节和整体回响，允许段落长短随场景变化，不强制早期解释或章尾悬念。
- **移动端连载**：控制单屏信息负荷，用短段落、早期异常、清晰进展和章尾推动力支持连续阅读；不把载体适配退化成只切短句子。
- **有声叙事**：保证人物声音可辨、场景切换可听懂，重要信息不能只依赖视觉排版；不把口语化等同于降低叙事密度。

两种版本需要真正改写叙事组织，而非只换标题、断句或段落长度。制造钩子不得取消人物迟疑、生活质感、行动代价和后续余波。

## 章卡

```text
本章功能：
主视角与进入状态：
行动目标：
阻力与异常升级：
人物选择：
信息 / 关系 / 风险 / 资源变化：
代价与余波：
章尾推动力：
不得提前揭示：
```

## 真情、可读与去 AI 味

正文优先用具体生活、身体反应、言外之意、矛盾动机、不完美选择、物件和环境变化承载情绪与信息。少替人物总结感受，允许沉默、迟钝、误解和没有即时闭环的段落。

可读与传播来自场景推进、信息差、关系变化及可记忆的动作或意象。能被记住的句子应从人物声音和冲突中长出，不刻意制造金句和口号。删改时重点检查过度解释、整齐排比、人物同声、主题直说、万能反转、每段都完整闭环和连续“不是……而是……”。

## 审查与试写

- **小说家视角**：人物是否主动，因果是否连续，意象与语言是否服务主题，转折是否有铺垫和余波。
- **连载读者视角**：开篇是否兑现类型承诺，本章是否有进展，疑问是否可追踪，章尾是否推动继续阅读。
- **删改判断**：一段文字既不改变人物理解、情绪、行动、关系、信息或风险，也不承担节奏、氛围、人物声音、视角质感、幽默或意象功能时，再删或并入动作。

先试写最小批次再扩展。连续长篇通常先验证 1-3 章；失败时回到最近的卷纲或章卡，不在错误方向上继续堆字数。
