# 故事设计与结构

## 使用时机

构思故事、设计总纲 / 卷纲 / 章纲、与作者讨论关键分叉、判断正文准入、处理开篇承诺、支线或评审叙事结构时读取。场景和正文读 `scene-and-prose-craft.md`；本文不规定固定三幕、字数或网文模板，结构必须服务作品类型和读者承诺。

## 故事发动机

先用一句话回答：谁想得到什么，为什么现在必须行动，什么力量阻止他，他愿付出什么，行动后会失去或改变什么。

主角不能只承接设定和旁人安排。即使被卷入事件，也要尽快形成自己的判断、选择和代价。配角至少承担阻力、镜像、关系、信息或后果中的一项，不因名单完整而出场。

重要配角须有自己的问题，其帮助、拒绝或离场会改变主线；对手须有目标、资源、情报和计划，并在主角视野外行动，受挫后按损失、新情报和剩余资源调整。普通功能角色不强制建立完整副线。实质冲突要求双方目标当前不兼容且各有具体退让成本；不能只用“职责如此”“剧情需要”或单方降智代替动机。

## 生活因果与意外

把故事背景当作所有人都在生活的真实世界。因果负责约束、反馈与结算，不负责证明每件事都由主线需要安排：天气、疾病、误差、延误、资源损坏、陌生人和机构的自行其是都可以在没有预告时改变选择空间；低概率不等于无现实成因，与主线无关也不等于逻辑漏洞。不要为显得严密把意外强编成反派计划、伏笔回收或单一幕后真相，也不要强行把高潮拉回原方案。

意外可以打乱计划，不能直接交付胜利、洗掉承诺或取消人物选择。用户已经锁定核心取舍时，意外可以改变选择空间，不能把这项取舍拆成互不承重的连续小选择来回避代价。发生后让各方按位置、知识、能力、利益和惯性独立应对，由后续选择与代价生成结果；主角不在场时，普通人、对手、机构、环境和资源仍继续变化。伤亡、疾病、迁徙、物价、关系与秩序余波按真实重量进入后文；生活细节可以只属于当下，不必全部变成伏笔。

## 开篇抓手与长期承诺

区分第一拍抓手与作品长期承诺。异常、日常失衡、关系压力、声音或意象都可以成为抓手，但须经过人物职责、有限知识和当场选择改变局面，并让读者知道接下来值得追踪什么。慢热、气氛型、序章或实验叙事可以延迟显性冲突，首章仍须建立人物处境、阅读问题或关系压力，不能只有世界观说明和空泛神秘。

不以固定字数、死亡、追杀、外挂或章尾 cliffhanger 判定开篇有效。廉价震惊若不连接故事发动机、人物责任和可持续后果，只消耗注意力，不形成承诺。

## 想象的两种来路

- **积厚而发**：长期阅读、一手材料、生活观察、历史与专业知识、人物和语言积累，只有能改变人物、关系、场景、因果或叙事声音的部分才进入作品；不堆知识，也不拼贴来源。
- **灵感天成**：突现的意象、声音、人物、冲突或句子先原样保留不可替代的幻想核，与后续加工分开，不急于合理化、筛优或统一世界观。

只有作者要求选择、成形、写入作品或检验可用性时，两种来路才进入“幻想归来”，再接受人物选择、故事因果、世界规则、三层真实、正典状态和读者效果检验。验证服务于成形，不能反向改写或扼杀探索期的原始核。

## 博采与熔铸

广读古典小说、现代小说、网文、短篇、散文及其他叙事传统，先从具体作品提炼可迁移能力，不按门类高下取舍，也不凭标签代替细读：古典小说可取叙述分寸、人情世态与章法照应，现代小说可取个体幽微、视角复杂与复义，网文可取目标推进、期待管理与连载反馈，短篇可取聚焦、留白与不可逆选择，散文可取意象、节奏与感官质地。这些能力并非各门类独有，具体作品若与概括不符，以作品实证为准。

熔铸时按当前作品的类型承诺、人物、场景和读者体验取舍，不设固定比例，不要求各门类等量出现，也不让段落逐一显露技法来源。保持同一叙述主体和统一声腔，让所取技法共同服务人物选择、故事因果与后果；可以分析具体作者如何成事，但不复刻其表面句法、口癖或标志性意象。自成一派不是预设风格标签或短期速成，而是长期阅读、生活与材料积累、持续创作、删改和读者反馈中反复取舍后形成的稳定审美判断与叙事声音，不以自称宗师代替作品验证。


## 故事架构：执简驭繁

按内容、类型、篇幅、作者要表达的故事与要展示的世界确定规划分辨率。先知其要者：不可替代的故事核、主角为何现在行动、类型承诺、核心关系、主要变化轴与必须兑现的结局责任；其余人物、支线、制度、历史和世界信息只有在改变这些要点时才进入架构。执简不是删掉复杂，而是用最少稳定主干统摄可生长的复杂。

篇幅体量与叙事范围分开判断。篇幅不是单纯字数，更关乎主干需要承重多久、因果反馈需要推演多深、多少人物与关系变化需要持续追踪；地域和时代跨度由故事实际承诺的叙事范围决定：

| 规模 | 规划原则 |
| --- | --- |
| 短篇 | 聚焦一次不可逆选择、一个核心关系或一种处境变化；控制视角、人物与解释范围，让局部行动和后果折射未展开的世界；确有跨地域或跨时代承诺时仍保留必要跨度 |
| 长篇 | 以主线统摄卷或阶段目标、关系弧、必要支线与世界揭示；每卷或阶段都形成不可逆新状态，支线必须改变主线、人物或结局条件 |
| 超长篇 | 保持稳定故事核、长期读者承诺与跨阶段因果；只有作品实际承诺主角群、时代、制度或世界范围演进时才预建相应跨度；每个阶段重建可独立成立的故事发动机，定期回收、转义或退役旧线，不提前锁死全部章节 |

类型决定主要承诺和组织压力：悬疑重公平线索与揭晓，成长重能力、关系与认知的阶段变化，情感重关系选择与不可替代性，史诗或制度叙事重多方力量、资源、责任和时代反馈。组合类型先定主承诺，再让次类型服务主线，不为每个类型各造一套平行故事。

重要支线须有行动者、局部目标、阻碍、阶段结果与代价，能在主角不在场时继续行动；同时保留两向主线接口：主线变化会迫使支线转向，支线也会改变主线证据、人物关系、资源或结局条件。只有单向陪衬、沿途展示或永不交换因果时，合并、降级或删除。短意象、生活纹理和一次性呼应可以只承担氛围或主题回响，不强迫建立完整支线发动机。

扩写前问新增人物、支线、制度、历史或地域改变了哪一项上层状态；没有改变就不加。压缩时保护故事核、关键选择、因果支点与结局责任，先删重复证明、同功能角色和只供参观的世界信息。不得把同一模板按字数机械拉长，也不得因篇幅巨大先做完整百科、逐章锁死远期剧情或靠重复升级维持长度。

## 剧情演进、叙事时序与多线并行

先确定当前单元以什么为主推进，不把两种组织方式混成流水账：

- **剧情推进**：沿`目标 -> 行动 -> 阻力 -> 选择 -> 结果 -> 新局势`前进，后一单元必须承接前一结果并改变下一步可选行动。
- **时间推进**：沿人物生命、制度演变、旅行、战争、灾害或季节等承重时段前进；每次跃迁须说明前一阶段的行动、关系、能力、债务或公共后果怎样沉积到下一阶段，不逐年填满空白。

两者都用“**双轴一链**”控制：**事件发生轴**记录作者本真中的先后、历时和前置条件；**叙事呈现轴**记录正文何时让读者看见、误解、回忆或重新理解；**因果与状态链**记录人物、关系、知情、资源、风险、身体和世界状态怎样变化。事件发生序是连续性底盘，呈现序可以重排；重排不得让结果早于必要前提、人物提前获得信息或既有代价无因复位。

### 角色本位的局势演化

剧情不从预定转折倒推人物动作。先从当前权威继承人物底色、被当场唤起的过往因果痕迹、关系债务、知情与误解、身体资源和上一单元离场状态；再区分已确认事实、创作候选与待确认项，不让恢复摘要、旧稿或本轮新设的涉案者、凭据和真相自动成为事实。规划输出若使用输入未确认的具体身份、凭据、制度动作、因果机制或真相，先用一句总括标明这些内容仍是候选，不为每项重复贴标签；总括须覆盖本轮全部未确认内容，不能只标一类而让其余细节事实化。只有作者确认或落入明确自决授权后才能写入卡片与权威。人物依据读 `character-craft.md`，跨轮权威与状态依据读 `continuity-and-revision.md`。

作者侧沿`继承状态 -> 感知或误读 -> 相互冲突的冲动 -> 有限选择 -> 他人、制度与环境反作用 -> 即时、延迟或非预期后果 -> 新局势`推演。把当前时间、地点、身体、资源、时限、通行或发言资格、可用物件以及其他行动者正在进行的事务压入选择；不会改变选择或读者理解的背景留在作者侧。人物不要求永远理性或最优，动机也不必唯一；其他行动者即使不在主角视野内，仍按自己的目标、知情、关系和能力行动。

输出前做两项承重检查：

- **承重者闭环**：落笔前列出题面明确出现且会影响主线的行动者，逐个确认其此刻目标、知情、能力与可见影响；未出场者也说明正在做什么、为何不能介入或消息怎样抵达。机构接口若只有规则功能，说明规则由什么条件触发、怎样执行并改变选择，不为填表强造角色目标。
- **失常选择闭环**：人物若作出违背常态的关键选择，显式核对其当时所知或误读、辨识把握、身体与能力、正在承担的责任、可求助者、不可兼得的时限及环境阻碍；输入未提供的承重条件列为待确认或候选，不能跳过或补成事实。作者侧必须存在足以压过惯性的当场支点，并说明替代动作为何不能免除其亲自承担；正文是否让读者当场看见完整自我辩解，服从 POV、叙事距离与揭示时点，可以只留下可回望的动作、克制或片段心理。不得只说人物已有矛盾、冲动或创伤，也不能只补一个促使其折返的信号。

规律表现为约束、趋势、反馈与代价，不是替人物决定结局的宿命；偶发事件可以改变机会、顺序和信息窗口，不能替人物完成核心选择、免费送来答案或抹掉已确认取舍。反向检查人物选择能否回到其底色、过往、有限认知和当场压力，正向检查即时与长尾后果是否真实限制下一步；只有前者没有后者，剧情会停成人物切片，只有后者没有前者，人物就成了作者搬运结果的工具。

复杂时序只维护承重项，不强制所有场景填表：

```text
事件 / 场景与所属线：
发生时点、历时与地点：
进入状态、人物底色与被唤起的过往：
各方目标、知情 / 误解与关系压力：
场景约束、独立行动与偶发扰动：
选择、即时 / 延迟 / 非预期后果与状态增量：
正文呈现位置与读者所得：
跨线接口或回忆进出锚点：
```

复杂主线按 `SKILL.md` 协同 `huaxia-practical-wisdom`，只消费能缩小误差的叙事校准：时势怎样改变选择窗口，身份、权力、责任与实际行为是否相称，不可兼得时谁作选择、谁受益、谁付代价，行动反馈怎样形成下一阶段的新条件。经典名词和校准卡不进入正文，也不替作者确认正典。

并行或多线剧情为每条线保留自己的局部时钟、地点、行动者、目标、知情、资源与状态链，再用共同事件、消息传播、人物移动、资源转移、环境变化或会合节点对齐全局。切线不自动表示时间跳跃；只按读者定位需要给出最小时间、空间或共同事件锚点，并让未出场的行动者继续按自身利益和条件行动。规划每个切口时同时记清本线经过多久，以及其他线在这段时间继续、等待、受阻还是已经结束什么行动，不用一句“与此同时”抹平局部时钟。跨线影响必须经过真实接口：消息有传递与理解时间，路程有距离与阻碍，命令有执行偏差，资源转移会使原持有者失去选择。不同线可以错过、先后抵达或只在后果上相交，不为制造同步高潮让所有人同时知道、同时行动或同时会合。

### 线索驱动的多线协作

多线围绕同一事件、秘密或读者承诺演进时，每条线除局部状态外只增加当前推测及其行动依据，不复制一张全知答案表。跨线线索沿`线索产生者 -> 载体 -> 传播时间与失真 -> 接收者 -> 理解或误解 -> 行动 -> 跨线反馈`传递；没有真实载体的相似意象、巧合或主题呼应不能自动成为证据，也不能让人物共享作者本真。

同一线索可以在不同位置、利益和时势下形成不同推测，一条线也可以只承载代价、阻碍或后果，不要求所有线都参与解谜、共享结论或同步会合。每次切线检查新获得、失去或误解的信息怎样改变选择，并让行动反馈支持、削弱或推翻原推测；若一条所谓支线没有独立行动者、目标、选择和状态变化，只负责递送答案，则并入场景或跨线接口。

倒叙、插叙、回忆、梦境和不可靠记忆先标明它们在事件发生轴与叙事呈现轴上的不同位置，再检查进入刺激、时间或空间定位、返回当下的锚点及其当前作用。它们可以延迟真相、重释旧事或显露人物偏见，不因非顺叙被判错；但结束后须改变当下判断、关系、风险、行动或读者理解。人物记忆可以残缺或错误，作者本真、人物确信与读者所得仍须分层；若删去整段不影响当前单元，只保留必要片段或移出。

## 节奏与呼吸

规划一批章节时联合检查句段的信息与感知速度、场景加压与恢复、章节进展或揭示、跨章张力变化及卷级承诺消耗。连续高压只要每次改变约束、选择、关系或后果就可以成立；连续章节功能同质、代价长期未清或读者承诺被拖欠时，再插入或改写清算、关系、线索、世界侧面或情感沉淀。缓冲不是停滞，也必须改变后续处境；不规定每几章一次缓冲、峰值后几章降压，也不把短句、长句或节拍标签直接等同于快慢。

## 层级契约

- **全书**：核心命题、主角长线变化、主要力量及不可逆终点。
- **卷**：卷首状态、阶段目标、主要阻力、不可逆转折、卷末新状态和后续接口。
- **幕/阶段**：目标、升级、选择、代价和阶段反馈。
- **章**：进入状态、行动目标、冲突、异常升级、信息或关系变化、代价、章尾推动力。
- **场景**：视角人物、地点时间、即时目标、阻碍、动作、感官细节、转折和离场状态。

下层必须改变上层状态；没有变化的场景应合并、删去或改写。

## 分层规划与作者讨论

按当前任务需要增加分辨率，不把所有层级一次写满：

```text
总纲 -> 卷提要 -> 作者裁决 / 明确自决授权 -> 卷卡
卷卡 + 已发生正文 -> 章节提要 -> 作者裁决 / 明确自决授权 -> 章卡 -> 正文 -> 状态回写
```

提要用于讨论，允许保留少量互斥候选；卡片只固化作者已确认或明确授权 Agent 自决的当前契约。先区分已确认、候选、待确认和可临场调整，再列出会改变核心因果、高潮、结局或读者承诺的关键分叉及其依赖；除用户已经点明的显性选择，还要检查互斥机制、揭示时点、关键物件或资源功能等会改变选择含义的隐含前提。只展开当前主 blocker，给出推荐及理由；不得因一次只请作者裁决一个 blocker 而隐藏其他关键分叉，依赖当前主 blocker 的其他分叉只列候选关系，不替作者选定。已有自决授权时直接采用最合适的候选，记录采用、舍弃及对上层承诺的影响，不重复请示。表现细节、场景顺序或章节边界若不改变承重状态，留给写作现场；表现细节只包括场内可感的动作、语气、节拍、空间与感官呈现，不授权新增场前、场外、人物过往或新的因果凭据。

### 卷提要与卷卡

卷不是任意篇幅切段，而是全书内部的中程叙事单元。卷提要先回答本卷为何存在：怎样承接全书终点与长期承诺，本卷自己的核心问题、阶段故事发动机、人物与关系变化、主要阻力、高潮选择和卷末交付是什么。高潮优先由人物面对不可兼得目标时的选择与代价形成；卷末须兑现本卷主要承诺，同时明确已转交、转义、退役或新建立的后续承诺，不能只靠突然中断制造下一卷需求。

作者确认后再形成卷卡：

```text
全书承接与本卷核心问题：
卷首状态与阶段目标：
人物 / 关系变化：
主要阻力与升级链：
不可逆转折：
高潮选择与代价：
卷末新状态与已兑现承诺：
后续接口与待回收承诺：
事实与权威指针：
```

卷卡不预设固定章数、三幕比例或远期逐章事件。写作改变了人物、因果或读者承诺时，先记录影响；只有作者确认或明确自决授权范围内的变化才能修订受影响的卷卡，否则保留候选差异并交作者裁决，不让成篇文字或旧卷纲成为第二正典。

### 章节提要与正文准入

章节提要先核对上一章实际离场状态和当前权威，再说明本章为何存在、必须改变哪些行动 / 关系 / 信息 / 风险 / 资源状态、候选场景链、核心选择与代价、章尾新状态及不得提前揭示的信息。进入状态只复述当前权威已经给出的事实；材料没有说明的物件归属、地点、时点、动机或因果保持待确认，不为填满章卡擅自补齐。场景先按因果和情绪关系成链，再决定合并为一章还是拆章；章节边界服务小型弧线、节奏、情绪闭合或翻页期待，不强制一章一场，也不要求每章 cliffhanger。

进入正式正文前确认：

- 当前权威上下文和上章离场状态已经核对；
- POV、时间、地点及人物 / 读者知情边界无冲突；
- 当前创作单元调用的世界硬约束及跨系统依赖已按 `worldbuilding-and-research.md` 核对；长篇与超长篇还须确认全书外框和当前卷运行系统不存在会推翻正式正文的承重缺口；
- 不得把读者专属线索改写成人物可感暗示，不得补造权威未确认的场前 / 场外事件、人物过往、对白、记忆或因果凭据；“只授权本场表现细节”不改变这条边界；
- 本章必须改变的状态、核心选择、代价和章尾可承接状态明确；
- 不存在会推翻本章核心因果、当前卷运行或全书长期承诺的待确认项。

缺少承重条件时继续讨论，不靠补猜进入正文。作者明确要求先看效果时，可以交付标明边界的非正典压力测试，不写回权威。正式正文完成后按实际结果记录状态增量，以及章卡中兑现、移动、转义或退役的内容；临场发现更有效写法时以真实成篇为候选依据。已核对且无冲突的准入项只报告结论，不逐项复述；合并重复的边界说明，只展开当前主 blocker、其他关键分叉、候选差异及其影响。只有作者确认或明确自决授权范围内的变化才能回写卡片和后续承诺；超出授权的变化只记录为候选差异并交作者裁决。

纯正文交付前做一次正典增量扫描：逐句检查所有发生在开场前或场外的动作、旧对白、回忆、物件属性、关系细节和因果凭据。输入或当前权威没有明确给出的内容一律删除，或改写为当前场内可见事实与不带新增细节的既有关系反应；例如只能写“妹妹仍在官差手中”，不能补写“她被带走时回头、没有哭、说过什么或穿着什么”。扫描只在内部执行，不把清单混进正文。


## 发布载体与叙事语体

先锁定事实、人物欲望、关系和类型承诺，再按发布载体选择视角、人称、叙事距离、人物声音、节奏、段落与信息密度；载体改变表达，不改写人物性格或新增事实。

- **纸媒文学短篇**：保护叙事呼吸、复义、生活细节和整体回响，允许段落长短随场景变化，不强制早期解释或章尾悬念。
- **移动端连载**：控制单屏信息负荷，用短段落、早期异常、清晰进展和章尾推动力支持连续阅读；不把载体适配退化成只切短句子。
- **有声叙事**：保证人物声音可辨、场景切换可听懂，重要信息不能只依赖视觉排版；不把口语化等同于降低叙事密度。

两种版本需要真正改写叙事组织，而非只换标题、断句或段落长度。制造钩子不得取消人物迟疑、生活质感、行动代价和后续余波。

## 章卡

```text
类型 / 节拍：推进 / 峰值 / 缓冲（代价·对话·线索）
本章功能：
主视角与进入状态：
事实与权威指针：
行动目标：
阻力与异常升级：
人物选择：
信息 / 关系 / 风险 / 资源变化：
代价与余波：
章尾推动力：
不得提前揭示：
```

事实与权威指针只引用本章实际调用的正文、人物、规则、时间线、活跃承诺或原始材料及其当前版本；摘要和恢复简报只作索引，不能替代事实权威。类型 / 节拍是规划时的叙事功能提示，不是不可修改的标签。临场发现新人物、事件或更有效写法时，先核对它是否改变上层状态和读者承诺；授权范围内再更新、移动、合并或退役章卡，超出授权则只记录候选差异并交作者裁决，不为服从旧表格牺牲当场故事，也不让成篇自动升级正典。章尾推动力优先留下关系、决定、风险或情绪的余力，不只靠突发声响或陌生人出现。章卡钩子记录计划中的因果功能和读者承诺，不锁死字面事件：尚未形成承诺时可以有依据地删除、移动或转义；已经形成承诺时须兑现、转义或明确改变承诺，不能被临场刺激静默替换。下一章第一拍须承接上一章留下的动作与后果：扩大、改变或迫使人物承担它，不复述、不无因降温，也不长期切走拖欠。
