# 通用人物动态档案模板

## 使用方式

本模板用于承接人物自身的生活、关系、选择与故事后果，不是第二份正典，也不是所有人物都要填满的问卷。先按 `../references/character-craft.md` 的“先立其人，再辨其用”理解人物，再读取项目本地状态、权威来源和档案职责：项目已有定义时服从项目；没有定义时，才另行约定状态与确认方式。

- 背景人物可直接写在章卡或场景中，不建档。
- 阶段人物与首次规划的重要人物先用“最小人物卡”。
- 核心人物、重要配角和对手按需增加“重要人物扩展”。
- 事件真实发生后才填写“动态更新附录”；创作候选留在候选区，不冒充人物事实。
- 只有人物承担承重剧情经历且项目已有时间线或事件台账时，才引用稳定事件号、发生锚和权威指针；人物卡不复制整条时间线，也不因“寻找”“预备”等已确认行动把后续相遇或结果写成必然事件。

删除未使用字段。外形、衣着、技能和生平可服务选择、关系、视角、行动或后果，也可只呈现生活质感、趣味与审美；不为填满档案编造经历，不以没有剧情用途为由删掉使人物可感的细节。

## A. 最小人物卡

### 1. 档案边界

```text
人物：
当前创作单元与时间点：
项目本地状态：
人物事实权威：
承重经历时序引用（Event ID / Time Axis / T Anchor / 权威指针；无则删）：
条件式或未落位经历及其条件、上下界与 blocker（无则删）：
本轮可决定 / 待作者确认：
```

### 2. 立身与当前处境

```text
时代 / 世界、身体与生活来处（只写当下所需）：
赖以生活、安心或自重的事物与关系：
当前目标与为何现在行动：
此事对他的意义、眼前限制与可选行动：
```

需要论证故事定位时，再说明此人对主线、关系、生活感受或阅读体验的作用；删除测试用于取舍叙事，不作为人物能否存在的资格判断。普通过客不因此补建人物卡。

### 3. 内在牵系

按当前场景裁剪，允许相安与平常；不用补反差、创伤或自欺来填满栏目。

```text
所欲与所守，眼前相合或相争之处：
怎样解释自己，哪些尚未明白或不愿承认（如适用）：
当下感受、判断与可能的行动 / 不行动：
```

确有相应依据时才追问错误信念或旧伤、保护策略、认知盲区、脆弱触发及其代价；未经确认的解释仍是候选。

### 4. 关键关系与行动限制

```text
关键关系：亲疏 / 信任 / 利益 / 权力 / 亏欠 / 共同经历：
双方怎样看待自己与对方，如何相处或相互牵动：
身体、身份、资源、能力或知情限制：
可写进场景的动作、感官、物件或声音抓手：
```

## B. 重要人物扩展

只选当前故事会调用的栏目。

### 1. 因果经历卡

每段经历只回答：发生了什么，当时如何感受或解释，怎样沉成能力、习惯、好恶与关系，如今何事会唤起或改写它。快乐、照料、学习与日常积累也可塑人，不只追踪损伤；完整生平不等于有效人物设计。

### 2. 独立行动

适用于重要配角和对手；普通功能角色无需强建副线。

```text
自己的问题与目标：
可用资源、情报和计划：
即使主角不在场也会采取的行动：
行动给主线留下的可见后果：
受挫后的损失、新情报、剩余资源与计划调整：
```

### 3. 能力与边界

```text
稳定能力及其来源：
使用条件、盲区和代价：
他人误判之处：
本阶段允许发生的变化：
```

### 4. 关系接口

对每段关键关系记录双方各自想要什么、握有什么、隐瞒什么、谁能伤害谁，以及一次关键选择前后，信任、权力、亏欠或距离怎样改变。

### 5. POV 与人物声音

```text
欲望让他优先看见什么：
知识、偏见与身体让他误读或忽略什么：
常态声音与压力下的变化：
不会说、不能说、只会用行动表达的内容：
```

### 6. 经事与变化（按需）

```text
原有习惯、理解与关系：
哪些相处、遭际或选择可能使它改变或更加稳固：
尚未察觉、迟来才明白或仍未解决的事：
后续场景应继承的余波：
```

变化可以渐成，也可以未发生；人物可以坚守、拒绝改变或倒退，不默认安排创伤、顿悟与不可逆大抉择。

## C. 动态更新附录

一场戏、一个阶段或一次重大事件结束后，只记录实际发生的变化；未发生的预想保持原项目状态。

```text
事件 / 场景、稳定事件号、发生锚与事实权威：
落位状态 / 条件（如适用）：
触发：
人物实际选择：
即时代价与外部后果：

状态                  进入前              离开后              变化依据
目标：
情绪：
关键关系：
身体：
知情：
人物声音：
资源 / 能力 / 身份：

下一阶段必须继承的限制、责任或余波：
仍属候选、不得写回事实的反应：
```

无变化的维度删去，不为完整而补空白。若离场状态与既有事实冲突，先回到人物事实权威核对，不用新解释覆盖旧冲突。
